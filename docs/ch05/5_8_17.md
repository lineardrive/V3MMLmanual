# 5.8.17 機能名：`velocity`：ベロシティの最大値

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   velocity: peak=100,
}
```

上記のように記述すると、ベロシティ（`vel`。[4.17](../ch04/4_17.md)）の最大値が 100 になります。`vel100` が最も強く、`vel50` がその半分の強さです。

## 【解説】

ベロシティの最大値を設定します。この設定は、曲全体に効きます。

V3MML は、ベロシティを中では割合 r ＝ `vel` ÷ `peak`（0 〜 1）で持ちます。ベロシティを使う所は、すべて r で計算します。

- エンベロープの `vel_curve`・`vel_depth`・`time_vel`（[7.4](../ch07/7_3n4.md)・[7.5](../ch07/7_5n6.md)）
- 動的フィルタの `mod=vel`（[6.42](../ch06/6_41n42.md)）

`peak` を変えた曲では、同じ強さを `peak` に対する割合で書きます（例：`peak=100` なら `vel50` が r ＝ 0.5）。エンベロープや動的フィルタの定義は書き直しません。

ベロシティの値を書く所（`vel`・音色のレイヤーの `map_vel`・`map_vel_val`・`map_vel_osc` の点の位置。[10.9](../ch10/10_9n10.md)）は、どれも 0 〜 `peak` の範囲で、小数も書けます。`peak` を小さい値（例えば 1）にするときに使います。

当設定を使用しなかった場合の初期設定は、次の通りです。

```mml
#MB:CONFIG {
   velocity: peak=127,
}
```

### 項目名(1)：`peak`

定義値には、ベロシティの最大値を、0 より大きい数で指定します。小数も書けます。  
トラックの先頭の `vel` は、この値（r ＝ 1）です。

`#MB:CONFIG` は、ほかの `#MB:` の定義の後ろに書いても構いません。ベロシティの値の範囲は、全部の `#MB:` を読んだ後に調べます。
