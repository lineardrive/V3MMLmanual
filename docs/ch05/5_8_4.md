# 5.8.4 機能名：`env_clock`：エンベロープ時間単位設定

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   env_clock: unit=sec: rate=1/60,
}
```

## 【解説】
エンベロープ全種類への、エンベロープの時間単位を設定します。  
この設定は、全トラックへの初期設定となります。  
当設定を使用しなかった場合の初期設定は次の通りです。

```mml
#MB:CONFIG {
   env_clock: unit=sec: rate=1/127,
}
```

### 項目名(1)：`unit`

定義値には、時間単位を文字列で指定します。

|設定文字列|エンベロープ時間単位設定内容|
|:-:|:-:|
|`sec`|時間単位は「１秒」|
|`tick`|時間単位は「１tickカウント」|

### 項目名(2)：`rate`
定義値には、時間単位に対する倍率を数値（計算式）で指定します。
時間単位が「`sec`」だった場合、`rate`の有効範囲は、1/3000 〜 1 になります。

#### 【備考】
時間単位が「１tickカウント」の場合、テンポにより時間単位が変動します。  
ノートオン中にテンポ変更が掛かった場合も、その時点から自動追従します。

- 進行中の節は、残りの時間が新しいテンポに合わせて伸び縮みします。節の途中の音量から、次のポイントの音量へ、新しい速さで変化を続けます。
- 以降の節は、新しいテンポで計算されます。
- 例えば、節の途中で `t120` から `t60` に変わると、その節の残りは２倍の時間を掛けて進みます。

時間単位が「１秒」の場合は、テンポを変更しても時間単位は変わりません。
