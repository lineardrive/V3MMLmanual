# 5.5 `∕∕`：コメントライン

[← 目次](../index.md)

## 【記述例】

```mml
//cdefg;
```

上記の場合、「`cdefg;`」はコメント扱いになり、演奏されません。

```mml
#ML:TITLE テストタイトル//test title
```

上記の場合、「`//test title`」の文字列は、コメントライン処理により、「`#ML:TITLE`」によるタイトル文字列には含まれないことになります。

## 【解説】

コメントラインを設定します。  
「`//`」を記述して以降、改行までをコメントエリアとして読み飛ばします。  
コメントエリア内には全角文字を含んでいても問題ありません。

### 【備考】

[プリプロセッサの処理順序](5_1.md) により、メタデータ処理よりも、コメントライン処理が優先されます。
