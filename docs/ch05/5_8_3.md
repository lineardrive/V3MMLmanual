# 5.8.3 機能名：`relative_sign`：相対記号`<>()`の方向設定

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   relative_sign: oct_updown=><: vol_updown=)(,
}
```

## 【解説】

相対オクターブ記号、相対ボリューム記号の方向を設定します。  
この設定は、全トラックへの初期設定となります。

### 項目名(1)：`oct_updown`

相対オクターブ記号の方向として、定義値には次のいずれかを指定します。

|設定文字列|相対オクターブ設定内容|
|:-:|:-:|
|`><`|「`>`」でUP、「`<`」でDOWN|
|`<>`|「`<`」でUP、「`>`」でDOWN|

### 項目名(2)：`vol_updown`

相対ボリューム記号の方向として、定義値には次のいずれかを指定します。

|設定文字列|相対ボリューム設定内容|
|:-:|:-:|
|`)(`|「`)`」でUP、「`(`」でDOWN|
|`()`|「`(`」でUP、「`)`」でDOWN|
