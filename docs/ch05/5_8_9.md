# 5.8.9 機能名：`z_damper_rate`：強制ダンパーの初期設定

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
  z_damper_rate: env=0.05: fms=15,
}
```

## 【解説】

強制ダンパー（`z`コマンド・`@az`コマンド。[7.8](../ch07/7_8.md)・[7.9](../ch07/7_9.md)）の、初期設定を行います。  
この設定は、全トラックへの初期設定となります。  
強制ダンパーは、内部で音量エンベロープ（`@ea`）向けとＦＭ音源（`@@"fms"`）向けの２種類に分かれており、初期設定はそれぞれに行います。  
当設定を使用しなかった場合の初期設定は次の通りです。

```mml
#MB:CONFIG {
   z_damper_rate: env=0.03: fms=15,
}
```

### 項目名(1)：`env`

定義値には、0 以上の数値を指定します。小数点以下の指定も受け付けます。  
定義値は音量エンベロープ（`@ea`）用の強制ダンパーに使われます。  
また、定義値は、エンベロープ定義内における変化率（ I のモード）によるレートとして解釈されます。減衰時間はエンベロープクロック（時間単位）の設定に依存します。

### 項目名(2)：fms

定義値には、0 〜 15 の整数を指定します。
定義値は、ＦＭ音源モジュール（`@@"fms"`）用の強制ダンパーに使われます。  
強制ダンパー実行時に、全てのオペレータのリリースレートが、定義値に書き換えられます。

各オペレータのリリースレートと、音が０になるまでの時間の目安は、[7.7](../ch07/7_7.md) の表を見てください。

### 【備考】名前の変更

この機能の名前は、以前は `damper_rate` でした。オートダンパー（`@ad`。[7.14](../ch07/7_14n15.md)）と区別するため、`z_damper_rate` に改めました。  
`damper_rate` と書くと、次のエラーになります。

```
設定名称エラー：damper_rate
```
