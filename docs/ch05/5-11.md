# 5.11 `!`：ＭＭＬステータス表示関係

[← 目次](../index.md)

【解説】
ＭＭＬ編集中のデバッグ表示として、各種情報を Warningウィンドウ に表示し
ます。
- !n[1]：音符ログ
【記述例】

この場合、前半のcdefgrの音符部分のログのみが表示されます。
【解説】
ＭＭＬ編集中のデバッグ表示として、音符の履歴情報（ログ）を、Warningウィ
ンドウに表示します。
引数[1]は、０または１で指定します。
指定値が１のとき、音符ログの開始します。
指定値が０のとき、音符ログの停止します。
```mml
!n1 cdefgr
!n0 gfedcr;
```

- !r[1]：休符ログ
【記述例】

この場合、前半のcdefgrの休符部分のログのみが表示されます。
【解説】
ＭＭＬ編集中のデバッグ表示として、休符の履歴情報（ログ）を、Warningウィ
ンドウに表示します。
引数[1]は、０または１で指定します。
指定値が１のとき、休符ログの開始します。
指定値が０のとき、休符ログの停止します。
```mml
!r1 cdefgr
!r0 gfedcr;
```

- !s[str]：現時点のステータス表示
【記述例】

どの時点かの判別を容易にするため、ラベル"stat-a"、"stat-b"、"stat-c"を
使っています。最後の「!s」記述のように、ラベル無しでも受け付けます。
【解説】
!s[str]コマンド記述時点での、各種ＭＭＬコマンド発行状態が、Warningウィン
ドウに表示されます。
引数[str]はダブルクォーテーションで括った文字列を指定します。文字列は単
なるラベルですので内容は自由ですが、半角文字のみで記述してください。
引数を省略する場合は「!s」とだけ記述します。
```mml
t70 l4 @q3 v15
a(2 a(2
!s"stat-a" a(2 a(2
!s"stat-b" a(2 a(2
!s"stat-c" a(2 !s
```

- !c[1],[str]：回数条件によるステータス表示
【記述例】

!c3,"ge"によって、その時点で３回以上指定されているコマンドのステータスを
表示します。
【解説】
!c[1],[str]コマンド記述時点での、その時点で指定条件に合うＭＭＬコマンド
の発行状態が、Warningウィンドウに表示されます。
引数[1]はＭＭＬコマンドの指定回数、引数[str]はダブルクォーテーションで括っ
た文字列で、条件を指定します。
```mml
t70 l4 @q3 v15 a(2 a(2 a(2 a(2 a(2 a(2 a(2
!c3,"ge";
```
【!c[1],[str]の条件文字とその内容】
条件文字
```
gt
ge
lt
le
eq
ne
```
内容
より多い
以上
より少ない
以下
等しい
等しくない

- !m[1]：ステータスを指定メモリ番号へ記憶
- !d[1],[2]：記憶したステータス同士の差分を表示
【記述例】

!m1 と !m2 によってメモリ番号１番と２番にその場所のステータスを記憶。
!d1,2 によって、メモリ番号１番と２番の状態比較をし、差分を表示。
【解説】
ステータスメモリコマンド（!m[1]）：
!m[1]コマンド記述時点でのステータスを記憶します。
引数[1]は記憶するメモリ番号です。0 〜 9 までの整数で指定します。
ステータスdiffコマンド（!d[1],[2]）：
記憶済みメモリ番号同士でステータス内容を比較し、差分を表示します。
引数[1]と引数[2]はメモリ番号です。双方 0 〜 9 までの整数で指定します。
```mml
t70 l4 @q3 v15 !m1 a(2 a(2 a(2 !m2 a(2 a(2 a(2 a(2
!d1,2;
```

- ![str]：注意喚起の通告を表示
【記述例】

【解説】
![str]コマンド記述時点での通告が、Warningウィンドウに表示されます。
引数[str]はダブルクォーテーションで括った文字列で、通告内容を半角文字で
記述します。
主な用途は、後で修正を促す内容のコメントを設定しておく、などです。
```mml
t70 l4 @q3 v15 !"start" a(2 a(2 a(2 a(2 a(2 a(2 a(2
!"end";
```

- !：ステータス表示関係機能の簡易ヘルプ表示
【記述例】

【解説】
ステータス表示関係コマンドの概要を簡易的に Warningウィンドウ に表示しま
す。
```mml
t70 l4 @q3 v15 ! a(2 a(2 a(2 a(2 a(2 a(2 a(2;
```
