# 5.14 `[R:]` `[MW:]` `[MR:]` `[S…:]`：テーブルの文字列前処理

[← 目次](../index.md)

## 【記述例】

```mml
#MB:LFOTBL_ATK 1 {
   loop=0, cmpl=0, offset=0, denom=256, width_mode=step, |
   [R:6:[R:37:256,] 56, -44, -144, -44, 56,]
}
```

上記の場合、テーブルの値の並びは「`256` を 37 個、続けて `56, -44, -144, -44, 56`」を 6 回くり返した、252 個の値になります。

## 【解説】

メタデータ定義（`#MB:`）のうち、値をカンマで並べるテーブルの本体に、くり返しや数列を書くための仕組みです。

テーブルの本体は、値を 1 つずつ読む前に、この前処理を通ります。  
前処理は、大カッコ `[ ]` で書いた命令を、決まった規則で別の文字列に置き換えるだけです。置き換えた後の文字列が、今までどおり 1 つずつの値として読まれます。

- 前処理は「文字列のコピーと貼り付け」です。カンマを補うことはしません（S 系の命令だけは、各値の後ろにカンマを付けます）。
- 命令を含まない本体は、前処理で何も変わりません。
- メタデータ定義の中ではマクロや繰り返し（`|: :|`）を使えませんが（[5.1](5_1.md)）、この前処理は、テーブルの本体の中だけで別に働きます。

### 命令の形

```
[ 種類 : 引数 : … ]
```

- 最初に命令の種類を書き、引数を「`:`」で区切って続けます。
- 種類は大文字・小文字のどちらで書いても構いません（`[R:…]` と `[r:…]` は同じです）。
- 文字列の引数は、ダブルクォートで括らずにそのまま書きます。文字列の中に「`:`」と「`|`」は書けません。
- 文字列の引数の中に計算式を書けます。前処理はそのままコピーし、値を読むときに計算されます（`[R:2:1+1,]` は `1+1,1+1,` になり、`2,2` として読まれます）。
- 数の引数（回数・番号・始め・終わり・増分・個数）は計算式で書けます。前後の空白は無視されます。数の引数では、「`#`」は 0、「`?`」は乱数として読まれます。

### 命令の一覧

|命令|引数|置き換え|例|結果|
|:-|:-|:-|:-|:-|
|`R`|回数、文字列|文字列を回数ぶん、そのままつなげます。|`[R:2:45,56,26,]`|`45,56,26,45,56,26,`|
|`MW`|番号、文字列|文字列を番号に記憶し、この命令は空にします（切り取り）。|`[MW:2:256,]`|（空）|
|`MR`|番号、回数|記憶した文字列を回数ぶん貼り付けます。回数を省くと 1 回です。|`[MR:2:4]`|`256,256,256,256,`|
|`S.<E/C`|始め、終わり、個数|始めから、終わりの手前までを個数ぶんに等分した数列です（終わりは含みません）。|`[S.<E/C:1:10:4]`|`1,3.25,5.5,7.75,`|
|`S..E/C`|始め、終わり、個数|始めから終わりまで（両端を含む）を個数ぶんにした数列です。|`[S..E/C:1:10:4]`|`1,4,7,10,`|
|`S/DT/C`|始め、増分、個数|始めから増分ずつ足した数列を個数ぶん並べます。|`[S/DT/C:1:3:4]`|`1,4,7,10,`|

- `R` の回数 0 は空になります。一時的に消しておきたい部分を囲むのに使えます。
- S 系の命令は、各値の後ろにカンマを付けます（最後の値にも付けます）。値は丸めずに、指数表記を使わない 10 進で書き出します（`[S..E/C:0:1:4]` は `0,0.3333333333333333,0.6666666666666666,1,`）。
- `S.<E/C` は終わりを含まないので、折れ線を区間ごとに並べても、つなぎ目の値が重なりません。  
  例：`[S.<E/C:0:100:4][S.<E/C:100:40:3] 40,` → `0,25,50,75,100,80,60,40,`

### 値の範囲

|値|範囲|
|:-|:-|
|`R` の回数|0 以上の整数|
|`MR` の回数|0 以上の整数（省くと 1）|
|`MW` / `MR` の番号|0 〜 999 の整数|
|`S.<E/C` / `S/DT/C` の個数|1 以上の整数|
|`S..E/C` の個数|2 以上の整数|
|始め・終わり・増分|任意|

範囲の外や、整数でない指定はエラーになります。

### 構造の決まり

- **入れ子**：`R` と `MW` の文字列の中に、命令（`R`・`MR`・S 系）を書けます。入れ子は 8 段まで（`MW` の段も数えます）で、9 段目はエラーです。
- **`MW` の置き場所**：最上位（どの命令の中でもない所）にだけ書けます。`R` の中や `MW` の中に書くとエラーです。
- **記憶の範囲**：記憶は 1 つの `#MB:` 定義の中だけで有効です。別の定義で記憶した番号は呼べません。
- **書き直し**：同じ番号の `MW` を 2 回書くとエラーです。
- **処理の順**：左から右へ読みます。`MR` が呼べるのは、それより左にある `MW` だけです。記憶の無い番号を呼ぶとエラーです。
- **`R` の回数 0 の中**：展開せずに読み飛ばします。大カッコの対応と入れ子の段数だけを確かめ、中の誤りはエラーにしません。
- **数の引数の中**：命令は書けません（「`[`」があるとエラーです）。

### 値の数の上限

置き換えた後の値の数が、そのテーブルの上限を超える場合は、展開する前にエラーになります。

- 値の数は、空の要素（先頭・末尾の余分なカンマや「`,,`」）を除いて数えます。値を 1 つずつ並べた場合と同じ数え方です。
- 個数が決まっているテーブル（`#MB:KEYEVENT_CODE` の 120 個など）では、余分なカンマがあっても、値の数が決まった数なら受け付けます。

### エラー

次の場合はエラーになります。エラーの文には、本体の先頭から何文字目かが入ります。

- 大カッコの対応の誤り（「`]`」が足りない・多い）
- 命令の種類の誤り、引数の数の誤り
- 回数・個数・番号が範囲外、整数でない、または計算式の誤り
- 9 段目の入れ子、数の引数の中の「`[`」、文字列の引数の中の「`:`」
- `MW` が最上位以外にある、同じ番号の書き直し、記憶の無い番号の `MR`
- 置き換えた後の値の数が上限を超える

#### 【注意】

`R` と `MR` は中身をそのままつなげるので、値の後ろにカンマを書き忘れると、隣の値とつながります。  
`[R:3:256]` は `256256256` という 1 つの数になります。エラーにはなりません。

### 使えるテーブル

|定義|上限|
|:-|:-|
|`#MB:LFOTBL_ATK` / `#MB:LFOTBL_REL`（[8.18](../ch08/8_18.md) / [8.19](../ch08/8_19.md)）|2048 個|
|`#MB:KEYEVENT_TRG`（[10.4](../ch10/10_3n4.md)）|2048 個|
|`#MB:KEYEVENT_CODE`（[10.6](../ch10/10_5n6.md)）|120 個（ちょうど）|
|`#MB:VOLUME_SCALE` の `type=table`（[4.8.1](../ch04/4_8_1.md)）|1025 個|
|`#MB:PITCH_SCALE` の値の並び（[2.14](../ch02/2_13n14.md)）|その種類の決まった個数|
|`#MB:WVM_WAVE`（[6.47](../ch06/6_47.md)）|`csv_*`：4096 個、`seq_*int4`：4096 文字、`seq_*int8`：8192 文字|

- `#MB:WVM_WAVE` の `seq_*` 型では、`R`・`MW`・`MR` を使えます（`[R:4:EE77]` → `EE77EE77EE77EE77`）。S 系の命令はカンマ区切りの数を作るので、`seq_*` 型ではエラーになります。
- `#MB:KEYEVENT_LEN`（[10.8](../ch10/10_7n8.md)）では使えません。本体に「`[`」があるとエラーになります。
- エンベロープの定義（`#MB:ENV_A` など）や音色の定義では使えません（前処理は働きません）。

## 【使用例】

### パターンの使い回し

「A, A, B, A, A, C」のように、同じ形をくり返すテーブル：

```
[MW:1:…A…] [MW:2:…B…] [MW:3:…C…] [MR:1:2] [MR:2] [MR:1:2] [MR:3]
```

### `#MB:KEYEVENT_CODE` の鍵盤の範囲

```
[R:37:21,] 22, 23, [R:2:24,] …
```

音程番号 0〜36 は 21、37 は 22、38 は 23、39〜40 は 24 … のように、範囲ごとに書けます。  
全部の位置を順に書くので書き落としが起きず、合計が 120 個でなければエラーになります。

### 折れ線

```
[S.<E/C:0:100:4][S.<E/C:100:40:3][S.<E/C:40:40:2] 40,
```

0 から 100 へ 4 歩、100 から 40 へ 3 歩、40 のまま 2 歩、最後に 40 を置きます。
