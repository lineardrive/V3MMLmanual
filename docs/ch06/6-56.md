４オペレータモードの音色設定

```mml
#MB:FMS_4OP
```

```mml
#MB:FMS_OPM
```
（ＯＰＭ互換）

```mml
#MB:FMS_OPNA
```
（ＯＰＮＡ互換）

```mml
#MB:FMS_OPN
```
（ＯＰＮ互換）
における、CON（connection：オペレータの接続パターン）の内容を示します。
色付きのオペレータがキャリアで、それ以外がモジュレータです。キャリアが複
数あるCONでは、コーラスや和音の効果を出すことも可能です。
全てのオペレータにセルフフィードバック機能があります。
４オペレータモードの CON は、0〜13 で指定します。
