# 6.25 `@oc[1]`：オペレータクリッピング機能

[← 目次](../index.md)

## 【記述例】

```mml
@oc1
```

上記のように書くと、オペレータクリッピング機能を有効にします。

## 【解説】

オペレータクリッピング機能の対象となるのは、次の音源モジュールです。

```mml
@@"sin"
@@"saw"
@@"tri"
@@"pls"
@@"cpx"
@@"wvm"
```
上記の音源モジュールのいずれかが選択されている場合に、有効になっている全オペレータの合計出力に対し、  
標準振幅範囲の -1.0 〜 +1.0 からはみだす部分につき、  
+1.0以上を+1.0、-1.0以下を-1.0に制限（クリッピング）  
するか否かを設定します。  
トラック先頭における初期設定は、`@oc0`です。

- `@oc1`の場合、クリッピングを行います。
- `@oc0`の場合、クリッピングを行いません。

この機能の目的は、ディストーション効果を得ることです。
