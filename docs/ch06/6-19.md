# 6.19 `@mhz`：@@"fms"用：ＨＬＦＯ無効

[← 目次](../index.md)

【記述例】

【解説】
ＦＭ音源モジュール（@@"fms"）用の、ＨＬＦＯ
（Hardware Low Frequency Oscillator）機能を無効に設定します。
ＨＬＦＯ機能が無効になると、ＦＭ音源の動作がその分軽くなります。
トラック開始時の初期設定では、ＨＬＦＯ機能は無効になっています。
ＨＬＦＯ機能が無効の状態では、yコマンドを使用して直接ＨＬＦＯパラメータ
設定を行っても動作しないので注意してください。
ＨＬＦＯ機能を利用する場合、@mhコマンド または @mhaコマンド を使用する
と、必ずＨＬＦＯ機能が有効化されますので確実です。
```mml
@mhz
```
