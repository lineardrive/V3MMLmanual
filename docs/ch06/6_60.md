# 6.60 バイナリファイルの作成（バインダースクリプト）

[← 目次](../index.md)

## 【概要】

`#MB:LOAD_SAMPLING` で読み込むバイナリファイル（標準の拡張子は `.v3b`）は、複数のサンプリングデータ（ＰＣＭ／ＡＤＰＣＭ／ＤＰＣＭ）を、定められたフォーマットで１つに束ねたものです。

このファイルを作るための、シェルスクリプトの例を示します。  
macOS の標準ターミナルで動作し、Finder からのダブルクリックでも実行できます。

```
本節のスクリプトは、作成方法の一例として掲載しているものです。
内容を確認のうえ、利用者ご自身の責任で使用してください。
```

[（読み込むファイルのフォーマットとは）](6_59.md)

## 【準備】スクリプトの設置

本節末尾のスクリプトをテキストエディタへコピーし、次のファイル名で保存します。

```
__v3mmlBind.command
```

保存したら、ターミナルで次のコマンドを実行し、実行属性を付けます。

```
chmod u+x __v3mmlBind.command
```

これで、Finder からダブルクリックして実行できるようになります。

---

## 【準備】リストファイルの記述

スクリプトと同じフォルダに、次のファイル名でテキストファイルを作ります。

```
__v3mmlBindList.txt
```

### 【記述例】

```
#バインド結果の書き出しファイル（*.v3b）
_generate/v3mml__testpcm.v3b
#読み込みファイル
bd.dpc
sd.dpc
msm0.amb
msm1.amb
msm21.amb
ymadp13.ayb
u8pcm195.u08
VV2608_bd_441.16l
VV2608_sd_441.16l
```

### 【解説】

- １行に、ファイル名を１つ書きます。
- 「`#`」で始まる行はコメントとして読み飛ばされます。
- 空行も読み飛ばされます。
- 最初に書いたファイル名が、書き出すバイナリファイル名になります。
- ２行目以降に書いたファイル名が、束ねる読み込みファイル名になります。

書き出しファイル名の拡張子に制限はありませんが、標準は「`.v3b`」です。  
記述例のように、サブフォルダを付けた書き出し先も指定できます。  
ただし、そのサブフォルダは、あらかじめ作成しておく必要があります。作成されていない場合は、次のエラーで停止します。

```
[v3mmlBind: error] 書き出し先のフォルダがありません:フォルダ名
```

読み込みファイルは、`__v3mmlBindList.txt` と同じフォルダに置きます。  
見つからない場合は、次のエラーで停止します。

```
[v3mmlBind: error] 次のリスト内ファイルが見つかりません:ファイル名
```

### 【注】並び順と `smp` 番号

読み込みファイルを書いた順番が、そのまま `#MB:LOAD_SAMPLING` 第２チャンクの「`smp`」番号になります。番号は ０ から始まります。

上の記述例であれば、次のようになります。

|記述順|`smp` 番号|ファイル|
|:-:|:-:|:-|
|１番目|`smp=0`|`bd.dpc`|
|２番目|`smp=1`|`sd.dpc`|
|３番目|`smp=2`|`msm0.amb`|
|：|：|：|
|９番目|`smp=8`|`VV2608_sd_441.16l`|

## 【実行】

次の３つを、同じフォルダに揃えます。

- `__v3mmlBind.command`
- `__v3mmlBindList.txt`
- 読み込みファイル群

`__v3mmlBind.command` をダブルクリックすると、バイナリファイルが書き出されます。  
正常終了すると、ターミナルに次のように表示されます。

```
[v3mmlBind: 正常終了] _generate/v3mml__testpcm.v3b を書き出しました
returnキーを押してください
```

書き出されたバイナリファイルは、プレイリストのカレントフォルダ配下に置くことで、`#MB:LOAD_SAMPLING` から読み込めるようになります。

### 【注】

バイナリファイル全体のサイズは、２ギガバイトまでです。  
この上限を超えるサイズの場合、演奏開始で読み込む際にエラーとなります。

### 【備考】作業用ファイル

スクリプトは、バイナリの内容を一度１６進数のテキストとして組み立てるため、作業用ファイルを１つ作ります。

- 名前は `__v3mmlBindTemp.` に続く８文字の英数字で、実行のたびに変わります。
- 同名のファイルが既にある場合は、別の名前が選ばれます。既存のファイルを上書きすることはありません。
- スクリプトの終了時に、正常終了・エラー停止のどちらであっても、自動的に削除されます。

### 【備考】エラー停止したときの表示

途中でエラー停止した場合は、エラーの内容に続けて、どこまでの処理が正常に終わっていたかが表示されます。

次の表示例は、読み込みファイル９個のうち、第３チャンクの４個目の書き出しで停止したときのものです。

```
[v3mmlBind: error] 第３チャンクの 4 個目を書き出せません:msm1.amb
[v3mmlBind: ここまでは正常に終わっています]
  作業フォルダへ移動：/Users/xxxx/Music/pcmbind
  リスト読み込み：読み込みファイル 9 個
  作業用ファイル作成：./__v3mmlBindTemp.3gVuy6Dq
  第１チャンク（固定ヘッダ）：書き出し完了
  第２チャンク（アロケーションテーブル）：9 個 書き出し完了
  第３チャンク（実データ群）：3 個 書き出し完了
returnキーを押してください
```

この例であれば、３個目までは正常に書き出せていて、４個目の `msm1.amb` で失敗した、と読み取れます。

## 【読み込みファイルの作り方】

読み込みファイルを用意するときの要点は、次の３つです。

1. ヘッダ情報を含まない「ＲＡＷデータ」であること。
2. モノラルデータであること。
3. 定められた拡張子を付けること。

波形編集ソフトなどで、`*.wav` などの素材をＲＡＷデータとして書き出し、拡張子を、次の８種類のいずれかに変更します。

|拡張子|形式|
|:-|:-|
|`.u08`|unsigned 8bit PCM|
|`.s08`|signed 8bit PCM|
|`.16l`|signed 16bit PCM（リトルエンディアン）|
|`.16b`|signed 16bit PCM（ビッグエンディアン）|
|`.ayb`|YM2608互換 4bit ADPCM（ニブルは上位から下位）|
|`.amb`|OKI互換 4bit ADPCM（ニブルは上位から下位）|
|`.aml`|OKI互換 4bit ADPCM（ニブルは下位から上位）|
|`.dpc`|FC互換 DPCM|

拡張子は、Ｖ３ＭＭＬがデータの種別を判別するために使用します。  
実際のデータ形式と異なる拡張子を付けると、正しく展開されません。

規定外の拡張子を書いた場合は、バインド時に次のエラーで停止します。

```
[v3mmlBind: error] 拡張子が規定（u08/s08/16l/16b/ayb/amb/aml/dpc）外です:ファイル名
```

[（各形式の詳細とは）](6_59.md)

### 【備考】16bit PCM の WAV について

一般的な 16bit PCM の WAV は、signed 16bit PCM のリトルエンディアンです。  
ただし、たいていはステレオであるため、モノラル化してからＲＡＷデータとして書き出す必要があります。

## 【スクリプト】

```bash
#!/bin/bash
#V3MML バイナリファイル バインダー

v_listName="__v3mmlBindList.txt"
v_tempName=""
v_doneMsg=""

function cleanUp() {
    #作業用ファイルを削除する
    if [ -n "$v_tempName" ]; then
        rm -f "$v_tempName"
    fi
}

function progressAdd() {
    #完了した処理を記録する
    if [ -z "$v_doneMsg" ]; then
        v_doneMsg="  $1"
    else
        v_doneMsg="$v_doneMsg
  $1"
    fi
}

function errorExit() {
    echo "$1"
    if [ -n "$v_doneMsg" ]; then
        echo "[v3mmlBind: ここまでは正常に終わっています]"
        echo "$v_doneMsg"
    else
        echo "[v3mmlBind: 正常に終わった処理はありません]"
    fi
    echo "returnキーを押してください"
    read -r varWait
    exit 1
}

trap cleanUp EXIT

#スクリプトの置き場所へ移動
MY_DIRNAME=$(dirname "$0")
cd "$MY_DIRNAME" || errorExit "[v3mmlBind: error] 作業フォルダへ移動できません:$MY_DIRNAME"
progressAdd "作業フォルダへ移動：$(pwd)"

#バインドリスト（__v3mmlBindList.txt）存在確認
if [ ! -f "$v_listName" ]; then
    errorExit "[v3mmlBind: error] $v_listName が見つかりません"
fi

#バインドリスト読み込み：バイナリ作成用の配列作成
v_file_arr=()
v_fileSize_arr=()
v_fileExt_arr=()
v_listCount=0

while IFS= read -r v_line || [ -n "$v_line" ]
do
    #行末のCRを除去
    v_line=${v_line%$'\r'}

    #空行とコメント行（先頭が#）は読み飛ばす
    case "$v_line" in
        "" | "#"* ) continue ;;
    esac

    v_Ext=${v_line##*.}

    if [ "$v_listCount" -eq 0 ]; then
        #最初のファイル名は書き出しファイル名
        v_outDir=$(dirname "$v_line")
        if [ ! -d "$v_outDir" ]; then
            errorExit "[v3mmlBind: error] 書き出し先のフォルダがありません:$v_outDir"
        fi
        v_file_arr[0]="$v_line"
        v_fileSize_arr[0]=0
        v_fileExt_arr[0]="$v_Ext"
    else
        #２個目以降は読み込みファイル名
        if [ ! -f "$v_line" ]; then
            errorExit "[v3mmlBind: error] 次のリスト内ファイルが見つかりません:$v_line"
        fi
        case "$v_Ext" in
            u08 ) ;;
            s08 ) ;;
            16l ) ;;
            16b ) ;;
            ayb ) ;;
            amb ) ;;
            aml ) ;;
            dpc ) ;;
            * ) errorExit "[v3mmlBind: error] 拡張子が規定（u08/s08/16l/16b/ayb/amb/aml/dpc）外です:$v_line" ;;
        esac
        v_file_arr[$v_listCount]="$v_line"
        v_fileSize_arr[$v_listCount]=$(stat -f%z "$v_line")
        v_fileExt_arr[$v_listCount]="$v_Ext"
    fi
    v_listCount=$((v_listCount+1))
done < "$v_listName"

if [ "$v_listCount" -lt 2 ]; then
    errorExit "[v3mmlBind: error] $v_listName 内のファイル数不足：少なくとも１つの出力ファイル名と１つの読み込みファイル名が必要です"
fi

v_dataCount=$((v_listCount-1))
progressAdd "リスト読み込み：読み込みファイル $v_dataCount 個"

#作業用ファイル作成（既存ファイルを上書きしない一意な名前）
v_tempName=$(mktemp "./__v3mmlBindTemp.XXXXXXXX") || errorExit "[v3mmlBind: error] 作業用ファイルを作成できません"
progressAdd "作業用ファイル作成：$v_tempName"

#1st Chunk:固定ヘッダ出力:keyStr(16),2ndChunkTop(4),3rdChunkTop(4),reserved(8)
v_gap=32
v_2ndTop=32
v_3rdTop=$(((v_dataCount*16)+v_2ndTop+v_gap))

v_keyHex=$(printf '%s' "V3MML...20220624" | xxd -p) || errorExit "[v3mmlBind: error] 第１チャンクの認識用ヘッダーを作れません"
printf '%s\n' "$v_keyHex" >"$v_tempName" || errorExit "[v3mmlBind: error] 第１チャンクを書き出せません:$v_tempName"
printf '%08x%08x%016x\n' "$v_2ndTop" "$v_3rdTop" 0 >>"$v_tempName" || errorExit "[v3mmlBind: error] 第１チャンクを書き出せません:$v_tempName"
progressAdd "第１チャンク（固定ヘッダ）：書き出し完了"

#2nd Chunk:可変ヘッダ出力
v_allocPt=0
v_index=1
while [ "$v_index" -le "$v_dataCount" ]
do
    if ! printf '%08x%08x%08x' "$v_allocPt" "${v_fileSize_arr[$v_index]}" 0 >>"$v_tempName"; then
        progressAdd "第２チャンク（アロケーションテーブル）：$((v_index-1)) 個 書き出し完了"
        errorExit "[v3mmlBind: error] 第２チャンクの $v_index 個目を書き出せません:${v_file_arr[$v_index]}"
    fi
    v_extHex=$(printf '.%s' "${v_fileExt_arr[$v_index]}" | xxd -p)
    if ! printf '%s\n' "$v_extHex" >>"$v_tempName"; then
        progressAdd "第２チャンク（アロケーションテーブル）：$((v_index-1)) 個 書き出し完了"
        errorExit "[v3mmlBind: error] 第２チャンクの $v_index 個目を書き出せません:${v_file_arr[$v_index]}"
    fi
    v_allocPt=$((v_allocPt+v_fileSize_arr[v_index]+v_gap))
    v_index=$((v_index+1))
done
#GAP書き出し
printf '%032x\n%032x\n' 0 0 >>"$v_tempName" || errorExit "[v3mmlBind: error] 第２チャンクの区切り領域を書き出せません:$v_tempName"
progressAdd "第２チャンク（アロケーションテーブル）：$v_dataCount 個 書き出し完了"

#3rd Chunk:バイナリデータ出力
v_index=1
while [ "$v_index" -le "$v_dataCount" ]
do
    #バイナリ実体
    if ! xxd -p "${v_file_arr[$v_index]}" >>"$v_tempName"; then
        progressAdd "第３チャンク（実データ群）：$((v_index-1)) 個 書き出し完了"
        errorExit "[v3mmlBind: error] 第３チャンクの $v_index 個目を書き出せません:${v_file_arr[$v_index]}"
    fi
    #GAP書き出し
    if ! printf '%032x\n%032x\n' 0 0 >>"$v_tempName"; then
        progressAdd "第３チャンク（実データ群）：$((v_index-1)) 個 書き出し完了"
        errorExit "[v3mmlBind: error] 第３チャンクの $v_index 個目の区切り領域を書き出せません:${v_file_arr[$v_index]}"
    fi
    v_index=$((v_index+1))
done
progressAdd "第３チャンク（実データ群）：$v_dataCount 個 書き出し完了"

#バイナリファイル作成
if ! xxd -r -p "$v_tempName" "${v_file_arr[0]}"; then
    errorExit "[v3mmlBind: error] バイナリファイルへ変換できません:${v_file_arr[0]}
（書き出し途中のファイルが残っている場合があります）"
fi

#正常終了
echo "[v3mmlBind: 正常終了] ${v_file_arr[0]} を書き出しました"
echo "returnキーを押してください"
read -r varWait
```

### 【備考】スクリプトが書き出す内容

スクリプトは、次の順に１６進数のテキストを組み立て、最後に `xxd -r -p` でバイナリへ戻しています。

- 第１チャンクの固定ヘッダ（32バイト）
- 第２チャンクのアロケーションテーブル（読み込みファイル１個につき16バイト）
- 第３チャンクの実データ群

各チャンクの区切りと、実データの間には、32バイトのゼロ埋め領域が挿入されます。この領域の分も含めた位置が、第２チャンクのアロケーション開始位置として記録されます。
