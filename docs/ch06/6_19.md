# 6.19 `@mhz`：@@"fms"用：ＨＬＦＯ無効

[← 目次](../index.md)

## 【記述例】

```mml
@mhz
```

## 【解説】

ＦＭ音源モジュール（@@"fms"）用の、ＨＬＦＯ（Hardware Low Frequency Oscillator）機能を無効に設定します。

ＨＬＦＯ機能が無効になると、ＦＭ音源の動作がその分軽くなります。  
トラック開始時の初期設定では、ＨＬＦＯ機能は無効になっています。

ＨＬＦＯ機能が無効の状態では、`y`コマンドを使用して直接ＨＬＦＯパラメータ設定を行っても動作しないので注意してください。

ＨＬＦＯ機能を利用する場合、`@mh`コマンド または `@mha`コマンド を使用すると、必ずＨＬＦＯ機能が有効化されますので、有効無効の状態を気にせずＨＬＦＯ機能が使用できます。
