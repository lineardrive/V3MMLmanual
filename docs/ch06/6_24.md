# 6.24 `@oa[1]`：オペレータ振幅の自動調整

[← 目次](../index.md)

## 【記述例】

```mml
@oa1
```

上記のように書くと、振幅調整を行い、レベルオーバーを防ぎます。

## 【解説】

オペレータ振幅の自動調整の対象となるのは、次の音源モジュールです。

```
@@"sin"
@@"saw"
@@"tri"
@@"pls"
@@"cpx"
@@"wvm"
```

上記の音源モジュールのいずれかが選択されている場合に、有効になっているオペレータ数や各オペレータのdB設定に応じて、レベルオーバーを防ぐ振幅調整を行うか否かを設定します。  
トラック先頭における初期設定は、`@oa1`です。

- `@oa1`の場合、振幅調整を行い、レベルオーバーを防ぎます。
- `@oa0`の場合、振幅調整を行いません。

### 【備考】

振幅調整の具体的な処理は、複数オペレータ有効時に、各オペレータの振幅倍率の合計を、振幅の分母に設定する処理です。

```
m_ampDenom = m_op[0].op_amp +
             m_op[1].op_amp +
             m_op[2].op_amp ...
```
