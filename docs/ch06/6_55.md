# 6.55 ＦＭ音源６オペレータモードの接続形態

[← 目次](../index.md)

６オペレータモードの音色設定における、  
`CON`（connection：オペレータの接続パターン）  
の内容を示します。

対象となる音色定義は、次の通りです。

```
#MB:FMS_6OP
```

以下に、`CON`番号ごとの接続図を示します。

「out」は音声出力です。  
色が白のオペレータがモジュレータです。  
色がオレンジのオペレータがキャリアです。  
キャリアが複数ある`CON`では、コーラスや和音の効果を出すことも可能です。

全てのオペレータにセルフフィードバック機能があります。

６オペレータモードの `CON` は、0〜63 で指定します。
