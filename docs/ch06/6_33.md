# 6.33 `@c[1]`：ＰＣＭ音源の補間モード設定

[← 目次](../index.md)

## 【記述例】

```mml
@c1
```

上記のように書くと、ＰＣＭ再生が１次補間（線形補間）モードになります。

## 【解説】

対象となる音源モジュール、@@"pcm" が選択されている場合に、
ＰＣＭ再生の補間モードを設定します。

- @c0の場合、０次補間を行います。（前回値で補間）
- @c1の場合、１次補間を行います。（線形補間）
- @c2の場合、４点のガウス補間を行います。

トラック先頭における初期設定は、`@c1` です。  
0 〜 2 の範囲外を指定するとエラーになります。

### `@c2`（４点のガウス補間）

補間する点の前後の、再生する順に並んだ４つのサンプルに、ガウス関数（ベル形の曲線。幅 σ = 0.57 サンプル）の重みを掛けて足し、重みの合計で割ります。  
σ は固定で、変えることはできません。

- 線形補間（`@c1`）に比べて、補間する点の位置による高い音域の削れ方の揺れが小さく、音程を変えて鳴らしたときのザラつき（微小なノイズ）が少なくなります。
- その代わり、高い音域は少し丸くなります（元の波形のサンプリング周波数の 0.3 倍の周波数で、およそ -4.4 〜 -5.7 dB）。
- 補間した値は、元のサンプルの値を通りません（サンプルの真上でも、両隣の値を混ぜます）。
- 一定の値が続く波形は、その値のまま出ます（重みの合計で割るため）。
- ループのつなぎ目、逆再生、ループしない波形の終わり（最後のサンプルの値を保つ）は、`@c0` / `@c1` と同じ並びで補間します。
- 音の頭では、音の前を無音とみなします。
- 計算の手間は `@c1` より大きくなりますが、曲全体の書き出しの時間ではほとんど差が出ない程度です。

### 表示

KeyDisp と、ＭＭＬステータス表示（`!s`）には、`@c2` のように表示されます。
