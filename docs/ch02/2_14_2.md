# 2.14.2 `type=12_TET_trunc` のとき（１２平均律）

[← 目次](../index.md)

## 【記述例】

```mml
#MB:PITCH_SCALE ps=2 {
   type = 12_TET_trunc,  //@dの小数点以下を0方向へ丸める。
   base_note = 57,
   base_freq = 440.0,
   halftone_reso = 100,
}
```

## 【解説】

基本的に、`type=12_TET` の時とほぼ同様です。  
違いは次の通りです。
- `type=12_TET` の場合、`@d`コマンドで指定されるデチューン値の小数点以下の丸め処理は行いません。
- `type=12_TET_trunc` の場合、`@d`コマンドで指定されるデチューン値の小数点以下を、０方向へ丸める処理がなされます。
