# 2.6 音程番号表

[← 目次](../index.md)

## 【解説】

Ｖ３ＭＭＬでは、音程に番号を振って、音程番号を管理しています。

オクターブ０の「c（ド）」の音を０番とし、半音上がるごとに番号が１増えることとしています。

初期設定では、オクターブ４の「a（ラ）」の音に440Hzの周波数を割り当てて、それを基準に他の音程には１２平均律に従った周波数を割り当てています。
