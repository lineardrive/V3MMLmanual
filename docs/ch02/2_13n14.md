# 2.13 `ps[1]`：ピッチスケール
# 2.14 `#MB:PITCH_SCALE`：ピッチスケール定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:PITCH_SCALE ps=1 {
   type = 12_TET,        //12 tone equal temperament
   base_note = 57,
   base_freq = 440.0,
   halftone_reso = 100,
}
ps1 cdefg;
```

上記のように書くと、

- `#MB:PITCH_SCALE` により、定義番号１番にピッチスケール内容を定義。この場合、`o4 a` に 440Hzを割り当てて、それ以外を１２平均律で計算します。
- `ps1`によって、定義番号１番の `#MB:PITCH_SCALE` の内容を適用。

といった定義と適用を記述できます。

## 【解説】

### ピッチスケールコマンド（ps[1]）：  

音程名または音程番号から発音周波数を算出する方式を、選んで適用します。  
トラック先頭における初期設定は次の通りです。

```mml
type = 12_TET,
base_note = 57,
base_freq = 440.0,
halftone_reso = 100,
```

`ps`コマンドの 引数[1] には、ピッチスケール定義番号を、0 〜 999 の整数で指定します。

`ps`コマンドは、本来、曲の頭で設定するものです。曲の途中で切り替えるときは、副作用があります。次の点に注意してください。

- `ps`コマンドの直後は、休符を書かず、音符を書いてください。  
休符の間に前の音のリリースが残っていると、そのリリースが、でたらめな周波数で鳴ることがあります。  
音程番号は音符を書いた時点のピッチスケールで作られていて、切り替えた後の計算方法では正しく読めないためです（ピッチＬＦＯなどで周波数を計算し直したときに表れます）。  
`ps`コマンドと音符の間に、時間の進まないコマンド（`@d` など）を挟むのは構いません。
- スラー（`&`）の最中は、`ps`コマンドを使えません（エラーになります）。
- オートポルタメント（`@ap`、[2.19](2_19.md)）が有効な間は、`ps`コマンドを使えません（エラーになります）。先に `@apz` で止めてから切り替えます。
- `ps`コマンドで切り替えると、オートポルタメントの始点になる「直前に鳴った音符の音程番号」は、トラック開始時の値（`o0c`、音程番号 0）に戻ります。
- デチューン（`@d`）の値と、ピッチＬＦＯ（`@lp`・`@lq`）の深さは、そのときのピッチスケールの単位で読まれます。数値は書き直されないので、`ps`コマンドで切り替えたら、`@d`・`@lp`・`@lq` も書き直してください。
- ポリフォニックモードでは、`ps` は次のノートオンからその発音チャネルに効きます。`@dlv"ps","all"`（[9.3](../ch09/9_3.md)）で、すべての発音チャネルにすぐ配ることもできます。

### ピッチスケール定義（#MB:PITCH_SCALE）：

`ps`コマンドで使用する、ピッチスケールパターンを定義します。

定義方法の概要は次の通りです。
- 行頭からの記述で、キーワード `#MB:PITCH_SCALE` を書く。
- 続けて、スペースを置き、`ps=定義番号` を書く。
- 続けて、スペースを置き、中括弧 `{ }` で括られた`パターンデータ`を書く。

パターンデータの開始は `{` で認識され、終了は `}` で検知されます。

パターンデータの各パラメータは、カンマ区切りで記述します。スペースや改行は読み飛ばされます。（最後のパラメータの後にカンマがあっても可）

#### 定義番号：

定義番号は、`ps`コマンドの引数で使用する番号と合致するように定義します。  
定義番号の設定範囲は 0 〜 999 です。  
`#MB:PITCH_SCALE` の定義は 512 個までです。超えるとエラーになります。

#### パターンデータ：

パターンデータのフォーマットは、まず最初のパラメータで指定する種別定義 `type=...` で変わります。種別定義が必ず先頭で行われる必要があります。詳しくは`2.14.1`以降で解説します。

#### 【テーブルの文字列前処理】

`#MB:PITCH_SCALE` の「`|`」で区切られた後の値の並び（`type=f_number` 以降）には、くり返しや数列を書く命令（`[R:…]` `[MW:…]` `[MR:…]` `[S…:…]`）を使えます。  
[5.14 テーブルの文字列前処理](../ch05/5_14.md) を参照してください。
