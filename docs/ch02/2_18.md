# 2.18 `_`：ポルタメント

[← 目次](../index.md)

## 【記述例】

```mml
c_>c4
```

上記の場合、ドからオクターブ上のドまで４分音符の長さで滑らかに変化させます。

```mml
c1&c_>c4&c2.
```

上記の場合、ドを全音符で鳴らした後、オクターブ上のドまで４分音符の長さで滑らかに変化させ、その後付点２分音符の長さで音程を維持します。

```mml
c_>c1&1&1&1
```

上記の場合、全音符４つ分の長さで、ドからオクターブ上のドまで滑らかに変化させています。  
全音符以上の長さで変化をさせたい場合はタイ（音長の延長）で実現できます。

```mml
c_<c4_>c4
```
上記のような記述は出来ません。エラーになります。

## 【解説】

ポルタメント（音程の滑らか変化）です。  
音名を `_` で繋げるとポルタメントになります。  
ピッチスケールが１２平均律モードの場合に使用できます。

## 【注】

### テンポ変更との関係

ポルタメントの変化に要する時間は、テンポ変更（`t`コマンド）に追従しません。  
滑っている途中でテンポを変えても、目標音程に到達するまでの実時間は変わりません。

### 次のノートオンとの関係

目標音程に到達しないうちに次のノートオンが発生した場合、前の音符に属するポルタメントは、その時点で打ち切られます。  
滑り残りが次の音符に持ち越されることはありません。

タイ・スラーの継続部分（`&` で繋がれた、ノートオンを伴わない部分）は、ここでいう「次のノートオン」には当たりません。

### オートポルタメントとの関係

`_` によるポルタメントと、オートポルタメント（`@ap`）は、同時に掛けることができます。  
両方が掛かっている音符では、それぞれの音程変位が合計されます。優先順位や取り合いは発生しません。
