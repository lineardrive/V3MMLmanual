# 2.18 `_`：ポルタメント

[← 目次](../index.md)

## 【記述例】

```mml
c_>c4
```

上記の場合、ドからオクターブ上のドまで４分音符の長さで滑らかに変化させます。

```mml
c1&c_>c4&c2.
```

上記の場合、ドを全音符で鳴らした後、オクターブ上のドまで４分音符の長さで滑らかに変化させ、その後付点２分音符の長さで音程を維持します。

```mml
c_>c1&1&1&1
```

上記の場合、全音符４つ分の長さで、ドからオクターブ上のドまで滑らかに変化させています。  
全音符以上の長さで変化をさせたい場合はタイ（音長の延長）で実現できます。

```mml
c_<c4_>c4
```
上記のような記述は出来ません。エラーになります。

## 【解説】

ポルタメント（音程の滑らか変化）です。  
音名を `_` で繋げるとポルタメントになります。  
ピッチスケールが１２平均律モードの場合に使用できます。
