# 2.10 `r`：休符

[← 目次](../index.md)

## 【記述例】

```
l16 c4 r d8 r8 r.
```

上記のように書くと、`r` は１６分休符、`r.` は付点１６分休符になります。

```
c4 r2&8 c4
```

上記のように書くと、２分休符を８分休符延長しています。

```
c64 r8^64 c4
```

上記のように書くと、８分休符を６４分休符短縮しています。

```
c4 r8&r8 c4
```

上記のように書くと、エラーとなります。

## 【解説】

直前までノートオンされていればノートオフし、音符同様の長さ指定に従って休符が実行されます。  
休符でも音符のように、長さの延長 `&` や、短縮 `^` が出来ます。  
ただし、スラー `r4&r4` の記述はエラーとなります。

休符は、大文字 `R` による記述でも小文字同様に機能します。
