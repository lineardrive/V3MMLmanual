# 2.10 `r`：休符

[← 目次](../index.md)

【記述例】
この場合、「r」は１６分休符、「r.」は付点１６分休符になります。

この場合、２分休符を８分休符延長しています。

この場合、８分休符を６４分休符短縮しています。

この場合、エラーとなります。
【解説】
直前までノートオンされていればノートオフし、音符同様の長さ指定に従って休
符が実行されます。
休符でも音符のように、長さの延長（&）や、短縮（^）が出来ます。
ただし、スラー（r4&r4）の記述はエラーとなります。
休符は、大文字（R）による記述でも小文字同様に機能します。
```
l16 c4 r d8 r8 r.
c4 r2&8 c4
c64 r8^64 c4
c4 r8&r8 c4
```
