# 2.18. _：ポルタメント

[← 目次](../V3MML_TOC.md)

【記述例】

ドからオクターブ上のドまで４分音符の長さで滑らかに変化させます。

ドを全音符で鳴らした後、オクターブ上のドまで４分音符の長さで滑らかに変化
させ、その後符点２分音符の長さで音程を維持します。

全音符以上の長さで変化をさせたい場合はタイ（音長の延長）で実現できます。
この例では、全音符４つ分の長さで、ドからオクターブ上のドまで滑らかに変化
させています。
＜次のような記述は出来ません＞

この場合はエラーになります。
【解説】
ポルタメント（音程の滑らか変化）です。
音名を _ で繋げるとポルタメントになります。
ピッチスケールが１２平均律モードの場合に使用できます。
```mml
c_>c4
c1&c_>c4&c2.
c_>c1&1&1&1
c_<c4_>c4
```
