# 2.14.1 `type=12_TET` のとき（１２平均律）

[← 目次](../index.md)

## 【記述例】

```mml
#MB:PITCH_SCALE ps=1 {
   type = 12_TET,        //12 tone equal temperament
   base_note = 57,
   base_freq = 440.0,
   halftone_reso = 100,
}
```

この例では、オクターブ４の `a` に440Hzを割り当て、それを基準にした１２平均律を定義しています。

## 【解説】

フォーマットは次の通りです。

```mml
#MB:PITCH_SCALE ps=定義番号 {
   type=12_TET,
   base_note=[],
   base_freq=[],
   halftone_reso=[],
   auto_portamento=[],   （省略可能）
}
```

---

### `base_note`：

基準になる音程番号を整数で指定します。（[音程番号とは](2_6.md)）  
設定可能範囲は、0 〜 119 です。

---

### `base_freq`：

基準になる音程に割り当てる周波数を指定します。  
小数点以下の指定も受け付けます。  
設定結果、`o4a` に割り当たる周波数が 195Hz 〜 988Hz の範囲外の場合は、エラーになります。

---

### `halftone_reso`：

`@d`コマンドで指定する値を、半音を何分割した単位にするかを設定します。  
100分割を指定した場合、`@d1`とすると、１セント上げる設定になります。

---

### `auto_portamento`：

オートポルタメント（`@ap`コマンド）の、音程変化のさせ方の型名を指定します。  
この項目は省略可能です。省略した場合は `auto_portamento = linear_duration` が指定されたものとみなされます。

設定できる型名は次の５つです。それ以外の名称を書くとエラーになります。

|型名|変化のカーブ|
|:-|:-|
|`linear_duration`|直線（到達までの時間で指定）|
|`linear_duration_per_oct`|直線（１オクターブあたりの時間で指定）|
|`root2nd_duration`|平方根カーブ|
|`pow2nd_duration`|２乗カーブ|
|`sys2lv`|機種互換の漸化式 (type:sys2lv)|

※型名にダブルクォーテーションは付けません。  
※この項目を記述できるのは、`type=12_TET` と `type=12_TET_trunc` の場合だけです。

詳細は [`@ap`：オートポルタメント](2_19.md) を参照してください。
