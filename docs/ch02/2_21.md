# 2.21 `@apz`：オートポルタメント停止

[← 目次](../index.md)

## 【記述例】

```mml
@ap100 cdefgab>c
@apz cdefgab>c
```

上記の場合、`@apz` 以降の音符は滑らなくなります。

## 【解説】

オートポルタメント（`@ap`・`@ap%`、[2.19](2_19.md)）を停止します。  
トラック先頭における初期設定は、`@apz`（停止）です。

次の３つは、いずれも同じ「停止」の意味になります。

```mml
@apz        @ap0        @ap%0
```

- 停止は「その音符だけ滑らない」ではなく、「以降のすべての音符が滑らなくなる」という意味です。再び滑らせるには、`@ap` を記述し直します。
- `@apz` を書いた時点で滑っている途中の音は、そのまま目標まで滑ります。次のノートオンから滑らなくなります。
- `@ap` 側と `@ap%` 側の両方が停止します。
- 引数[2]（始点の音程番号）の差し替えも取り消されます。
- スラーの扱い（`@aps`、[2.20](2_20.md)）は `0` に戻りません。
- `@apz` を書いた後に `@ap#`・`@ap%#` と書くと、`#` は `0`（停止）になります。

ピッチスケール（`ps`、[2.13](2_13n14.md)）は、オートポルタメントが有効な間は切り替えられません。先に `@apz` で止めてから切り替えます。

`@apz`コマンドは時間を消費しません。

## 【エラー】

- `@apz%` と書いた：停止に単位はありません。

```
@apz に % は付けられません（停止に単位はありません）。
```

---

## 【表示】

### KeyDispへの表示：

停止している間は、`@ap` は表示されません。

### `!c` への表示：

ＭＭＬステータス表示（`!c`）では、`@ap` 側と `@ap%` 側が、それぞれ `@apz` と `@ap%0` と表示されます。（[2.19](2_19.md)）
