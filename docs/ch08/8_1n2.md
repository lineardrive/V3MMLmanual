# 8.1 `@loc[str],[1]`：ＬＦＯオプション CLOCK
# 8.2 `@lor[str],[1]`：ＬＦＯオプション RESOLUTION

[← 目次](../index.md)

## 【記述例】

```mml
#MB:ENV_A @ea=1 { peak=15, init=& | n:0:15, r:1:0 }
#MB:LFO_P @lp=1 { depth=400, width=24, delay=48, form=sin }

t120 q12,16 v15 @@"pls" o5 @ea1
@loc"sec",1/90
@lor"sec",1/600
@lp1 c1&2;
```

## 【解説】

ＬＦＯ全種類への、オプション設定を行います。

- `@loc[str],[1]`
- `@lor[str],[1]`

上記のコマンドは、次の `#MB:CONFIG {...}` による設定を、トラックごとに変更したい場合に使用します。

```mml
#MB:CONFIG {
   lfo_clock: unit=sec: rate=1/60,
   lfo_resol: unit=sec: rate=1/300,
}
```

---

### `@loc[str],[1]`

ＬＦＯ全種類への、時間単位を設定します。  
時間単位は、width の周期時間と、delay に影響します。

指定する引数は次の通りです。

- 引数[str]：時間単位
- 引数[1]：時間単位への倍率

引数はカンマで区切って指定します。

#### 引数[str]が、`"sec"` だったとき

時間単位が「１秒」になります。  
引数[1]の設定範囲は、1/3000[秒] 〜 1.0[秒] です。

#### 引数[str]が、`"tick"` だったとき

時間単位は「１tickカウント」になります。  
引数[1]の設定範囲は、０より大きい値です。  
ただし、最小は1/3000[秒]に制限されます。

---

### `@lor[str],[1]`

ＬＦＯ時間軸の解像度（ＬＦＯ変位計算の最小時間単位）を設定します。  
この設定が有効になる対象は、次の３種類です。

- ピッチＬＦＯ
- `y`コマンドＬＦＯ
- フィルタＬＦＯ

```
ＬＦＯ解像度は、ポルタメント機能による周波数変更の最小時間単位にもなっています。
```

指定する引数は次の通りです。

- 引数[str]：解像度の時間単位
- 引数[1]：解像度の時間単位への倍率

引数はカンマで区切って指定します。

#### 引数[str]が、`"sec"` だったとき

解像度の時間単位が「１秒」になります。  
引数[1]の設定範囲は、1/3000[秒] 〜 1.0[秒] です。

#### 引数[str]が、`"tick"` だったとき

解像度の時間単位は「１tickカウント」になります。  
引数[1]の設定範囲は、０より大きい値です。  
ただし、最小は1/3000[秒]に制限されます。

#### 引数[str]が、`"clock"` だったとき

解像度の時間単位は「ＬＦＯクロック（`@loc` / `lfo_clock`）の１単位」になります。  
引数[1]の設定範囲は、０より大きい値です。  
区切り（ＬＦＯの値を書き換える間隔）の長さは「引数[1] × ＬＦＯクロックの１単位」で、区切りの位置は音符の頭から数えた絶対位置で決まります。長い音符でも区切りのずれがたまりません。  
詳しくは「5.8.7 `lfo_resol`」の【備考４】を参照してください。

```mml
@loc"tick",1 @lor"clock",1/4     /* １tickを４回に分けて更新する */
```

---

### 【備考】

時間単位が「１tickカウント」の場合、テンポにより時間単位が変動します。

テンポが変わっても、いま進んでいる区切りは最後まで進み、次の区切りから新しい長さになります（区切りの途中で切り直すことはありません）。`@loc` / `@lor` を書いた場合は、その位置から新しい区切りで数え直します。
