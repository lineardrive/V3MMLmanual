# 8.14 `@l*r`：ＬＦＯの再スタート

[← 目次](../index.md)

【記述例】

【解説】
指定のＬＦＯシーケンスを再スタートさせます。
スラー途中でＬＦＯを再スタートさせる場合や、ＬＦＯのノートオン非同期モー
ドで、任意のタイミングで再スタートさせる場合などの使用を想定しています。
```mml
@lpr
@lpr
```
ピッチＬＦＯを再スタートさせます。
```mml
@lar
```
音量ＬＦＯを再スタートさせます。
```mml
@lbr
```
パンポットバランスＬＦＯを再スタートさせます。
```mml
@lfr
```
フィルタＬＦＯを再スタートさせます。
```mml
@lyr
```
yコマンドＬＦＯを再スタートさせます。
