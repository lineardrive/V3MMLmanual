# 8.14 `@l*r`：ＬＦＯの再スタート

[← 目次](../index.md)

## 【記述例】

```mml
@lpr
```

## 【解説】

指定のＬＦＯシーケンスを再スタートさせます。  
スラー途中でＬＦＯを再スタートさせる場合や、ＬＦＯのノートオン非同期モードで、任意のタイミングで再スタートさせる場合などの使用を想定しています。

|コマンド|ＬＦＯ再スタートさせる宛先|
|:-:|:-|
|@lpr|ピッチＬＦＯを再スタートさせます。|
|@lar|音量ＬＦＯを再スタートさせます。|
|@lbr|パンポットバランスＬＦＯを再スタートさせます。|
|@lfr|フィルタＬＦＯを再スタートさせます。|
|@lyr|yコマンドＬＦＯを再スタートさせます。|
