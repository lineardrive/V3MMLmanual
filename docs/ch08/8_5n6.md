# 8.5 `@lq[1]`：ピッチＬＦＯ（２本目）
# 8.6 `#MB:LFO_Q`：ピッチＬＦＯ（２本目）定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   lfo_clock: unit=sec: rate=1/120,
   lfo_resol: unit=clock: rate=1,
}
#MB:LFOTBL_ATK 1 {
   loop=-1, cmpl=0, offset=0, denom=1, width_mode=step, |
   0, 40, 80, 60, 40, 20, 0,
}
#MB:ENV_A @ea=1 { peak=15, init=& | n:1:15, r:1:0 }
#MB:LFO_P @lp=1 { depth=1,   width=2, delay=0, form=table, tbl_atk=1 }
#MB:LFO_Q @lq=1 { depth=60, width=16, delay=100, form=sin,
                  dp_seq_ini=0,  dp_seq_dur=171, dp_seq_form=saw_os,
                  wd_seq_ini=64, wd_seq_dur=256, wd_seq_form=saw_os }
t120 q16,16 v15 @@"pls" o5 @ea1
@lp1 @lq1 c1&1
```

上記のように書くと、１本目のピッチＬＦＯ（`@lp`）でテーブルによる音程の動きを付けながら、２本目のピッチＬＦＯ（`@lq`）でビブラートを重ねられます。  
２本目のビブラートは、キーオンから 100 単位（1/120 秒 × 100）は振れず、そこから深さが 0 から 60 まで 171 単位かけて増え、同時に速さが「１周 64 単位」から「１周 16 単位」まで 256 単位かけて速くなります。

## 【解説】

### ピッチＬＦＯ（２本目）コマンド（`@lq[1]`）：

ピッチＬＦＯ（２本目）定義（`#MB:LFO_Q`）の定義番号を整数で指定します。  
定義番号は 0 〜 9999 の整数です。  
未定義の番号を指定するとエラーになります。  
トラック先頭における初期設定では、ピッチＬＦＯ（２本目）は停止状態です。

２本目のピッチＬＦＯは、１本目のピッチＬＦＯ（`@lp`）と同時に掛けられます。最終的な音程には、１本目と２本目の変位の和が加わります。

２本目は１本目とまったく同じ働きをします（使える `form`、各要素の意味、時間の単位、制限、エラーが同じです）。そのうえで、２本目だけは深さと速さを時間とともに変えられます（下記の `dp_seq_*` / `wd_seq_*`）。

１本目と２本目は、互いに独立しています。

- ディレイの数え方、位相、テーブル番号（`@lqt` と `@lpt`）は別々に持ちます。
- 停止（`@lqz`）と再スタート（`@lqr`）は、２本目だけに効きます。
- 定義番号の空間も `#MB:LFO_P` とは別です（`@lp=1` と `@lq=1` は別の定義です）。
- 定義の個数も `#MB:LFO_P` とは別に数え、1024 個までです。

関連するコマンドは次の通りです。

|コマンド|働き|
|:-|:-|
|`@lq[1]`|２本目のピッチＬＦＯを、指定の定義番号にします。|
|`@lqz`|２本目のピッチＬＦＯを停止状態にします。（[8.15](8_15.md)）|
|`@lqr`|２本目のピッチＬＦＯを再スタートさせます。深さ・速さの時間変化も先頭に戻ります。（[8.16](8_16.md)）|
|`@lqt[1],[2]`|２本目のピッチＬＦＯで使用中の、ユーザー定義テーブル番号を変更します。（[8.17](8_17.md)）|
|`xa"@lq",[1]`|２本目のピッチＬＦＯの定義番号に加算します。（[10.1](../ch10/10_1.md)）|
|`ym"lqsin",...` など|２本目のピッチＬＦＯの波形モジュールを制御します。宛先名は `lqsin` / `lqsaw` / `lqtri` / `lqpls` / `lqnzw` / `lqtbl` / `lqnlb` です。（[6.35](../ch06/6_35.md)）|

`ps` で選んだ音程の方式が WSG（`steprate_mode1` / `steprate_mode2`）のときは、１本目と同じく `form=table` だけが使えます。２本目のテーブルの値も、１本目に続けて音程に積み上げられます。

### ピッチＬＦＯ（２本目）定義（`#MB:LFO_Q`）：

`@lq[1]` で使用する、ピッチＬＦＯ（２本目）の設定を定義します。  
書き方は `#MB:LFO_P` と同じで、キーワードを「`#MB:LFO_Q`」、定義番号の前を「`@lq=`」にします。

```
#MB:LFO_Q @lq=定義番号 {
   depth=[], width=[], delay=[], form=[],
   st_phase=[], pwm=[], tbl_atk=[], tbl_rel=[], bendrate=[],   （#MB:LFO_P と同じ）
   dp_seq_ini=[], dp_seq_dur=[], dp_seq_form=[],   （省略可能：深さの時間変化）
   wd_seq_ini=[], wd_seq_dur=[], wd_seq_form=[],   （省略可能：速さの時間変化）
}
```

`depth` / `width` / `delay` / `form` ほか、`#MB:LFO_P` と共通の要素の意味は「[8.4 `#MB:LFO_P`](8_3n4.md)」を参照してください。

---

#### 要素 `dp_seq_ini` / `dp_seq_dur` / `dp_seq_form`（深さの時間変化）：

深さを、初期値から `depth` の値（目標値）へ、時間とともに変えます。

|項目|意味|
|:-|:-|
|`dp_seq_ini=[]`|深さの初期値。単位は `depth` と同じ。負数も書けます。|
|`dp_seq_dur=[]`|変化の時間。単位は `delay` / `width` と同じ（ＬＦＯクロック）。|
|`dp_seq_form=[]`|変化の形。`saw_os` / `saw` / `tri` のどれか。|

３つは１組です。どれか１つを書いたら、残りの２つも書いてください。

---

#### 要素 `wd_seq_ini` / `wd_seq_dur` / `wd_seq_form`（速さの時間変化）：

速さを、`wd_seq_ini` で表した速さから、`width` で表した速さ（目標値）へ、時間とともに変えます。

|項目|意味|
|:-|:-|
|`wd_seq_ini=[]`|速さの初期値を、`width` と同じ単位・同じ意味の値で書いたもの。0 より大きい値。|
|`wd_seq_dur=[]`|変化の時間。単位は `delay` / `width` と同じ（ＬＦＯクロック）。|
|`wd_seq_form=[]`|変化の形。`saw_os` / `saw` / `tri` のどれか。|

３つは１組です。どれか１つを書いたら、残りの２つも書いてください。  
`wd_seq_*` は、`form` が `sin*` / `saw*` / `tri*` / `pls*` / `table` のときだけ書けます。`nzw*` と `nlbend` では書けません。

速さは `width` の値そのものではなく、「速さ」について直線に変わります。

|`form`|速さ|
|:-|:-|
|`sin*` / `saw*` / `tri*` / `pls*`|1 / `width`（１周の時間の逆数）|
|`table`（`width_mode=step`）|1 / `width`（１ステップに進む項目数）|
|`table`（`width_mode=shift`）|`width` / `shift_reso`（１ステップに進む項目数）|

たとえば `wd_seq_ini=64`、`width=16`、`wd_seq_dur=48`、`wd_seq_form=saw_os`（`form=sin`）では、速さは 1/64 から 1/16 へ直線に上がり、途中の `width` は 64 → 36.57 → 25.6 → 19.69 → 16（12 単位ごと）になります。

`form=table` の速さは、そのとき読んでいるテーブル（ノートオン同期用 / ノートオフ同期用）の `width_mode` で決まります。  
テーブルの項目を読み飛ばすことはしないので、１ステップに進む項目数は 1 項目までです（`width_mode=step` で `width` が 1 より小さい値に当たる速さは、1 項目 / ステップになります）。

速さが変わっても、位相は戻りません（１周の途中で速さだけが変わります）。

---

#### 変化の形：

|形|動き|`*_dur` の意味|
|:-|:-|:-|
|`saw_os`|初期値から目標値まで滑ったら、目標値を保つ。|初期値から目標値までの時間|
|`saw`|初期値から目標値へ。着いたら初期値に戻って繰り返す。|１周期（初期値から目標値まで）|
|`tri`|初期値 → 目標値 → 初期値 の往復を繰り返す。|１往復の時間|

値はＬＦＯステップ（`@lor` などで決まる更新の周期）ごとに、そのステップの頭の経過時間で決まり、そのステップの間は保たれます。整数に丸めず、なめらかに変わります。

---

#### 変化が始まる時機と戻る時機：

- ノートオン同期モード（`delay` が 0 以上）：ノートオンで先頭に戻ります。`delay` の間は進まず、ＬＦＯが振れ始めた最初のステップが初期値です。
- ノートオン非同期モード（`delay` が負数）：`@lq` を実行した直後から進み、ノートオンでは戻りません。音が鳴っていない間も進みます。
- `@lq` で定義を掛け直したとき、`@lqr` で再スタートしたときは、同期・非同期とも先頭に戻ります。
- タイ（`&`）の間やノートオフの後（リリース中）は、戻らずに進み続けます。
- 経過時間はＬＦＯクロックの単位で数えます。ＬＦＯクロックが tick のときにテンポが変わると、その時点から進み方（１秒あたり）が変わります。変化の途中の値は保たれます。

---

#### 変化が無効になる場合：

次の場合、その変化は働かず、深さ・速さは `depth` / `width` のまま一定です（`#MB:LFO_P` と同じ動きです）。

- `dp_seq_*` / `wd_seq_*` を書いていない。
- `dp_seq_dur` / `wd_seq_dur` が 0 以下（エラーにはなりません）。

---

#### エラーになる書き方：

- ３つ組の欠け（例：`dp_seq_ini` だけ、`wd_seq_dur` と `wd_seq_form` だけ）

```
dp_seq_ini / dp_seq_dur / dp_seq_form は 3 つそろえて書いてください。
```

- `*_form` に `saw_os` / `saw` / `tri` 以外を書いた

```
<形の名前> 使用できない変化の形です（saw_os / saw / tri）。
```

- `form` が `nzw*` / `nlbend` の定義に `wd_seq_*` を書いた

```
<form名> この form では wd_seq を指定できません。
```

- `wd_seq_ini` が 0 以下

```
<値> wd_seq_ini が不正です（0 より大きい値）。
```

- `#MB:LFO_P` ほか、`#MB:LFO_Q` 以外の定義に `dp_seq_*` / `wd_seq_*` を書いた

```
<項目名> 項目名が不正です。
```

---

#### 【備考】ずれのない変化にするには：

ＬＦＯステップの長さがＬＦＯクロックの単位と連動していないと、ステップの頭の経過時間が端数を持ちます。  
`lfo_resol: unit=clock`（`@lor"clock"`）でＬＦＯステップをＬＦＯクロックに連動させると、経過時間は１ステップごとに決まった量ずつ進み、変化の値が設計どおりに出ます。（[8.2](8_1n2.md)）
