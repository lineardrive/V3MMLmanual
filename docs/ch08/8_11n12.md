# 8.11 `#MB:LFO_FD`：フィルタＬＦＯ定義
# 8.12 （廃止）`@lf[1]`・`#MB:LFO_F`

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   lfo_clock: unit=tick: rate=1,
   lfo_resol: unit=sec: rate=1/300,
}
#MB:ENV_A @ea=1 { peak=15, init=& | n:1:15, r:1:0 }
#MB:LFO_FD 1  { depth=100, width=24, delay=24, form=sin_u }
#MB:LFO_FD 2  { depth=50, width=24, delay=24, form=sin, offset=50 }
#MB:FILTER_D @fd=1 { stages=lpA_lpA_lpB_lpB, cutA=13230.9, cutB=33975, lfo_fd1=1, cutA_lfo_fd1=-24, }
#MB:FILTER_D @fd=2 { stages=lpA_lpA_lpB_lpB, cutA=13230.9, cutB=33975, lfo_fd1=2, cutA_lfo_fd1=-24, }
t90 q12,16 v15 @@"pls" o5 @ea1
@fd1 c1 @fd2 c1;
```

上記のように書くと、

- `#MB:LFO_FD` によって、定義番号１番・２番にフィルタＬＦＯ内容を割り当てています。
- `#MB:FILTER_D` の `lfo_fd1=1` によって、動的フィルタ（`@fd1`）の枠に定義番号１番の `#MB:LFO_FD` を入れています。
- `cutA_lfo_fd1=-24` によって、ＬＦＯの値が 1 のとき、カットオフ A がおよそ 24 半音下がります。
- ２番は `offset=50` なので、ＬＦＯの値は 0 〜 1 で揺れ、カットオフ A は下側だけに揺れます。

といった定義と適用を記述できます。

## 【解説】

フィルタＬＦＯは、動的フィルタ（`@fd`・`#MB:FILTER_D`。[6.41](../ch06/6_41n42.md)）のカットオフを揺らすＬＦＯです。  
コマンドで選ぶのではなく、`#MB:FILTER_D` の枠（`lfo_fd1`）に定義番号を書いて使います。  
ＬＦＯの値 L は、次の式で求めます。

```
L ＝ (offset ＋ depth × 波形) ÷ 100      （波形は form の変位。ふつう -1 〜 1）
```

L を、`#MB:FILTER_D` の量の欄（`cutA_lfo_fd1`・`cutB_lfo_fd1`）に掛けてカットオフに足します。動的フィルタは、ＬＦＯの解像度の区切りごとに、そのときの値を読みます。

### フィルタＬＦＯ定義（`#MB:LFO_FD`）：

動的フィルタの枠（`lfo_fd1`）で使用する、フィルタＬＦＯ設定を定義します。  
フィルタＬＦＯ定義方法の概要は、次の通りです。

- 行頭からの記述で、キーワード「`#MB:LFO_FD`」を書く。
- 続けて、スペースを置き、定義番号を書く（`#MB:LFO_P` と違い、「@lp=」のようなラベルは付けません。付けるとエラーになります）。
- 続けて、スペースを置き、中括弧「`{ }`」で括られた設定データを書く。

### 定義番号：

定義番号は、`#MB:FILTER_D` の `lfo_fd1` に書く番号と合致するように定義します。  
定義番号の設定範囲は 0 〜 9999 です。  
`#MB:LFO_FD` の定義は 1024 個までです。超えるとエラーになります。

### 設定データ：

#### 【記述例】

```
#MB:LFO_FD 1  { depth=100, width=24, delay=24, form=sin_u }
```

#### 【解説】

フォーマットは次の通りです。

```
#MB:LFO_FD 定義番号 {
   depth=[], width=[], delay=[], form=[],
   offset=[],   （省略可能：直流のずらし）
   st_phase=[], （省略可能：sin/saw/tri/pls系の form でのみ指定可能）
   pwm=[],      （form=plsまたはform=pls_uの場合に指定可能）
   tbl_atk=[],  （form=tableの場合に指定可能）
   tbl_rel=[],  （form=tableの場合に指定可能）
   bendrate=[], （form=nlbendの場合に指定可能）
   dp_seq_ini=[], dp_seq_dur=[], dp_seq_form=[],   （省略可能：深さの時間変化）
   wd_seq_ini=[], wd_seq_dur=[], wd_seq_form=[],   （省略可能：速さの時間変化）
}
```

設定データの各要素は「項目名=値,」の形式で列挙します。  
最後のカンマは、あってもなくても構いません。  
スペースや改行は読み飛ばされます。

---

#### 要素 `depth`：

`depth=[]`では、揺らす振幅を -100 〜 100 で指定します。範囲の外はエラーになります。  
小数点以下の指定も受け付けます。  
負数を指定した場合、変化パターンの上下が反転した動作になります。  
ゼロを指定すると揺れは無くなりますが、`offset` は残ります。

`form`の波形変位は、通常 -1 〜 1 ですが、ユーザー定義テーブルの場合は、自由に変位が定義できるため、「`depth` × テーブル値」となる点に注意してください。

---

#### 要素 `offset`：（省略可能。省略時の値は0）

`offset=[]`では、ＬＦＯの値の直流のずらしを -100 〜 100 で指定します。範囲の外はエラーになります。小数点以下の指定も受け付けます。

- `delay` で遅らせるのは `depth` の部分だけです。`offset` は発音の時点から効きます。
- `dp_seq_*` が変えるのは `depth` の部分だけで、`offset` は変えません。
- `depth=0` でも `offset` は残ります（L ＝ `offset` ÷ 100 の一定）。

|書き方|L の動き|
|:-|:-|
|`depth=100, offset=0`|-1 〜 1|
|`depth=50, offset=50`|0 〜 1|
|`depth=0, offset=100`|1 の一定|

---

#### 要素 `width`：

`width=[]`では、`form`の指定内容によって、`width`の時間単位が変わります。

- `form`が、`sin*`,`saw*`,`tri*`,`pls*`, のとき：  
`width` は `form`波形１周期の長さを数値で指定します。  
数値は１以上の値を指定してください。  
周期の時間単位の初期設定は「１tickカウント」ですが、ＬＦＯクロック設定（`@loc`コマンドなど）により、テンポに依存しない時間単位（0.01秒など）にも出来ます。

- `form`が、`nzw*`,`table`,`nlbend`, のとき：  
`width` は ＬＦＯステップ数を数値で指定します。  
数値は１以上の値で指定してください。  
ＬＦＯステップ数は、ＬＦＯ解像度設定（`@lor`コマンドなど）で決まる、ＬＦＯ専用の最小時間単位です。

  - 加えて、`form=table` のとき：  
  ユーザー定義テーブル内の設定で、`width`の動作モードを、ＬＦＯステップ数とＬＦＯシフト数の２つから選択します。  
  詳細は「`#MB:LFOTBL_ATK`」を参照してください。

---

#### 要素 `delay`：

`delay=[]`では、ノートオンからＬＦＯ開始までの遅延時間を数値で指定します。  
時間単位は `width` 同様です。

- `delay` が 0 以上のとき：  
ノートオンの都度、ＬＦＯシーケンスが再スタートします。  
（ノートオン同期モード）

- `delay` が負数のとき：  
ノートオンでＬＦＯシーケンスが再スタートしない、ノートオン非同期モードとなります。いかなる負数の値も、このモード指定と判定されます。

`#MB:LFO_FD` には再スタートのコマンドはありません（ＬＦＯの再スタートコマンド `@l*r` の対象外です）。

`@fd` で枠に入れた時点で、同期・非同期モードに関わらずＬＦＯシーケンスは位相ゼロからスタートします。  
非同期モードでも、`offset` は `@fd` を当てた時点から効きます。

---

#### 要素 `form`：

`form=[]`では、変化パターンの波形を指定します。  
[（波形パターン詳細）](8_20.md)

`form`に指定する文字列と、波形の対応表は次の通りです。（`#MB:LFO_FD`）

|form|波形|
|:-|:-|
|sin|サイン波|
|sin_u|調整サイン波|
|sin_tri|サイン波と三角波の平均|
|saw|ノコギリ波|
|saw_u|調整ノコギリ波|
|saw_os|ノコギリ波ワンショット|
|tri|三角波|
|tri_u|調整三角波|
|pls|パルス波|
|pls_u|調整パルス波|
|nzw|ホワイトノイズ|
|nzw_u|調整ホワイトノイズ|
|table|ユーザー定義テーブル|
|nlbend|ノンリニアベンド|

- `form=pls*` のとき：  
追加で次の項目を設定します。

  - `pwm=[],` （省略可能：デューティ比）  
`pwm`の設定範囲は 0.005 〜 0.995 です。  
`pwm`を省略した場合の初期設定は「`pwm`=0.5」（デューティ比=50%）です。

- `form=table` のとき：  
追加で次の項目を設定します。

  - `tbl_atk=[],` （必須：`#MB:LFOTBL_ATK`で定義したテーブル番号）  
`tbl_atk`の設定範囲は 0 〜 9999 です。  
未定義のテーブル番号を指定した場合、ＬＦＯ変化のないダミーテーブルが参照されます。

  - `tbl_rel=[],` （省略可能：`#MB:LFOTBL_REL`で定義したテーブル番号）  
`tbl_rel`の設定範囲は 0 〜 9999 です。  
`tbl_rel`を省略した場合、常に「tbl_rel=-1」と解釈され、`tbl_rel`は未使用扱いになります。  
未定義のテーブル番号を指定した場合、ＬＦＯ変化のないダミーテーブルが参照されます。

- `form=nlbend` のとき：  
追加で次の項目を設定します。

  - `bendrate=[],` （必須：ノンリニアベンドの変化率）  
`bendrate`の設定範囲は 0.0 〜 1.0 です。  
0.0未満 もしくは 1.0超え の指定は、それぞれ 0.0、1.0に制限されます。
  - ノンリニアベンドの計算式：  
y = 1 - ((1 - p)^x)  
[x=0,1,2,3,4,5,...]  
[pは設定値です。通常 p=1/64 など、小さい値で使用します]

---

#### 要素 `st_phase`：

`st_phase=[]`では、ＬＦＯシーケンスを開始する位相を数値で指定します。  
この項目は省略可能です。省略した場合は `st_phase=0`（従来からの動作）が指定されたものとみなされます。

設定値は、波形１周期を 1.0 とした割合です。0.25 であれば、１周期の 1/4 だけ進んだ位置から開始します。  
小数点以下の指定も受け付けます。

設定できる値は次の通りです。

|記述|意味|
|:-|:-|
|`st_phase=0`〜`1`|その位相から開始します。`1` は `0` と同じです|
|`st_phase=-1`|開始する位相を、その都度 0 以上 1 未満の乱数で決めます|
|`st_phase=-2`|位相を戻しません（前の音の続きの位相のまま開始します）|

1 より大きい値と、`-1`・`-2` 以外の負の値は、次のエラーになります。（後で意味を足すために空けてあります）

```
<値> st_phase は 0 以上 1 以下か、-1・-2 にしてください。
```

この位相は、ノートオン同期モード（`delay` が 0 以上）でノートオンごとに戻る位置としても使われます。ノートオン非同期モード（`delay` が負数）でも、シーケンスの開始位置として有効です。

`-1`・`-2` の動作は、ノートオン同期モードかどうかで次のように変わります。

|`st_phase`|ノートオン同期モード（`delay` が 0 以上）|ノートオン非同期モード（`delay` が負数）|
|:-:|:-|:-|
|`-1`|ノートオンごとに乱数の位相から開始します|定義を指定したときに 1 回だけ乱数の位相を決め、その後は走り続けます|
|`-2`|位相は戻さず、前の音の続きから開始します。最初の音は位相 0 から開始します|`st_phase=0` と同じです|

- ノートオン同期モードでは、`-1`・`-2` でも、深さ・速さの時間変化（`dp_seq_*` / `wd_seq_*`）はノートオンごとに先頭に戻ります。戻さないのは位相だけです。
- タイ・スラー（ノートオンしない所）では、乱数を引き直しません。
- 乱数の位相は、発音チャネルごと・ＬＦＯの種類ごとに別々に決まります。ポリモードの和音や音色のレイヤーでは、音ごとに違う位相になります。
- 乱数は曲を読み込むたびに決め直します。同じ曲でも、読み込み直すと揺れ方が変わります。
- `-2` で別の定義に替えたとき（`#MB:FILTER_D` の枠 `lfo_fd1` の番号が違う `@fd` に替えたとき）は、位相 0 から開始します。
- `delay` が正の数（待ってから揺れ始める）のときも、位相の扱いは `delay=0` と同じです。

`form=tri` の場合、指定値と波形の始まり方の対応は次の通りです。

|`st_phase`|波形の出力|変位の始まり方|
|:-:|:-|:-|
|0.0|0 から +1 へ|中央から上へ|
|0.25|+1（頂点）|上端から|
|0.5|0 から −1 へ|中央から下へ|
|0.75|−1（谷）|下端から|

`st_phase` を指定できるのは、`form` が `sin*`、`saw*`、`tri*`、`pls*` の場合だけです。  
`nzw*`、`table`、`nlbend` を指定した定義に `st_phase` を書くと、次のエラーになります。（`form` より前に書いた場合も同じです）

```
<form名> この form では st_phase を指定できません。
```

※`st_phase` は、シーケンス開始時の位相を決めるものです。

---

#### 要素 `dp_seq_*` / `wd_seq_*`（深さ・速さの時間変化）：

ピッチＬＦＯ（`#MB:LFO_P`）の同じ名前の要素と、同じ書き方・同じ動きです。[8.3](8_3n4.md) を参照してください。  
`dp_seq_*` が変えるのは `depth` の部分だけで、`offset` は変えません。

---

#### （廃止）要素 `src`：

ピッチＬＦＯの波形を借りる要素 `src`（`src=@lp`・`src=@lq`）は廃止しました。書くと次のエラーになります。

```
src src は廃止しました。
```

ピッチとフィルタを同じ位相で揺らしたいときは、どちらのＬＦＯも `delay=0`（ノートオン同期モード）にして、同じ `width`・`st_phase` を書きます。ノートオンから同じ位相で進みます。  
（`st_phase=-1` の乱数の位相は、ＬＦＯの種類ごとに別々に決まるので、そろいません）

---

## （廃止）`@lf[1]`・`#MB:LFO_F`：

フィルタＬＦＯコマンド `@lf` と、その定義 `#MB:LFO_F`、`@lfz`・`@lfr`・`@lft` は廃止しました。書くとエラーになります。  
フィルタＬＦＯは `#MB:LFO_FD` で定義し、`#MB:FILTER_D` の枠（`lfo_fd1`）に番号を書いて使います。  
`#MB:LFO_F` の `depth` は、カットオフの内部の値（0 〜 1）を揺らす量でしたが、`#MB:LFO_FD` の `depth` は、`#MB:FILTER_D` の量の欄に掛ける値 L を作るためのものです。書き直すときは、量の欄と合わせて決め直してください。
