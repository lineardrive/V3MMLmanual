# 8.22 `wh[1]`：モジュレーションホイール

[← 目次](../index.md)

## 【記述例】

```mml
#MB:LFO_P @lp=1 { depth=0, width=24, delay=0, form=sin, wh_dp_amt=1.736, wh_dp_max=220.51 }
t120 l4 v15 @@"pls" o5 @ea1 @lp1
wh0 c&wh40 c&wh90 c wh0 c
```

上記のように書くと、伸ばした音の途中でビブラートが掛かり始め、さらに深くなります。最後の音はビブラートが掛かりません。

## 【解説】

### モジュレーションホイールコマンド（`wh[1]`）：

ＬＦＯの深さを、鳴っている間に動かすためのコマンドです。ホイールの値を 0 〜 127 で指定します。小数も書けます。  
トラックの先頭では 0 です。次に変えるまで、その値を保ちます。

**`wh` だけでは、音は何も変わりません。** ＬＦＯの定義に `wh_dp_amt` を書いたときだけ効きます。  
ホイールの値は、そのトラックのすべてのＬＦＯ（`@lp`・`@lq`・`@la`・`@lb`・`@ly` と、`#MB:FILTER_D` の枠で使う `#MB:LFO_FD`）に配られます。どれだけ効くかは、それぞれのＬＦＯの定義が決めます。

`ym"lfoall","wh",[]` と書いても、`wh[]` と同じ意味になります。（[6.35](../ch06/6_35.md)）

### 定義の要素（`wh_dp_amt`・`wh_dp_max`）：

ＬＦＯの定義（`#MB:LFO_P`・`#MB:LFO_Q`・`#MB:LFO_A`・`#MB:LFO_B`・`#MB:LFO_Y`・`#MB:LFO_FD`）に、次の２つの要素を書けます。どちらも省略できます。

|要素|意味|省略したとき|
|:-|:-|:-|
|`wh_dp_amt=[]`|ホイールの値 1 あたりに深さへ足す量。単位は `depth` と同じ。負の数も書ける|0（ホイールは効かない）|
|`wh_dp_max=[]`|深さとホイールの分を足した値の上限（絶対値）。0 以上|上限なし|

ＬＦＯの深さは、次の式で決まります。

```
深さ ＝ (depth、または dp_seq_* で変化している途中の値) ＋ ホイールの値 × wh_dp_amt
深さの絶対値が wh_dp_max を超えたら、wh_dp_max で切る（符号はそのまま）
```

- `dp_seq_*`（深さの時間変化）は `depth` の分だけに掛かります。ホイールの分は、立ち上がりを待たずにすぐ効きます。
- `delay` で揺れ始めを待っている間は、今までどおり揺れません（ホイールも効きません）。
- `offset` は変わりません。
- `#MB:LFO_B` は、ホイールの分を足した後も、`depth` と同じく 200 で切られます。
- `#MB:LFO_FD` の `wh_dp_max` は 0 〜 100 です。ホイールの分を足した後も、`depth` と同じく 100 で切られます。
- `ps` で選んだ音程の方式が WSG（`steprate_mode1` / `steprate_mode2`）のとき、テーブルの段に掛ける深さにはホイールの分を足しません。

### 効くとき：

- `wh` を書いた位置から効きます。ピッチ・フィルタ・yコマンドのＬＦＯは、次のＬＦＯの区切り（`lfo_resol`。[8.2](8_1n2.md)）から新しい深さになります。
- タイ・スラーの途中でも効きます（ノートオンを待ちません）。
- リリース中の音にも効きます。
- ポリモード（`@pl`）では、`@dlv` の設定に関わらず、鳴っている音（押鍵中もリリース中も）すべてにすぐ効きます。後のノートオンは、そのときのホイールの値から始まります。
- 音色のレイヤー（`@tl`。[10.9](../ch10/10_9n10.md)）でレイヤーごとにＬＦＯの定義が違えば、それぞれの定義の `wh_dp_amt`・`wh_dp_max` で深さが決まります。
- `@lp` などで定義を替えたときは、新しい定義の `wh_dp_amt`・`wh_dp_max` と、今のホイールの値で深さが決まります。

## 【値と効果】

### ピッチＬＦＯ（`depth=0`、`wh_dp_amt=1.736`、`wh_dp_max=220.51`、音程の分解能は 1/256 半音）：

|`wh`|深さ（1/256 半音）|揺れの片側|
|:-:|:-:|:-:|
|0|0|揺れない|
|20|34.7|±13.6 セント|
|40|69.5|±27.1 セント|
|90|156.3|±61.0 セント|
|127|220.5|±86.1 セント|

### 深さの立ち上がりとホイール（`depth=40.68`、`dp_seq_ini=0`、`dp_seq_dur=315.1`、`dp_seq_form=saw_os`、`wh_dp_amt=1.736`、`wh_dp_max=220.51`。`wh40` を鳴らす前から書いた場合）：

|ノートオンからの時間|立ち上がりの値|ホイールの分|深さ|
|:-:|:-:|:-:|:-:|
|0 ms|0|69.4|69.4|
|157.6 ms（半分）|20.34|69.4|89.8|
|315.1 ms 以降|40.68|69.4|110.1|

### 頭打ち（`depth=126.0`、`wh_dp_amt=1.736`、`wh_dp_max=220.51`）：

|`wh`|和|深さ（`wh_dp_max` で切る）|
|:-:|:-:|:-:|
|40|195.4|195.4|
|60|230.2|220.51|

### フィルタＬＦＯ（`#MB:LFO_FD`：`depth=0`、`wh_dp_amt=0.787`（＝ 100 ÷ 127）、`wh_dp_max=100`）：

|`wh`|深さ（−100 〜 100 の目盛り）|ＬＦＯの振れ（`offset=0`、波形が ±1 のとき）|
|:-:|:-:|:-:|
|0|0|0|
|30|23.6|±0.236|
|127|100|±1.0|

カットオフの添字の振れは、8 × `cutA_lfo_fd1` × ＬＦＯの振れです。（例：`cutA_lfo_fd1=13`、`wh30` で ±24.6）

## 【エラー】

- `wh` の値が 0 〜 127 の外（`ym"lfoall","wh",[]` も同じ）：

```
ホイールの値は 0〜127 です：wh128
```

- `wh` の数値を省略した：

```
wh[] の数値は省略できません。
```

- `ym"lfoall",…` の機能名が `wh` でない：

```
ym[str],[str],[]のfunc名が不正です。
```

- `wh_dp_max` が負：

```
-1 wh_dp_max は 0 以上です。
```

- `#MB:LFO_FD` の `wh_dp_max` が 100 を超える：

```
101 指定可能範囲は、(0.0 〜 100.0)です。
```

- 音色のレイヤー（`#MB:TONE_LAYER`）に `wh` を書いた：エラーになります。`wh` はトラックの値だけを持ちます。

`wh_dp_amt` を書いていない定義のトラックで `wh` を書いても、エラーにも警告にもなりません。

- 「`#`」を記述すると、前回の値として解釈されます。
- `)` `(` のような相対指定はありません。
- 無限リピート（`@rp`）で先頭へ戻っても、値は変わりません。

---

## 【表示】

### KeyDispへの表示：

ホイールの値は表示されません。  
ただし、KeyDisp の音程と音量・パンのＬＦＯのゲージは、ホイールの分を足した深さで動きます。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`）には、`vel` の後ろに `wh40` のように表示されます。0 のときは表示されません。  
差分（`!d`）には、値が変わったときに表示されます（0 に戻したときも `wh0` と表示されます）。
