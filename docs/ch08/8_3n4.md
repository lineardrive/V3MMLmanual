# 8.3 `@lp[1]`：ピッチＬＦＯ
# 8.4 `#MB:LFO_P`：ピッチＬＦＯ定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   lfo_clock: unit=tick: rate=1,
   lfo_resol: unit=sec: rate=1/300,
}
#MB:LFOTBL_ATK 1 {
   loop=0, cmpl=0, offset=0, denom=1, width_mode=step, |
   0, 1, 0, -1,
}
#MB:ENV_A @ea=1 { peak=15, init=& | n:1:15, r:1:0 }
#MB:LFO_P @lp=0  { depth=400, width=24, delay=48, form=sin }
#MB:LFO_P @lp=1  { depth=400, width=24, delay=48, form=sin_u }
#MB:LFO_P @lp=10 { depth=400, width=24, delay=48, form=saw }
#MB:LFO_P @lp=11 { depth=400, width=24, delay=48, form=saw_u }
#MB:LFO_P @lp=12 { depth=400, width=24, delay=48, form=saw_os }
#MB:LFO_P @lp=20 { depth=400, width=24, delay=48, form=tri }
#MB:LFO_P @lp=21 { depth=400, width=24, delay=48, form=tri_u }
#MB:LFO_P @lp=30 { depth=400, width=24, delay=48, form=pls }
#MB:LFO_P @lp=31 { depth=400, width=24, delay=48, form=pls_u }
#MB:LFO_P @lp=40 { depth=400, width=4,  delay=48, form=nzw }
#MB:LFO_P @lp=41 { depth=400, width=4,  delay=48, form=nzw_u }
#MB:LFO_P @lp=50 { depth=400, width=24, delay=48, form=table, tbl_atk=1 }
#MB:LFO_P @lp=60 { depth=400, width=4,  delay=48, form=nlbend, bendrate=64/1024 }
t120 q12,16 v15 @@"pls" o5 @ea1
@lp0 c1&2 @lp1 c1&2
@lp10 c1&2 @lp11 c1&2 @lp12 c1&2
@lp20 c1&2 @lp21 c1&2
@lp30 c1&2 @lp31 c1&2
@lp40 c1&2 @lp41 c1&2
@lp50 c1&2
@lp60 c1&2;
```

上記のように書くと、`#MB:LFO_P` と `@lp`コマンドによって、ピッチＬＦＯの定義と適用を記述できます。

## 【解説】

### ピッチＬＦＯコマンド（`@lp[1]`）：

ピッチＬＦＯ定義（`#MB:LFO_P`）の定義番号を整数で指定します。  
定義番号は 0 〜 9999 の整数です。  
未定義の番号を指定するとエラーになります。  
トラック先頭における初期設定では、ピッチＬＦＯは停止状態です。

`ps` で選んだ音程の方式が WSG（`steprate_mode1` / `steprate_mode2`）のときは、`form=table` だけが使えます。（[2.14.9 / 2.14.10](../ch02/2_14_9n10.md)）

２本目のピッチＬＦＯ（`@lq`）を同時に掛けることもできます。２本目は１本目とまったく同じ働きをし、本節の説明がそのまま当てはまります。（[8.5 `@lq`](8_5n6.md)）

### ピッチＬＦＯ定義（`#MB:LFO_P`）：

ピッチＬＦＯコマンド（`@lp[1]`）で使用する、ピッチＬＦＯ設定を定義します。
ピッチＬＦＯ定義方法の概要は、次の通りです。

- 行頭からの記述で、キーワード「`#MB:LFO_P`」を書く。
- 続けて、スペースを置き、「@lp=定義番号」を書く。
- 続けて、スペースを置き、中括弧「`{ }`」で括られた設定データを書く。

### 定義番号：

定義番号は、`@lp`コマンドの引数で使用する番号と合致するように定義します。  
定義番号の設定範囲は 0 〜 9999 です。  
`#MB:LFO_P` の定義は 1024 個までです。超えるとエラーになります。

### 設定データ：

#### 【記述例】

```
#MB:LFO_P @lp=0  { depth=400, width=24, delay=48, form=sin }
```

#### 【解説】

フォーマットは次の通りです。

```
#MB:LFO_P @lp=定義番号 {
   depth=[], width=[], delay=[], form=[],
   st_phase=[], （省略可能：sin/saw/tri/pls系の form でのみ指定可能）
   pwm=[],     （form=plsまたはform=pls_uの場合に指定可能）
   tbl_atk=[], （form=tableの場合に指定可能）
   tbl_rel=[], （form=tableの場合に指定可能）
   bendrate=[],（form=nlbendの場合に指定可能）
   dp_seq_ini=[], dp_seq_dur=[], dp_seq_form=[],   （省略可能：深さの時間変化）
   wd_seq_ini=[], wd_seq_dur=[], wd_seq_form=[],   （省略可能：速さの時間変化）
}
```

設定データの各要素は「項目名=値,」の形式で列挙します。  
最後のカンマは、あってもなくても構いません。  
スペースや改行は読み飛ばされます。

---

#### 要素 `depth`：

`depth=[]`では、揺らす音程の振幅を数値で指定します。  
小数点以下の指定も受け付けます。  
単位は、`ps`コマンドで設定されている音程の解像度です。  
ゼロを指定した場合、ピッチＬＦＯが無効になります。  
負数を指定した場合、変化パターンの上下が反転した動作になります。

振幅は「`depth` × `form`の波形変位」で得られます。  
`form`の波形変位は、通常 -1 〜 1 ですが、ユーザー定義テーブルの場合は、自由に変位が定義できるため、振幅演算が「`depth` × テーブル値」となる点に注意してください。

---

#### 要素 `width`：

`width=[]`では、`form`の指定内容によって、`width`の時間単位が変わります。

- `form`が、`sin*`,`saw*`,`tri*`,`pls*`, のとき：  
`width` は `form`波形１周期の長さを数値で指定します。  
数値は１以上の値を指定してください。  
周期の時間単位の初期設定は「１tickカウント」ですが、ＬＦＯクロック設定（`@loc`コマンドなど）により、テンポに依存しない時間単位（0.01秒など）にも出来ます。

- `form`が、`nzw*`,`table`,`nlbend`, のとき：  
`width` は ＬＦＯステップ数を数値で指定します。  
数値は１以上の値で指定してください。  
ＬＦＯステップ数は、ＬＦＯ解像度設定（`@lor`コマンドなど）で決まる、ＬＦＯ専用の最小時間単位です。

  - 加えて、`form=table` のとき：  
ユーザー定義テーブル内の設定で、`width`の動作モードを、ＬＦＯステップ数とＬＦＯシフト数の２つから選択します。  
詳細は「`#MB:LFOTBL_ATK`」を参照してください。

---

#### 要素 `delay`：

`delay=[]`では、ノートオンからＬＦＯ開始までの遅延時間を数値で指定します。  
時間単位は `width` 同様です。

- `delay` が 0 以上のとき：  
ノートオンの都度、ＬＦＯシーケンスが再スタートします。（ノートオン同期モード）

- `delay` が 負数のとき：  
ノートオンでＬＦＯシーケンスが再スタートしない、ノートオン非同期モードとなります。いかなる負数の値も、このモード指定と判定されます。

ノートオン非同期モードにおいて、任意のタイミングでＬＦＯ位相のリセットを行いたい場合は、ＬＦＯの再スタートコマンドを使用します。

ＬＦＯコマンドの指定時には、同期・非同期モードに関わらずＬＦＯシーケンスは位相ゼロからスタートします。

---

#### 要素 `form`：

`form=[]`では、変化パターンの波形を指定します。  
[（波形パターン詳細）](8_20.md)

`form`に指定する文字列と、波形の対応表は次の通りです。（`#MB:LFO_P`）

|form|波形|
|:-|:-|
|sin|サイン波|
|sin_u|調整サイン波|
|saw|ノコギリ波|
|saw_u|調整ノコギリ波|
|saw_os|ノコギリ波ワンショット|
|tri|三角波|
|tri_u|調整三角波|
|pls|パルス波|
|pls_u|調整パルス波|
|nzw|ホワイトノイズ|
|nzw_u|調整ホワイトノイズ|
|table|ユーザー定義テーブル|
|nlbend|ノンリニアベンド|

- `form=pls*` のとき：  
追加で次の項目を設定します。

  - `pwm=[],` （省略可能：デューティ比）  
`pwm`の設定範囲は 0.005 〜 0.995 です。  
`pwm`を省略した場合の初期設定は「`pwm`=0.5」（デューティ比=50%）です。

- `form=table` のとき：  
追加で次の項目を設定します。

  - `tbl_atk=[],` （必須：`#MB:LFOTBL_ATK`で定義したテーブル番号）  
`tbl_atk`の設定範囲は 0 〜 9999 です。  
未定義のテーブル番号を指定した場合、ＬＦＯ変化のないダミーテーブルが参照されます。

  - `tbl_rel=[],` （省略可能：`#MB:LFOTBL_REL`で定義したテーブル番号）  
`tbl_rel`の設定範囲は 0 〜 9999 です。  
`tbl_rel`を省略した場合、常に「tbl_rel=-1」と解釈され、`tbl_rel`は未使用扱いになります。  
未定義のテーブル番号を指定した場合、ＬＦＯ変化のないダミーテーブルが参照されます。

- `form=nlbend` のとき：  
追加で次の項目を設定します。

  - `bendrate=[],` （必須：ノンリニアベンドの変化率）  
`bendrate`の設定範囲は 0.0 〜 1.0 です。  
0.0未満 もしくは 1.0超え の指定は、それぞれ 0.0、1.0に制限されます。
  - ノンリニアベンドの計算式：  
y = 1 - ((1 - p)^x)  
[x=0,1,2,3,4,5,...]  
[pは設定値です。通常 p=1/64 など、小さい値で使用します]

---

#### 要素 `st_phase`：

`st_phase=[]`では、ＬＦＯシーケンスを開始する位相を数値で指定します。  
この項目は省略可能です。省略した場合は `st_phase=0`（従来からの動作）が指定されたものとみなされます。

設定値は、波形１周期を 1.0 とした割合です。0.25 であれば、１周期の 1/4 だけ進んだ位置から開始します。  
小数点以下の指定も受け付けます。

値域の外を指定してもエラーにはならず、１周期ぶんずつ畳み込まれます。

|記述|実際の位相|
|:-:|:-:|
|`st_phase=1.0`|0.0|
|`st_phase=1.25`|0.25|
|`st_phase=-0.75`|0.25|

この位相は、ノートオン同期モード（`delay` が 0 以上）でノートオンごとに戻る位置としても使われます。ノートオン非同期モード（`delay` が負数）でも、シーケンスの開始位置として有効です。

`form=tri` の場合、指定値と波形の始まり方の対応は次の通りです。

|`st_phase`|波形の出力|変位の始まり方|
|:-:|:-|:-|
|0.0|0 から +1 へ|中央から上へ|
|0.25|+1（頂点）|上端から|
|0.5|0 から −1 へ|中央から下へ|
|0.75|−1（谷）|下端から|

`st_phase` を指定できるのは、`form` が `sin*`、`saw*`、`tri*`、`pls*` の場合だけです。  
`nzw*`、`table`、`nlbend` を指定した定義に `st_phase` を書くと、次のエラーになります。（`form` より前に書いた場合も同じです）

```
<form名> この form では st_phase を指定できません。
```

※`st_phase` は、シーケンス開始時の位相を決めるものです。演奏中に現在の位相そのものを変更したい場合は、`ym"lptri","phase",[]` を使用します。  
[（音源モジュール制御詳細モードとは）](../ch06/6_35.md)

---

#### 要素 `dp_seq_*` / `wd_seq_*`（深さ・速さの時間変化）：

深さと速さを、時間とともに変えられます。この項目は省略可能です。省略した場合、深さ・速さは `depth` / `width` のまま一定です。

```
#MB:LFO_P @lp=2 { depth=60, width=16, delay=100, form=sin,
                  dp_seq_ini=0,  dp_seq_dur=171, dp_seq_form=saw_os,
                  wd_seq_ini=64, wd_seq_dur=256, wd_seq_form=saw_os }
```

上記では、キーオンから 100 単位は振れず、そこから深さが 0 から 60 まで 171 単位かけて増え、同時に速さが「１周 64 単位」から「１周 16 単位」まで 256 単位かけて速くなります。

|項目|意味|
|:-|:-|
|`dp_seq_ini` / `dp_seq_dur` / `dp_seq_form`|深さを、初期値から `depth` の値へ変える。|
|`wd_seq_ini` / `wd_seq_dur` / `wd_seq_form`|速さを、`wd_seq_ini` で表した速さから `width` で表した速さへ変える。|

---

#### 要素 `dp_seq_ini` / `dp_seq_dur` / `dp_seq_form`（深さの時間変化）：

深さを、初期値から `depth` の値（目標値）へ、時間とともに変えます。

|項目|意味|
|:-|:-|
|`dp_seq_ini=[]`|深さの初期値。単位は `depth` と同じ。負数も書けます。|
|`dp_seq_dur=[]`|変化の時間。単位は `delay` / `width` と同じ（ＬＦＯクロック）。|
|`dp_seq_form=[]`|変化の形。`saw_os` / `saw` / `tri` のどれか。|

３つは１組です。どれか１つを書いたら、残りの２つも書いてください。

---

#### 要素 `wd_seq_ini` / `wd_seq_dur` / `wd_seq_form`（速さの時間変化）：

速さを、`wd_seq_ini` で表した速さから、`width` で表した速さ（目標値）へ、時間とともに変えます。

|項目|意味|
|:-|:-|
|`wd_seq_ini=[]`|速さの初期値を、`width` と同じ単位・同じ意味の値で書いたもの。0 より大きい値。|
|`wd_seq_dur=[]`|変化の時間。単位は `delay` / `width` と同じ（ＬＦＯクロック）。|
|`wd_seq_form=[]`|変化の形。`saw_os` / `saw` / `tri` のどれか。|

３つは１組です。どれか１つを書いたら、残りの２つも書いてください。  
`wd_seq_*` は、`form` が `sin*` / `saw*` / `tri*` / `pls*` / `table` のときだけ書けます。`nzw*` と `nlbend` では書けません。

速さは `width` の値そのものではなく、「速さ」について直線に変わります。

|`form`|速さ|
|:-|:-|
|`sin*` / `saw*` / `tri*` / `pls*`|1 / `width`（１周の時間の逆数）|
|`table`（`width_mode=step`）|1 / `width`（１ステップに進む項目数）|
|`table`（`width_mode=shift`）|`width` / `shift_reso`（１ステップに進む項目数）|

たとえば `wd_seq_ini=64`、`width=16`、`wd_seq_dur=48`、`wd_seq_form=saw_os`（`form=sin`）では、速さは 1/64 から 1/16 へ直線に上がり、途中の `width` は 64 → 36.57 → 25.6 → 19.69 → 16（12 単位ごと）になります。

`form=table` の速さは、そのとき読んでいるテーブル（ノートオン同期用 / ノートオフ同期用）の `width_mode` で決まります。  
テーブルの項目を読み飛ばすことはしないので、１ステップに進む項目数は 1 項目までです（`width_mode=step` で `width` が 1 より小さい値に当たる速さは、1 項目 / ステップになります）。

速さが変わっても、位相は戻りません（１周の途中で速さだけが変わります）。

---

#### 変化の形：

|形|動き|`*_dur` の意味|
|:-|:-|:-|
|`saw_os`|初期値から目標値まで滑ったら、目標値を保つ。|初期値から目標値までの時間|
|`saw`|初期値から目標値へ。着いたら初期値に戻って繰り返す。|１周期（初期値から目標値まで）|
|`tri`|初期値 → 目標値 → 初期値 の往復を繰り返す。|１往復の時間|

値はＬＦＯステップ（`@lor` などで決まる更新の周期）ごとに、そのステップの頭の経過時間で決まり、そのステップの間は保たれます。整数に丸めず、なめらかに変わります。

---

#### 変化が始まる時機と戻る時機：

- ノートオン同期モード（`delay` が 0 以上）：ノートオンで先頭に戻ります。`delay` の間は進まず、ＬＦＯが振れ始めた最初のステップが初期値です。
- ノートオン非同期モード（`delay` が負数）：`@lp` を実行した直後から進み、ノートオンでは戻りません。音が鳴っていない間も進みます。
- `@lp` で定義を掛け直したとき、`@lpr` で再スタートしたときは、同期・非同期とも先頭に戻ります。
- ２本目のピッチＬＦＯ（`@lq`）の変化とは、互いに独立しています。`@lp` / `@lpr` で戻るのは１本目の変化だけで、２本目の変化は `@lq` / `@lqr` で戻ります。
- タイ（`&`）の間やノートオフの後（リリース中）は、戻らずに進み続けます。
- 経過時間はＬＦＯクロックの単位で数えます。ＬＦＯクロックが tick のときにテンポが変わると、その時点から進み方（１秒あたり）が変わります。変化の途中の値は保たれます。

---

#### 変化が無効になる場合：

次の場合、その変化は働かず、深さ・速さは `depth` / `width` のまま一定です（変化を書かない定義と同じ動きです）。

- `dp_seq_*` / `wd_seq_*` を書いていない。
- `dp_seq_dur` / `wd_seq_dur` が 0 以下（エラーにはなりません）。

---

#### エラーになる書き方：

- ３つ組の欠け（例：`dp_seq_ini` だけ、`wd_seq_dur` と `wd_seq_form` だけ）

```
dp_seq_ini / dp_seq_dur / dp_seq_form は 3 つそろえて書いてください。
```

- `*_form` に `saw_os` / `saw` / `tri` 以外を書いた

```
<形の名前> 使用できない変化の形です（saw_os / saw / tri）。
```

- `form` が `nzw*` / `nlbend` の定義に `wd_seq_*` を書いた

```
<form名> この form では wd_seq を指定できません。
```

- `wd_seq_ini` が 0 以下

```
<値> wd_seq_ini が不正です（0 より大きい値）。
```

- ピッチＬＦＯ（`#MB:LFO_P` / `#MB:LFO_Q`）以外の定義（`#MB:LFO_A` / `#MB:LFO_B` / `#MB:LFO_F` / `#MB:LFO_Y`）に `dp_seq_*` / `wd_seq_*` を書いた

```
<項目名> 項目名が不正です。
```

---

#### 【備考】ずれのない変化にするには：

ＬＦＯステップの長さがＬＦＯクロックの単位と連動していないと、ステップの頭の経過時間が端数を持ちます。  
`lfo_resol: unit=clock`（`@lor"clock"`）でＬＦＯステップをＬＦＯクロックに連動させると、経過時間は１ステップごとに決まった量ずつ進み、変化の値が設計どおりに出ます。（[8.2](8_1n2.md)）
