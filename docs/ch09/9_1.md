# 9.1 `@pl[1],[2]`：ポリフォニックモード設定

[← 目次](../index.md)

## 【記述例】

```mml
#MB:ENV_A @ea=1 { peak=15, init=& | n:1:15, r:250:0 }
@@"pls" @ea1 o4 l8
@pl4,0 dfa ceg brrr rrrr
@pl1,0 dfa ceg brrr;
```

上記のように書くと、`@pl4,0`の掛かった音符は、リリース音が重なりながら演奏されます。(4-poly)

`@pl1,0`の掛かった音符は、リリース音が重ならずに演奏されます。(mono)

## 【解説】

１トラックの記述で音が複数重なる「ポリフォニックモード」の設定を行います。

指定する引数は次の通りです。

- 引数[1]...最大発音数
- 引数[2]...音が重なる方式のモード番号

引数はカンマで区切って指定します。

引数[1]には、同時発音数を整数で記述します。  
設定範囲は、1 〜 128 です。  
同時発音数が多すぎると処理落ちの原因になります。

引数[2]には、音が重なる方式のモード番号を、0 または 1 で指定します。

- モード番号 0 のとき：  
ポリフォニックモードを上塗り方式にします。  
まず、無音チャネルを検索し、見つかればそこで発音させます。  
無音チャネルが見つからなかった場合、ノートオフされて余韻状態で発音しているチャネルのうち、最も古い発音に、最も新しい発音を上塗りします。  
すべてのチャネルがノートオン中のときは、ノートオン中のチャネルのうち、最も古い発音に上塗りします。  
最も古い発音が同時発音により複数存在する場合は、最初に見つかったものに機械的に上塗りされます。

- モード番号 1 のとき：  
ポリフォニックモードを鍵盤楽器方式にします。  
(1)ノートオフされて余韻状態で発音しているチャネルを検索し、その中から、これからノートオンしようとしている音程と同じ音程のものがあれば、新しい発音を上塗りします。  
(2)(1)で見つからなければ、無音チャネルを検索し、見つかればそこで発音させます。  
(3)(2)においても見つからなければ、ノートオフされて余韻状態で発音しているチャネルのうち、最も古い発音に、最も新しい発音を上塗りします。  
(4)すべてのチャネルがノートオン中のときは、ノートオン中のチャネルのうち、これからノートオンしようとしている音程と同じ音程のものがあれば、その中で最も古い発音に上塗りします。無ければ、最も古い発音に上塗りします。  
最も古い発音が同時発音により複数存在する場合は、最初に見つかったものに機械的に上塗りされます。

【備考】  
ポリフォニックモードが発動されたトラックでは、最大発音数の分だけ、内部的に発音チャネルを固定的に確保するので、メモリ使用量が増えます。

ポリフォニックモードが発動されていないトラックでは、多重チャネル化を行わないので、メモリ使用量は増えません。

【配り方】  
ポリフォニックモードのトラックでは、`v`・`)` `(`・`vl`・`mv`・`@p`・`p`・`px` などの値は、次のノートオンの直前に、その発音チャネルへ当たります。  
鳴っている音にもすぐに効かせたいときは、[9.3 `@dlv`](9_3.md) で配り方を切り替えます。

音色の層（[10.9](../ch10/10_9n10.md)）に持たせるコマンド（`v`・`vl`・`@d`・`@p`・`px`・`@@`・`@`・`@ea`・`@ef`・`@lp`・`@lq`・`@la`・`@lb`・`@lf`・`@ly`・`@fd`・`@bf`）は、`@tl` を使っていなくても、ノートオンのたびに、その発音チャネルへすべて配ります。  
前に同じ発音チャネルで鳴らした音の値を、引き継がないようにするためです。

【音色の層（`@tl`）を使うとき】  
`@tl`（[10.9](../ch10/10_9n10.md)）を使うと、1 つの音符で、条件に合った層の数だけ発音チャネルを使います。

- 引数[1] は、定義に書いた層の数以上にしてください。`@tl` を書いた時点、または `@tl` を使っている途中で `@pl` を書いた時点で、引数[1] が定義の層の数より少ないとエラーになります。  
和音などで同時に鳴らす音符の数も見込んで、引数[1] を指定してください。
- `@tl` を使っている間は、引数[2]（モード番号）を使わず、層ごとに次の順で発音チャネルを取ります（`@tlz` の後は、また引数[2] に従います）。  
(1)無音チャネルのうち、番号の小さいもの。  
(2)(1)で見つからなければ、ノートオフされて余韻状態で発音しているチャネルのうち、最も古い発音。  
(3)(2)においても見つからなければ、ノートオン中のチャネルのうち、最も古い発音。同じ音符のほかの層が取ったチャネルは選びません。  
最も古い発音が同時発音により複数存在する場合は、最初に見つかったものに上塗りされます。  
モード番号 1 の「同じ音程の余韻状態のチャネルを先に取る」動きを層に当てると、別の層の余韻を切ってしまうので、使いません。

【備考】非同期のＬＦＯ  
ポリフォニックモードでは、ノートオンで位相を戻さないＬＦＯ（ＬＦＯ定義の `delay` が負の数のもの）は、動作を保証しません。  
ノートオンのたびに値を配るので、どの発音チャネルで鳴るかによって、ＬＦＯの状態が変わるためです。
