# 10.9 `@tl[1]` / `@tlz`：音色のレイヤー
# 10.10 `#MB:TONE_LAYER`：@tl用音色のレイヤー定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:TONE_LAYER @tl=1 {
   layer=1, map_key=0:59,   @=1, @ea=1, |
   layer=2, map_key=48:119, @=2, @ea=2, v_keymap+=1, |
   layer=3, map_vel=100:127, @@=nzw-0, @ea=3, v=6, |
   map_key_val=1, 48:-8, 59:0,
}
@@"pls" @pl8,0 @tl1 vel64 o4 c e g o5 c vel110 e
```

上記の場合、1 つの音符で、条件に合ったレイヤー（`layer`）の数だけ発音チャネルが同時に鳴ります。

- 音程番号 0〜59 の音符ではレイヤー 1（`@1`・`@ea1`）が鳴ります。
- 音程番号 48〜119 の音符ではレイヤー 2（`@2`・`@ea2`）が鳴ります。音程番号 48〜59 では、レイヤー 1 とレイヤー 2 が重なります。レイヤー 2 の音量は、マップ 1 によって、音程番号 48 で `v` を 8 下げ、59 に向かって元の `v` に近づきます。
- ベロシティ（`vel`。[4.17](../ch04/4_17.md)）が 100 以上の音符では、レイヤー 3（ノイズ音源の `@0`・`@ea3`・`v6`）も鳴ります。

## 【解説】

### 音色のレイヤーコマンド（`@tl[1]` / `@tlz`）：

`@tl` は、音色のレイヤー定義（`#MB:TONE_LAYER`）の定義番号を整数で指定して、レイヤーを使い始めます。  
定義番号は 0 〜 9999 の整数です。未定義の番号を指定するとエラーになります。  
`@tlz` を書くと、レイヤーを使わない状態に戻ります。トラック先頭における初期設定では、レイヤーを使わない状態です。

音色のレイヤーとは、1 つの音符で、設定の違う発音チャネルを最大 8 本同時に鳴らす機能です。  
レイヤーごとに、音程番号とベロシティの範囲で「鳴らす・鳴らさない」を決め、音色・エンベロープ・音量などのコマンドの値を変えられます。  
キーイベント（[10.3](10_3n4.md)〜[10.8](10_7n8.md)）と同じく音符ごとに働きますが、キーイベントがトラックの値を変えるのに対し、音色のレイヤーはトラックの値を変えず、発音チャネルごとに違う値を持たせます。

`@tl` は、ポリフォニックモード（[9.1](../ch09/9_1.md)）のトラックでだけ使えます。

- `@tl` より前に、引数[1] が 2 以上の `@pl` を書いてください。そうでないトラックの `@tl` は警告になります。
- `@tl` を書いた時点の `@pl` の引数[1] が、定義に書いたレイヤーの数より少ないとエラーになります。`@tl` を使っている途中で、レイヤーの数より少ない `@pl` を書いてもエラーになります。  
比べるのは定義に書いたレイヤーの数です（1 つの音符で実際に鳴るレイヤーの数は、音程とベロシティで変わるので使いません）。
- レイヤーを使っている間の、発音チャネルの取り方は [9.1](../ch09/9_1.md) を参照してください（`@pl` の引数[2] は使いません）。

#### 【ノートオンの流れ】

1. キーイベント（`@kt`・`@kc`・`@kl`）が、今までどおりトラックの値を変えます。
2. レイヤーごとに、`map_key`・`map_vel` の条件を判定します。
3. 条件に合ったレイヤーごとに、コマンドの値を決め、発音チャネルを 1 本取ります。
4. その発音チャネルに、レイヤーに持たせるコマンドの値をすべて配ってから、ノートオンします。

条件に合うレイヤーが 1 つも無い音符は鳴りません（警告も出ません）。

#### 【ノートオフ・タイ・スラー】

- ノートオフは、その音符で鳴らしたすべてのレイヤーに送られます。
- タイ・スラー（`&`）で音程を変えると、すべてのレイヤーの音程が一緒に変わります。
- スラーの途中で音程番号が変わっても、レイヤーの選び直しはしません（最初のノートオンのレイヤーのままです）。

#### 【備考】

- `@tl` と `vel` は、無限リピート（`@rp`）で先頭へ戻っても、値を変えません。
- レイヤーの値を決めるときの「トラックの値」は、その音符の時点の値です。

### 音色のレイヤー定義（`#MB:TONE_LAYER`）：

音色のレイヤーコマンド（`@tl[1]`）で使用する、レイヤーの設定を定義します。

定義方法の概要は、次の通りです。

- 行頭からの記述で、キーワード「`#MB:TONE_LAYER`」を書く。
- 続けて、スペースを置き、「@tl=定義番号」を書く。
- 続けて、スペースを置き、中括弧「`{ }`」で括られた設定データを書く。

### 定義番号：

定義番号は、`@tl`コマンドの引数で使用する番号と合致するように定義します。  
定義番号の設定範囲は 0 〜 9999 です。  
`#MB:TONE_LAYER` の定義は 1024 個までです。超えるとエラーになります。  
同じ定義番号を 2 回定義した場合は、先に書いた定義が使われます。

### 設定データ：

#### 【解説】

設定データは、「`|`」記号で区切った「ブロック」を並べて書きます。  
ブロックの先頭の要素が、そのブロックの種類と番号を表します。ブロックの順は問いません。

|先頭の要素|ブロックの意味|
|:-|:-|
|`layer=n`|n 番目のレイヤー（n = 1 〜 8）|
|`map_key_val=n`|音程番号に応じた数値のマップ n 番|
|`map_vel_val=n`|ベロシティに応じた数値のマップ n 番|
|`map_key_osc=n`|音程番号に応じた「音源名-音色番号」のマップ n 番|
|`map_vel_osc=n`|ベロシティに応じた「音源名-音色番号」のマップ n 番|

ブロックの中の各要素は、カンマで区切って記述します。  
最後のカンマは、あってもなくても構いません。  
スペースや改行は読み飛ばされます。

---

#### レイヤー（`layer=n`）：

レイヤーの数は 1 〜 8 で、少なくとも 1 つ要ります。  
同じ番号のレイヤーが 2 つあるとエラーになります。番号の抜け（1 と 3 だけ、など）は構いません。  
1 つの音符のレイヤーは、番号の小さい順に発音チャネルを取ります。

##### 条件（鳴らすかどうか）

|要素|意味|
|:-|:-|
|`map_key=lo:hi`|音程番号が lo 〜 hi のときだけ鳴ります。省略すると `0:119` です。|
|`map_vel=lo:hi`|ベロシティ（`vel`）が lo 〜 hi のときだけ鳴ります。省略すると `0:127` です。|

2 つの条件は両方を満たしたときだけ鳴ります。  
音程番号が 0〜119 の外の音符は、0 か 119 として判定します。

##### コマンドの値

レイヤーでは、コマンドごとに次の書き方で値を指定します。

|書き方|意味|
|:-|:-|
|`<cmd>=値`|固定の値を代入します（絶対指定）。|
|`<cmd>+=値`|固定の値を加算します（相対指定）。|
|`<cmd>_keymap=n`|`map_key_val` の n 番で引いた値を代入します。|
|`<cmd>_keymap+=n`|`map_key_val` の n 番で引いた値を加算します。|
|`<cmd>_velmap=n`|`map_vel_val` の n 番で引いた値を代入します。|
|`<cmd>_velmap+=n`|`map_vel_val` の n 番で引いた値を加算します。|

例：`v+=-2`、`@ea=6`、`v_keymap+=2`、`@ea_velmap=33`、`@lp_velmap+=34`

値は、書いた順に関係なく、次のように合成します。

```
結果 = 基準 + 固定の加算 + 音程のマップの加算 + ベロシティのマップの加算
```

- 基準は、代入（`=`・`_keymap=`・`_velmap=` のどれか 1 つ）があればその値、無ければノートオンの時点のトラックの値です。
- 1 つのレイヤーの 1 つのコマンドに、代入を 2 つ以上書くとエラーになります。同じ種類の加算（`v+=` を 2 つ、など）を書いてもエラーになります。
- コマンドを書かなかったときは、トラックの値で鳴ります。

##### レイヤーに書けるコマンド

|種類|コマンド|
|:-|:-|
|数値|`v`（[4.9](../ch04/4_9.md)）、`vl`（[4.11](../ch04/4_11.md)）、`@d`（[2.17](../ch02/2_17.md)）、`@p`（[4.5](../ch04/4_5.md)）、`px`（[4.6.1](../ch04/4_6_1.md)）|
|デューティ比|`@w`（[6.30](../ch06/6_30.md)。分子だけ）|
|番号|`@@`・`@`（音源と音色）、`@ea`、`@lp`・`@lq`・`@la`・`@lb`・`@ly`、`@fd`、`@bf`|

- これら以外のコマンド（`vs`・`ps`・`mv`・`p`・`@fs`・`@ph`・`@ap` など）をレイヤーに書くとエラーになります。これらはトラックの値だけを使います。
- 数値のコマンド：  
`v` と `vl` は、ノートオンの時点のトラックの `vs`（[4.7](../ch04/4_7n8.md)）の目盛りで数えます。結果は `vs` の範囲（0 〜 最大値）に収めます。0 になったときは `vs` の `v0act`・`vl0act` に従います。`type=table` の `vs` では、小数は丸めます。  
`@p` は -100 〜 100 に収めます。`px` は合計してから四捨五入し、0 〜 3 に収めます。
- デューティ比（`@w`）：  
レイヤーに書く値は、`@w` の分子です。分母は、ノートオンの時点のトラックの分母を使います。分母を変えたいときは、トラックに `@w` を書いてください。  
例：トラックが `@w4,8` なら、`@w+=-2` は 2/8、`@w=6` は 6/8 です。トラックが `@w3,16` に変わると、`@w+=-2` は 1/16、`@w=6` は 6/16 になります。  
キーイベント（[10.3](10_3n4.md)〜[10.8](10_7n8.md)）の `@w` でトラックの分子が変わったときは、その分子に足します。  
合計してから分子÷分母を計算し、`@w` と同じ範囲（0.005 〜 0.995）に収めます。パルス波音源（`@@"pls"`）以外の音源のレイヤーでは、音は変わりません。  
パルス幅をyコマンドＬＦＯ（`@ly`。[8.13](../ch08/8_13n14.md)）で動かしている間は、トラックの `@w` と同じく、ＬＦＯの値で上書きされます。
- 番号のコマンド：  
合計してから四捨五入して、番号として使います。  
結果が未定義の番号（定義の無い `@ea` など）になった場合は、その音符をコンパイルするときにエラーになります。定義の読み込みでは確かめません。

##### 音源と音色（`@@` と `@`）

- レイヤーで音源と音色を指定するときは、`@@=音源名-音色番号` と書きます（例：`@@=pcm-3`、`@@=fms-21`）。音源名は `@@[str]`（[6.1](../ch06/6_1.md)）と同じです。
- `@=音色番号` と書くと、トラックに設定されている音源の音色番号になります。
- `@@_keymap=n`・`@@_velmap=n` は、`map_key_osc`・`map_vel_osc` の n 番を引きます。
- `@_keymap=n`・`@_velmap=n` は、`map_key_val`・`map_vel_val` の n 番で引いた値を、トラックの音源の音色番号として使います。
- 音源と音色は代入だけです。`@@+=`・`@+=` はエラーになります。
- `@@` と `@` を同じレイヤーに両方書くとエラーになります。
- レイヤーごとに違う音源を組み合わせられます（例：`fms` と `pls`、`pcm` と `saw`）。

---

#### マップ（`map_key_val=n` など）：

```
map_key_val=n, [cmpl=0|1,] 音程番号:値, 音程番号:値, ...
map_vel_val=n, [cmpl=0|1,] ベロシティ:値, ベロシティ:値, ...
map_key_osc=n, 音程番号:音源名-音色番号, ...
map_vel_osc=n, ベロシティ:音源名-音色番号, ...
```

- 点は、位置の小さい順に書きます。同じ位置の点が 2 つあるとエラーになります。位置は、音程番号のマップでは 0〜119、ベロシティのマップでは 0〜127 の整数です。
- `cmpl=1`（省略時）：点と点の間は直線で補間します。
- `cmpl=0`：階段にします。その位置以下で最も近い点の値を使います（`@ea` などの番号を選ぶときに使います）。`cmpl` は点より前に書きます。
- 最初の点より手前と、最後の点より先は、端の点の値です。点が 1 つだけなら、どの位置でもその値です。
- `map_key_osc`・`map_vel_osc` は常に階段です。`cmpl=1` を書くとエラーになります。
- マップの番号（0〜9999）は、その `#MB:TONE_LAYER` の定義の中だけで有効です。4 つの種類ごとに別々に数えます。
- レイヤーから参照したマップが同じ定義の中に無いと、定義の読み込みでエラーになります。

---

## 【表示】

### KeyDispへの表示：

KeyDisp には、今までどおりトラックの値が表示されます。レイヤーごとの値は表示されません。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`）と差分（`!m` / `!d`）には、`@pl` の後ろに `@tl1` のように表示されます。`@tlz` の後は `@tlz` と表示されます。  
`@tl` を一度も記述していないトラックでは表示されません。
