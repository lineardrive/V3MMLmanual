# 7.8 `z`：強制ダンパー（消音機能）実行

[← 目次](../index.md)

## 【記述例】

```mml
#MB:ENV_A @ea=1 { peak=15, init=8, |
   n:2:15, n:12:13, r:100:0
}
t120 q16,16 v15 @@"pls" @ea1 l8 o5
crergrer fzr dzr gzr gzr
crergrer fzr dzr g&gzr;
```

上記のように書くと、音符の直後が「`r`」になっている部分はリリース音が残りますが、音符の直後が「`zr`」になっている部分はリリース音が残らず消音されます。

## 【解説】

エンベロープの強制ダンパー（消音機能）を実行します。  
引数はありません。

実行される強制ダンパーは、メタデータ設定 `#MB:CONFIG { z_damper_rate:...}` または、`@zr`コマンドによる設定内容に従います。

当コマンドでは、音量エンベロープ（`@ea`）または、ＦＭ音源（@@"fms"）エンベロープのうち、演奏中であるリリースを臨時的に書き換えて、即時無音までリリースを終結させる用途で使用します。

書き換えたリリースは、次回ノートオンの際、自動的に元のレートに戻されます。

例えば、リリースを長く設定したエンベロープで、ブレイクしたい休符前などに `z`コマンドを配置することで、即時消音したいときに使用します。

【備考】  
スラー中に `z`コマンドを使用した場合は、強制的にスラーが中断（ノートオフ）されて、`z`コマンド直後の音符があらためてノートオンされます。

押鍵中の音（和音記法 `[ ]` の中で、休符で `z` の位置をずらしたときなど）に `z` を使用した場合は、その音はその場でノートオフされます。音量エンベロープ（`@ea`）は強制ダンパーで下がり、ピッチやフィルタのエンベロープはその時点からリリースに入ります。  
後で本来のノートオフの位置が来ても、何も起きません（普通のリリースをやり直しません）。ＦＭ音源（@@"fms"）でも同じです。

```mml
@pl4,0 [c1 e1 r2 z]
```

上記の場合、`c`と`e`は全音符の半分の位置で強制ダンパーが掛かり、そこからノートオフになります。

強制ダンパーで下がっている音は、オートダンパー（`@ad`。[7.14](7_14n15.md)）を受けません。オートダンパーで下がっている途中の音に `z` を使用すると、強制ダンパーに切り替わります。

※この機能は、以前は「エンベロープダンパー」と呼んでいました。
