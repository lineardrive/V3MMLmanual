# 7.13 `#MB:ENVTBL_TIME`：エンベロープの時間の表

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   env_clock: unit=sec: rate=1/1000,        // 1 ＝ 1 ms
}
#MB:ENVTBL_TIME 1 {
   12, [S/DT/C:12:12:6] 81, 89.6, [G..E/C:96:49152:91]
}
#MB:ENV_A @ea=1 { peak=15, init=0, tbl_time=1 | n:X6:15, n:X40:8, r:X20:0 }
```

上記の表は 100 個の値で、添字 0 〜 6 が `12, 12, 24, 36, 48, 60, 72`、添字 7・8 が `81, 89.6`、添字 9 〜 99 が 96 から 49152 までの等比の数列（添字 10 で 2 倍）です。  
エンベロープの節 `n:X6:15` の時間は 表[6] ＝ 72 ms になります。

## 【解説】

エンベロープの節の時間を添字で書く（ENV節の `[rate]` の `X`。[7.4](7_3n4.md)）ときに引く、添字 → 時間の表を定義します。  
音量エンベロープ（`#MB:ENV_A`）・フィルタエンベロープ（`#MB:ENV_FD`。[7.5](7_5n6.md)）・ピッチエンベロープ（`#MB:ENV_P`。[7.11](7_10n11.md)）のどれからも、見出しの `tbl_time` で番号を選んで使います。

```
#MB:ENVTBL_TIME 定義番号 {
   値, 値, 値, …
}
```

- 定義番号は `#MB:ENVTBL_TIME` の直後に書きます（`@ea=` のようなラベルは付けません）。0 〜 9999 の整数で、定義は 1024 個まで書けます。
- 見出しの要素はありません。「`|`」も書きません。本体に値をカンマで並べるだけです。
- 先頭の値が添字 0 です。値の数は 1 〜 1024 個です。
- 値は 0 以上の数です。小数・計算式も書けます。
- 値の単位は書きません。ENV節の `T` の時間と同じ単位（エンベロープクロック。[5.8.4](../ch05/5_8_4.md)・`@eoc`。[7.1](7_1n2.md)）に従います。`T` の節と `X` の節を混ぜても単位がそろい、エンベロープクロックを替えれば表の時間も同じ倍率で変わります。
- 本体では、テーブルの文字列前処理（`[R:]`・`[MW:]`・`[MR:]`・S 系・G 系。[5.14](../ch05/5_14.md)）が使えます。
- 同じ番号を 2 回定義したときは、後に書いたほうが使われます。
- 表はエンベロープの定義より後ろに書いても構いません（全部の `#MB:` を読んだ後に、`tbl_time` の番号と `X` の添字を調べます）。

次の場合はエラーになります。

- 値が無い、負の値がある、値の数が 1024 個を超える。
- 見出しの要素や「`|`」を書いた。
- 定義番号にラベルを付けた、または範囲の外。

## 【使用例】

### 鍵とベロシティで時間を変える

```mml
#MB:ENV_A @ea=1 {
   peak=127, init=97,
   tbl_time=1,
   time_key_idx=0.84375, time_key_center=64,     // 鍵 1 つで添字 0.84375（1 オクターブで約 10）
   time_vel_idx=-0.3515625,                      // vel 1 つで添字 -0.3515625
   time_idx_rd=ceil, |
   n:X6:107:v, n:X29:121:k, n:X78:110:k, r:X32:0
}
```

アタック（添字 6）はベロシティだけで、ディケイ（添字 29・78）は鍵だけで添字をずらします。リリースはずらしません。  
ずらした添字が表の範囲の外になったときは、端（0 または 99）の時間になります。  
計算と値の表は [7.4](7_3n4.md) の「表の添字で時間を持つ要素」を参照してください。
