# 7.7 `@zr[str],[1]`：強制ダンパーの設定

[← 目次](../index.md)

## 【記述例】

```mml
@zr"env",0.1
```

上記のように書くと、音量エンベロープ（`@ea`）の強制ダンパーのレートを 0.1 に設定します。

```mml
@zr"fms",12
```

この場合、ＦＭ音源（@@"fms"）の音量エンベロープの強制ダンパーのレートを 12 に設定します。

## 【解説】

音量エンベロープの、強制ダンパー（消音機能）の設定を行います。  
当コマンドは、`z`コマンド および `@az`コマンドで実行される強制ダンパーの設定を変更したい場合に利用します。  
オートダンパー（`@ad`。[7.14](7_14n15.md)）の時間とリリースレートは、`@zr` ではなく `#MB:AUTO_DAMPER` の定義で決めます。

トラック先頭における初期設定は、`#MB:CONFIG { z_damper_rate:...}` の初期値に従います（[5.8.9](../ch05/5_8_9.md)）。`z_damper_rate` を書かなかったときの初期値は、次の通りです。

```mml
#MB:CONFIG { z_damper_rate: env=0.03: fms=15, }
```

指定する引数は次の通りです。

- 引数[str]...宛先（destination）
- 引数[1].....レート（rate）

引数はカンマで区切って指定します。

---

### 引数[str]（destination）

強制ダンパーの設定の宛先を、３文字の識別子で指定します。

#### `@zr[str],[1]`：宛先の識別子一覧

|識別子|宛先|
|:-:|:-|
|env|`@ea`コマンドの音量エンベロープ|
|fms|ＦＭ音源（@@"fms"）のエンベロープ|

---

### 引数[1]（rate）

強制ダンパーのレートを指定します。

#### destination が「env」のとき

rateは 0 以上の数値で指定します。小数点以下の指定も受け付けます。  
指定値はエンベロープ定義内における変化率（ I のモード）によるレートとして受け付けられます。減衰時間はエンベロープクロック（時間単位）の設定に依存します。

#### destination が「fms」のとき

rateは 0 〜 15 の整数で指定します。  
強制ダンパー実行時に、全てのオペレータのリリースレートが、指定値に書き換えられます。

#### ＦＭ音源のリリースレートと、音が０になるまでの時間

最大の音量（ＥＧの減衰量 0）から、音が０になる（減衰量が 1016 に達する）までの時間の目安です。  
マスタークロックが初期設定（3579545 Hz。[5.8.10](../ch05/5_8_10.md)）、キースケール（KS）が 0 のときの値です。  
低い音は左の列、高い音ほど右の列に近づきます（KS が 0 でも、音の高さで１〜３段速くなります）。

|リリースレート|低い音|高い音|
|:-:|:-:|:-:|
|0|148.8 秒|89.3 秒|
|1|74.4 秒|44.6 秒|
|2|37.2 秒|22.3 秒|
|3|18.6 秒|11.2 秒|
|4|9.30 秒|5.58 秒|
|5|4.65 秒|2.79 秒|
|6|2.33 秒|1.40 秒|
|7|1163 ms|698 ms|
|8|581 ms|349 ms|
|9|291 ms|174 ms|
|10|145 ms|87 ms|
|11|73 ms|44 ms|
|12|36 ms|22 ms|
|13|18 ms|11 ms|
|14|9.1 ms|6.8 ms|
|15|6.8 ms|6.8 ms|

- 強制ダンパーは、実行した時点の音量から下げ始めるので、音が０になるまでの時間は、この表より短くなります（残りの減衰量に比例します）。
- リリースレートが 1 増えると、時間はおよそ半分になります。
- マスタークロックを変えると、時間はマスタークロックに反比例します。
- オートダンパー（`@ad`）の `fms_rr` も、同じ表で時間を読めます。
