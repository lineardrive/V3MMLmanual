# 7.5 `#MB:ENV_FD`：フィルタエンベロープ定義
# 7.6 （廃止）`@ef[1]`・`#MB:ENV_F`

[← 目次](../index.md)

## 【記述例】

```mml
#MB:ENV_A @ea=1 {
   peak=15, init=0, |
   n:1:15, n:24:13, r:96:0
}
#MB:ENV_FD 1 {
   peak=100, init=0, |
   n:10:100, n:20:100, n:120:30, r:60:0
}
#MB:FILTER_D @fd=0 {
   stages=lpA_lpA_lpB_lpB,
   cutA=164, cutB=33975,
   env_fd1=1, cutA_env_fd1=64,
}

t120 q11,16 v15 @@"pls" @ea1 @fd0
l2 o5 cegefdgg cegefdg&g;
```

上記のように書くと、

- `#MB:ENV_FD` によって、定義番号１番にフィルタエンベロープ内容を割り当てています。
- `#MB:FILTER_D` の `env_fd1=1` によって、動的フィルタ（`@fd0`）の枠に定義番号１番の `#MB:ENV_FD` を入れています。
- `cutA_env_fd1=64` によって、エンベロープの出力が 1 のとき、カットオフ A がおよそ 64 半音上がります。

といった定義と適用を記述できます。

### 【備考】記述例の内容

記述例の `#MB:ENV_FD 1` の内容は次の通りです。

- レベル０で開始。
- 時間１０で最大（１００）。
- 時間２０でレベル１００を維持。
- 時間１２０でレベル３０に減衰。
- 以後レベル３０を維持。

以上の流れをノートオフまで繰り返します。どこでノートオフになるかは音長次第で、ノートオフになったら、次の流れに処理を移します。

- 時間６０でレベル０になる。
- 次のノートオンまでレベル０を維持。

## 【解説】

フィルタエンベロープは、動的フィルタ（`@fd`・`#MB:FILTER_D`。[6.41](../ch06/6_41n42.md)）のカットオフを時間で動かすエンベロープです。  
コマンドで選ぶのではなく、`#MB:FILTER_D` の枠（`env_fd1`・`env_fd2`）に定義番号を書いて使います。1 つの `#MB:FILTER_D` に 2 つまで入れられ、2 つの枠に同じ番号を入れても構いません（別々に動きます）。

- ノートオンで始め、ノートオフでリリース（`R` の節）に入ります。タイ・スラーでは始め直しません。
- 時間の単位と解像度は、エンベロープのクロックと解像度（`env_clock`・`env_resol`、`@eoc`・`@eor`。[7.1](7_1n2.md)）に従います。
- エンベロープの出力（0 〜 1）を、`#MB:FILTER_D` の量の欄（`cutA_env_fd1` など）に掛けてカットオフに足します。動的フィルタは、ＬＦＯの解像度の区切りごとに、そのときの出力を読みます。
- `#MB:ENV_A` と同じく、ベロシティと鍵で形を変える要素（`vel_curve`・`vel_curve_val`・`vel_depth`・`time_key`・`time_key_center`・`time_vel`）と、ENV節の印 `[mark]`、表の添字で時間を持つ要素（`tbl_time`・`time_key_idx`・`time_vel_idx`・`time_idx_rd` と `X` の節）を書けます（[7.4](7_3n4.md)）。高さの倍率 G を掛けると、境目が動く量が G 倍になります。

### フィルタエンベロープ定義（`#MB:ENV_FD`）：

動的フィルタの枠（`env_fd1`・`env_fd2`）で使用する、フィルタエンベロープ設定を定義します。

フィルタエンベロープ定義方法の概要は、次の通りです。

- 行頭からの記述で、キーワード「`#MB:ENV_FD`」を書く。
- 続けて、スペースを置き、定義番号を書く（`#MB:ENV_A` と違い、「@ea=」のようなラベルは付けません。付けるとエラーになります）。
- 続けて、スペースを置き、中括弧「{ }」で括られた設定データを書く。

---

### 定義番号：

定義番号は、`#MB:FILTER_D` の `env_fd1`・`env_fd2` に書く番号と合致するように定義します。  
定義番号の設定範囲は 0 〜 9999 です。  
`#MB:ENV_FD` の定義は 1024 個までです。超えるとエラーになります。

---

### 設定データ：

#### 【記述例】

```mml
#MB:ENV_FD 1 {
   peak=100, init=0, |
   n:10:100, n:20:100, n:120:30, r:60:0
}
```

#### 【解説】

フォーマットは次の通りです。

```
#MB:ENV_FD 定義番号 {
   peak=[], offset=[], init=[], |
   [ENV節],[ENV節],...（少なくとも２個以上のENV節）
}
```

設定データの各要素は、カンマで区切って記述します。  
最後のカンマは、あってもなくても構いません。  
スペースや改行は読み飛ばされます。

設定データの内容は、次の要領で記述します。

- エンベロープ全体に関わる設定を「項目名=値,」の形式で列挙します。
- 「`|`」記号で区切ります。この区切りは必須です。全体情報と`ENV節`情報を区切ります。
- `ENV節`の設定を「`[ptr]:[rate]:[lv],`」の形式で列挙します。

---

#### 要素 `peak`：

`peak=[]`では、エンベロープの出力レベルの最大値を、0 より大きい値で指定します。  
小数点以下の指定も受け付けます。

出力レベルの計算結果は、0 〜 1 の浮動小数点数で内部管理されています。  
※データ定義内で指定される出力レベル値を、`peak`値で除算し、0 〜 1 に変換して使っています。

```
ただし、出力レベルの計算結果として、次の式の結果が、0 〜 1 の範囲に収まらない場合はエラーになります。
    (レベル値 + offset値) ÷ peak値
```

---

#### 要素 `offset`：（省略可能。省略時の値は0）

`offset=[]`では、エンベロープの出力レベルに対するオフセット値を指定します。オフセット値の加算は、`peak`値による除算を行う前に実行されます。  
小数点以下の指定も受け付けます。負数も指定できます。

```
フィルタエンベロープでは、音量エンベロープと違い、リリース最終節のレベルをゼロにする必要はありません。
``` 

---

#### 要素 `init`：

`init=[]`では、エンベロープ開始時点の出力レベルを、数値または「`&`」記号で指定します。

- 「`&`」を指定したとき：  
ノートオン時の初期レベルが、直前までの演奏による出力レベルを引き継いだ値になります。

- 数値を指定したとき：  
ノートオン時の初期レベルが、指定した数値になります。  
数値の指定範囲は、0 〜 `peak`値 です。  
小数点以下の指定も受け付けます。

---

#### `ENV節`：

`ENV節`は、「:」で区切られた３個１組のパラメータを、「,」区切りで複数列挙したものです。

`ENV節`は、２組以上定義します。（最大2048組まで）

２組とは、最低でもエンベロープ開始時点の節と、リリース開始時点の節が必要なためです。

`ENV節`内の要素の名前を、次のように決め、それぞれについて説明します。

```
[ptr]:[rate]:[lv],
```

---

#### ENV節の要素`[ptr]`：

`[ptr]`には、今回のエンベロープ節の種類を、`N`、`L`、`R` の３択で指定します（大文字でも小文字でも指定可能）。

- `N`：通常のエンベロープの節
- `L`：ループエントリのエンベロープの節
- `R`：リリースエントリのエンベロープの節

`L` の節は、`R` より前の節で定義しなければなりません。

`L` の節は、１つのエンベロープ定義で１回だけ使用できますが、０回でも構いません。

`R` の節は、１つのエンベロープ定義で１回だけ、必ず使用しなければなりません。

`L` の節は、`R` の直前の節を、サスティンの末尾と解釈することで、サスティンの末尾の節から `L` の節へ無条件ジャンプするポイントになりますが、`L` の節が、サスティン末尾であった場合、ループリクエストは無視されます。（自分自身にループジャンプはしません）

---

#### ENV節の要素`[rate]`：

`[rate]`には、今回のエンベロープ節における変化レートを、0 以上の数値で指定します。  
小数点以下の指定も受け付けます。

変化レートの数値は、先頭１文字のアルファベット（大文字小文字問わず）でモード指定を記述することで、２種類の解釈がなされます。

モード指定は省略可能で、省略した場合、`T` を指定したものとみなされます。

##### `T`（ティー）を指定したとき：

`[rate]`の解釈を、時間（time）とします。  
変化時間を固定的に指定します。  
時間の単位は、`#MB:CONFIG`または `@eoc`コマンドの、エンベロープクロック設定に依存します。
このモードでは、ディケイ時など、始点レベルと到達点レベルの差が毎回固定的な場合は変化の傾きが一定になりますが、リリース時など、始点レベルと到達点レベルの差が一定でない場合は、時間が固定される都合、変化の傾きが変わります。

##### `I`（アイ）を指定したとき：

`[rate]`の解釈を、変化率（勾配:incline）とします。
時間当たりの変化量を、  
`最大変化量 ÷ rate値`  
で求めることで、固定化された変化量を設定できます。

そのため、リリース時など、始点レベルと到達点レベルの差が一定でない場合は、変化の傾きが固定される都合、時間が変わります。

`[rate]`の値が大きいほどゆっくり推移します。  
0 のときは時間 0 で推移終了します。

【例１】変化率３の記述。

```
I3
```

【例２】時間１０の記述。

```
10
```

上記の例では`T`が省略されている状態。

---

#### ENV節の要素`[lv]`：

`[lv]`には、今回のエンベロープ節における到達点レベルを、数値で指定します。  
数値の指定範囲は、0 〜 `peak`値 です。  
小数点以下の指定も受け付けます。

前回のレベルと今回のレベルが同じ場合で、  
`[rate]` が `I0` または `T0` の場合、  
時間 0 で何もせず次のエンベロープ節に移ります。

---

### （廃止）`@ef[1]`・`#MB:ENV_F`：

フィルタエンベロープコマンド `@ef` と、その定義 `#MB:ENV_F` は廃止しました。書くとエラーになります。  
フィルタエンベロープは `#MB:ENV_FD` で定義し、`#MB:FILTER_D` の枠（`env_fd1`・`env_fd2`）に番号を書いて使います。  
`#MB:ENV_F` の設定データ（`peak`・`offset`・`init`・ENV節）は、そのまま `#MB:ENV_FD` に書けます。
