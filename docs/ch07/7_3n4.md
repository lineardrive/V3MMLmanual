# 7.3 `@ea[1]`：音量エンベロープ
# 7.4 `#MB:ENV_A`：音量エンベロープ定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:ENV_A @ea=1 {
   peak=15, init=8, |
   n:2:15, n:12:10, n:30:10, n:10:12, l:10:8, n:10:12,
   r:i1:6, n:40:6, n:1:0
}
t100 q11,16 v15 @@"pls" @ea1
l2 o5 cegefdgg cegefdg&g;
```

上記のように書くと、

- `#MB:ENV_A` によって、定義番号１番に音量エンベロープ内容を割り当てています。
- `@ea1`によって、定義番号１番の `#MB:ENV_A` の内容を適用しています。

といった定義と適用を記述できます。

### 【備考】記述例の内容

記述例の `@ea1` エンベロープ定義の内容は次の通りです。

- 音量８で開始。
- 時間２で最大（１５）。
- 時間１２でレベル１０。
- 時間３０でレベル１０維持。
- 時間１０でレベル１２。
- ｛繰り返し開始｝時間１０でレベル８。
- 時間１０でレベル１２。
- 繰り返し開始にジャンプ。

以上の流れをノートオフまで繰り返します。どこでノートオフになるかは音長次第で、ノートオフになったら、次の流れに処理を移します。

- レート１でレベル６。
- 時間４０でレベル６維持。
- 時間１でレベル０。
- 次のノートオンまでレベル０を維持。

## 【解説】

### 音量エンベロープコマンド（`@ea[1]`）：

引数[1]には、音量エンベロープ定義（`#MB:ENV_A`）の定義番号を整数で指定します。  
定義番号は 0 〜 9999 の整数です。  
未定義の番号を指定するとエラーになります。

トラック先頭における初期設定には定義番号は無く、システム側で用意された暫定的な音量エンベロープが掛かっています。

```
@@"fms"（ＦＭ音源）には、@eaコマンド は無効です。
@@"fms"では音色データ定義内のエンベロープを使用します。
```

---

### 音量エンベロープ定義（`#MB:ENV_A`）：

音量エンベロープコマンド（`@ea[1]`）で使用する、音量エンベロープ設定を定義します。
音量エンベロープ定義方法の概要は、次の通りです。

- 行頭からの記述で、キーワード「`#MB:ENV_A`」を書く。
- 続けて、スペースを置き、「@ea=定義番号」を書く。
- 続けて、スペースを置き、中括弧「{ }」で括られた設定データを書く。

---

### 定義番号：

定義番号は、`@ea`コマンドの引数で使用する番号と合致するように定義します。  
定義番号の設定範囲は 0 〜 9999 です。  
`#MB:ENV_A` の定義は 1024 個までです。超えるとエラーになります。

---

### 設定データ：

#### 【記述例】

```mml
#MB:ENV_A @ea=1 {
   peak=15, offset=0, init=8, |
   n:2:15, n:12:10, n:30:10, n:10:12, l:10:8, n:10:12,
   r:i1:6, n:40:6, n:1:0
}
```

#### 【解説】

フォーマットは次の通りです。

```
#MB:ENV_A @ea=定義番号 {
   peak=[], offset=[], init=[],
   vel_curve=[], vel_curve_val=[], vel_depth=[],   （省略可能：ベロシティで高さを変える）
   time_key=[], time_key_center=[], time_vel=[],   （省略可能：鍵とベロシティで時間を変える）
   tbl_time=[], time_key_idx=[], time_vel_idx=[], time_idx_rd=[],   （省略可能：表の添字で時間を持つ）
   |
   [ENV節],[ENV節],...（少なくとも２個以上のENV節）
}
```

設定データの各要素は、カンマで区切って記述します。  
最後のカンマは、あってもなくても構いません。  
スペースや改行は読み飛ばされます。

設定データの内容は、次の要領で記述します。

- エンベロープ全体に関わる設定を「項目名=値,」の形式で列挙します。
- 「`|`」記号で区切ります。この区切りは必須です。全体情報と`ENV節`情報を区切ります。
- `ENV節`の設定を「`[ptr]:[rate]:[lv],`」または「`[ptr]:[rate]:[lv]:[mark],`」の形式で列挙します。

---

#### 要素 `peak`：

`peak=[]`では、エンベロープの出力レベルの最大値を、0 より大きい値で指定します。  
小数点以下の指定も受け付けます。

出力レベルの計算結果は、0 〜 1 の浮動小数点数で内部管理されています。  
※データ定義内で指定される出力レベル値を、`peak`値で除算し、0 〜 1 に変換して使っています。

```
ただし、出力レベルの計算結果として、次の式の結果が、0 〜 1 の範囲に収まらない場合はエラーになります。
    (レベル値 + offset値) ÷ peak値
```

---

#### 要素 `offset`：（省略可能。省略時の値は0）

`offset=[]`では、エンベロープの出力レベルに対するオフセット値を指定します。オフセット値の加算は、`peak`値による除算を行う前に実行されます。  
小数点以下の指定も受け付けます。負数も指定できます。

```
音量エンベロープでは、リリース中の無限演奏状態を避けるため、リリース最終節のレベルをゼロにしなければならない制限があります。  
そのため、オフセット値を 0 以外にした場合、オフセット値×(-1)のレベルでリリース最終節を終わらせる必要がある点に注意してください。
```

---

#### 要素 `init`：

`init=[]`では、エンベロープ開始時点の出力レベルを、数値または「`&`」記号で指定します。

- 「`&`」を指定したとき：  
ノートオン時の初期レベルが、直前までの演奏による出力レベルを引き継いだ値になります。

- 数値を指定したとき：  
ノートオン時の初期レベルが、指定した数値になります。  
数値の指定範囲は、0 〜 `peak`値 です。  
小数点以下の指定も受け付けます。

---

#### ベロシティと鍵で形を変える要素：（省略可能）

次の要素を書くと、ノートオンのたびに、その音符のベロシティ（`vel`。[4.17](../ch04/4_17.md)）と鍵（音程番号。`o5c` ＝ 60）で、エンベロープの高さと時間を変えます。  
1 つも書かなければ、今までと同じ動きです。

```
#MB:ENV_A @ea=1 {
   peak=15, init=0,
   vel_curve=linear, vel_depth=100,           // ベロシティで高さを変える
   time_key=0.5, time_key_center=60,          // 鍵で、印 k の節の時間を変える
   time_vel=0.5, |                            // ベロシティで、印 v の節の時間を変える
   n:20:15:v, n:300:10:k, r:200:0
}
```

|要素|意味|範囲|書かないとき|
|:-|:-|:-|:-|
|`vel_curve`|ベロシティの曲線の名前（下の表）|`sat`・`convex`・`linear`・`concave`|効かない|
|`vel_curve_val`|曲線の名前に対する追加の設定値。`sat` では頭打ちの位置（`vel` の値の目盛り）|`sat`：0 より大きく `velocity: peak` 以下|追加の設定値を持たない曲線では書かない|
|`vel_depth`|最も弱いとき（r ＝ 0）に、高さがどれだけ下がるか（%）|0 〜 100|効かない|
|`time_key`|鍵 1 オクターブ上で、印 `k` の節の時間が何倍になるか|0 より大きい数（1 で効かない）|効かない|
|`time_key_center`|`time_key` の倍率が 1 になる鍵（`o5c` ＝ 60）|0 〜 127 の整数|60|
|`time_vel`|最も強いとき（r ＝ 1）に、印 `v` の節の時間が何倍になるか（r ＝ 0 で 1 倍）|0 より大きい数（1 で効かない）|効かない|

r はベロシティの割合（`vel` ÷ `velocity: peak`。[5.8.17](../ch05/5_8_17.md)）です。数値の要素は小数も書けます（`time_key_center` を除く）。

##### 高さ：

```
G ＝ 1 − (1 − 曲線(r)) × vel_depth ÷ 100
レベル ＝ ([lv] × G ＋ offset) ÷ peak
```

`init` の数値と各節の `[lv]` を G 倍してから `offset` を足し、`peak` で割ります（`init=&` で引き継いだ値は G 倍しません）。結果が 0 〜 1 の外になったとき（`offset` が負のときに起こります）は、0 〜 1 に収めます。範囲の検査は、G ＝ 1 として行います。

|`vel_curve`|曲線(r)|
|:-|:-|
|`sat`|`vel_curve_val` で頭打ちになる直線（`vel` が `vel_curve_val` 以上で 1）|
|`convex`|上に凸（弱い所で大きく変わる）。下の点を直線でつなぐ|
|`linear`|r（直線）|
|`concave`|下に凸（強い所で大きく変わる）。下の点を直線でつなぐ|

|`vel`（r ＝ `vel` ÷ 127）|0|16|32|48|64|80|96|112|127|
|:-|-:|-:|-:|-:|-:|-:|-:|-:|-:|
|`convex`（× 1/127）|0|27|50|69|85|99|110|119|127|
|`concave`（× 1/127）|0|4|9|16|26|40|60|89|127|

`vel_curve` と `vel_depth` は、両方書くか両方書かないかのどちらかです。

値と効果（`velocity: peak=127` のとき。高さの倍率 G）：

|`vel_curve` / `vel_depth`|`vel0`|`vel32`|`vel64`|`vel95`|`vel127`|
|:-|-:|-:|-:|-:|-:|
|`linear` / 100|0|0.25|0.50|0.75|1|
|`linear` / 50|0.50|0.63|0.75|0.87|1|
|`sat`（64）/ 100|0|0.50|1|1|1|
|`convex` / 100|0|0.39|0.67|0.86|1|
|`concave` / 100|0|0.07|0.20|0.46|1|
|`convex` / 13.3|0.87|0.92|0.96|0.98|1|

音量のエンベロープ（`#MB:ENV_A`）なら音の大きさ、フィルタのエンベロープ（`#MB:ENV_FD`）なら境目が動く量が G 倍になります。  
例：`linear` / 100 なら、`vel64` でエンベロープの高さが半分になります（音量スケールが linear のとき約 -6 dB）。

##### 時間：

印（ENV節の 4 つ目の要素。下の `[mark]`）の付いた `T`・`I` の節の `[rate]` に、次の倍率を掛けます。`T`（時間）でも `I`（変化率）でも同じく掛けます。  
`X` の節（表の添字。下の「表の添字で時間を持つ要素」）には倍率を掛けず、添字をずらします。

```
印 k  ：time_key ^ ((鍵 − time_key_center) ÷ 12)
印 v  ：time_vel ^ r
印 kv ：上の 2 つの積
```

値と効果（`time_key_center=64` のとき。印 `k` の節の時間の倍率）：

|`time_key`|鍵 40|52|64|76|88|聞こえ方|
|:-|-:|-:|-:|-:|-:|:-|
|0.5|4 倍|2 倍|1|0.5 倍|0.25 倍|高い音ほど速い|
|1|1|1|1|1|1|鍵によらない|
|4.07|0.06 倍|0.25 倍|1|4.1 倍|16.6 倍|高い音ほどゆっくり|

値と効果（印 `v` の節の時間の倍率）：

|`time_vel`|`vel0`|`vel32`|`vel64`|`vel95`|`vel127`|聞こえ方|
|:-|-:|-:|-:|-:|-:|:-|
|1|1|1|1|1|1|ベロシティによらない|
|0.5|1|0.84 倍|0.71 倍|0.60 倍|0.5 倍|強いと少し速い|
|0.045|1|0.46 倍|0.21 倍|0.10 倍|0.045 倍|強いとすぐ立ち上がる|
|2|1|1.19 倍|1.42 倍|1.68 倍|2 倍|強いほどゆっくり|

- 印 `k` の `T`・`I` の節があるのに `time_key` が無い、印 `v` の `T`・`I` の節があるのに `time_vel` が無い（`kv` はどちらも要る）とエラーになります。
- `time_key`・`time_vel` を書いたのに、その印の `T`・`I` の節が 1 つも無いとエラーになります。`time_key_center` だけを書いて、`time_key` も `time_key_idx` も無いときもエラーです。

##### 倍率を決める時機：

- ノートオンで 1 回だけ求め、その音符の間（リリースも含む）使います。
- タイ・スラーでエンベロープを始め直さないときは、最初の音符の値のままです。タイの中で `@ea` を書き直したとき（始め直したとき）は、そのときの音符の鍵と `vel` を使います。
- `vel` を書かない曲では r ＝ 1 なので、`vel_curve` は効きません（G ＝ 1）。`time_vel` は r ＝ 1 で最も効くので、常に `time_vel` 倍になります。
- 音色のレイヤー（`@tl`）では、どのレイヤーのエンベロープにも同じ鍵と `vel` を使います。

---

#### 表の添字で時間を持つ要素：（省略可能）

節の時間を、時間の表（`#MB:ENVTBL_TIME`。[7.13](7_13.md)）の添字で書きます。印の付いた節では、鍵とベロシティで添字をずらしてから表を引きます。  
エンベロープの速さを番号で持ち、番号をずらしてから表で時間に直す音源の動き（表がきれいな指数の形でない、端で止まる、ずらしが整数に丸められる、など）を、そのまま書けます。

```
#MB:ENVTBL_TIME 1 {
   12, [S/DT/C:12:12:6] 81, 89.6, [G..E/C:96:49152:91]     // 100 個の時間
}
#MB:ENV_A @ea=1 {
   peak=127, init=97,
   tbl_time=1,                                       // X の節が引く表
   time_key_idx=0.84375, time_key_center=64,         // 鍵で、印 k の X の節の添字をずらす
   time_vel_idx=-0.3515625,                          // ベロシティで、印 v の X の節の添字をずらす
   time_idx_rd=ceil, |                               // ずらしの小数を切り上げる
   n:X6:107:v, n:X29:121:k, n:X78:110:k, r:X32:0
}
```

|要素|意味|範囲|書かないとき|
|:-|:-|:-|:-|
|`tbl_time`|`X` の節が引く表（`#MB:ENVTBL_TIME`）の番号|0 〜 9999 の整数|`X` の節は書けない|
|`time_key_idx`|鍵 1 つで、印 `k` の `X` の節の添字がいくつ増えるか|数（負・小数も可）|印 `k` の `X` の節は書けない|
|`time_vel_idx`|`vel` 1 つで、印 `v` の `X` の節の添字がいくつ増えるか|数（負・小数も可）|印 `v` の `X` の節は書けない|
|`time_idx_rd`|ずらしの小数の丸め方|`ceil`・`floor`・`round`|`floor`|

`time_key_center`（書かなければ 60）は、`T`・`I` の節の `time_key` と `X` の節の `time_key_idx` の両方に効きます。

##### 計算：

```
ずらし_k ＝ 丸め( time_key_idx × (鍵 − time_key_center) )      … 印 k・kv の X の節
ずらし_v ＝ 丸め( time_vel_idx × vel )                          … 印 v・kv の X の節
添字     ＝ 書いた添字 ＋ ずらし_k ＋ ずらし_v  を、0 〜（表の値の数 − 1）に収める
時間     ＝ 表[添字]
```

- 鍵は音程番号（`o5c` ＝ 60）、`vel` は書いた `vel` の値（0 〜 `velocity: peak`。[5.8.17](../ch05/5_8_17.md)）です。割合 r ではありません。`velocity: peak` を替えたときは、`time_vel_idx` も同じ倍率で替えてください。
- ずらし_k とずらし_v は、それぞれ丸めてから足します。収めるのは足した後の 1 回だけです。
- 積は 1e-9 の桁に丸めてから整数にします（`0.14 × 50` が `7.000000000000001` になって、切り上げで 8 にならないように）。
- 印の無い `X` の節は、書いた添字のまま表を引きます。
- 求める時機は、上の「倍率を決める時機」と同じです（ノートオンで 1 回）。

|`time_idx_rd`|丸め方|-2.5|-2.3|2.3|2.5|
|:-|:-|-:|-:|-:|-:|
|`ceil`|切り上げ（+∞ の方向）|-2|-2|3|3|
|`floor`|切り捨て（-∞ の方向）|-3|-3|2|2|
|`round`|四捨五入（0.5 は 0 から遠い側）|-3|-2|2|3|

値と効果（`time_idx_rd=ceil`・`time_key_center=64`。表は上の記述例の表で、添字 9 〜 99 では「添字 10 で時間 2 倍」）：

|`time_key_idx`|1 オクターブで添字|添字 9 〜 99 での時間（1 オクターブ上で）|鍵 40 / 52 / 64 / 76 / 88 のずらし|聞こえ方|
|:-|-:|-:|:-|:-|
|-1.96875|-23.625|0.19 倍|+48 / +24 / 0 / -23 / -47|高い鍵ほどずっと短い|
|-0.28125|-3.375|0.79 倍|+7 / +4 / 0 / -3 / -6|高い鍵ほど少し短い|
|0|0|1 倍|0|変わらない|
|0.84375|+10.125|2.02 倍|-20 / -10 / 0 / +11 / +21|高い鍵ほど長い（約 2 倍ずつ）|
|2.25|+27|6.50 倍|-54 / -27 / 0 / +27 / +54|高い鍵ほどずっと長い|

添字 8 以下と両端では、時間は表のとおりです（倍率では表せません）。

値と効果（`time_idx_rd=ceil`・`velocity: peak=127`。添字 6 ＝ 72 の節）：

|`time_vel_idx`|`vel32` / `vel64` / `vel127` のずらし|時間（`vel32` / `vel64` / `vel127`）|聞こえ方|
|:-|:-|:-|:-|
|-0.0703125|-2 / -4 / -8|48 / 24 / 12|強いほど少し速い立ち上がり|
|-0.3515625|-11 / -22 / -44|12 / 12 / 12|少し強ければもう最短|
|-0.9921875|-31 / -63 / -126|12 / 12 / 12|ほとんどの `vel` で最短|

次の場合はエラーになります。

- `X` の節があるのに `tbl_time` が無い。`tbl_time` を書いたのに `X` の節が無い。
- `tbl_time` の番号の `#MB:ENVTBL_TIME` が無い（全部の `#MB:` を読んだ後に調べるので、表はエンベロープの後ろに書いても構いません）。
- `X` の添字が整数でない、負、表の値の数以上。
- 印 `k`（`kv`）の `X` の節があるのに `time_key_idx` が無い。`time_key_idx` を書いたのに印 `k`（`kv`）の `X` の節が無い。`time_vel_idx` も同じです。
- `time_idx_rd` を書いたのに、印のある `X` の節が無い。`ceil`・`floor`・`round` 以外の値。

---

#### `ENV節`：

`ENV節`は、「:」で区切られた３個（または４個）１組のパラメータを、「,」区切りで複数列挙したものです。

`ENV節`は、２組以上定義します。（最大2048組まで）

２組とは、最低でもエンベロープ開始時点の節と、リリース開始時点の節が必要なためです。

`ENV節`内の要素の名前を、次のように決め、それぞれについて説明します。

```
[ptr]:[rate]:[lv],
[ptr]:[rate]:[lv]:[mark],
```

---

#### ENV節の要素`[ptr]`：

`[ptr]`には、今回のエンベロープ節の種類を、`N`、`L`、`R` の３択で指定します（大文字でも小文字でも指定可能）。

- `N`：通常のエンベロープの節
- `L`：ループエントリのエンベロープの節
- `R`：リリースエントリのエンベロープの節

`L` の節は、`R` より前の節で定義しなければなりません。

`L` の節は、１つのエンベロープ定義で１回だけ使用できますが、０回でも構いません。

`R` の節は、１つのエンベロープ定義で１回だけ、必ず使用しなければなりません。

`L` の節は、`R` の直前の節を、サスティンの末尾と解釈することで、サスティンの末尾の節から `L` の節へ無条件ジャンプするポイントになりますが、`L` の節が、サスティン末尾であった場合、ループリクエストは無視されます。（自分自身にループジャンプはしません）

---

#### ENV節の要素`[rate]`：

`[rate]`には、今回のエンベロープ節における変化レートを、0 以上の数値で指定します。  
小数点以下の指定も受け付けます。

変化レートの数値は、先頭１文字のアルファベット（大文字小文字問わず）でモード指定を記述することで、３種類の解釈がなされます。

モード指定は省略可能で、省略した場合、`T` を指定したものとみなされます。

##### `T`（ティー）を指定したとき：

`[rate]`の解釈を、時間（time）とします。  
変化時間を固定的に指定します。  
時間の単位は、`#MB:CONFIG`または `@eoc`コマンドの、エンベロープクロック設定に依存します。  
このモードでは、ディケイ時など、始点レベルと到達点レベルの差が毎回固定的な場合は変化の傾きが一定になりますが、リリース時など、始点レベルと到達点レベルの差が一定でない場合は、時間が固定される都合、変化の傾きが変わります。

##### `I`（アイ）を指定したとき：

`[rate]`の解釈を、変化率（勾配:incline）とします。  
時間当たりの変化量を、  
`最大変化量 ÷ rate値`  
で求めることで、固定化された変化量を設定できます。

そのため、リリース時など、始点レベルと到達点レベルの差が一定でない場合は、変化の傾きが固定される都合、時間が変わります。

`[rate]`の値が大きいほどゆっくり推移します。  
0 のときは時間 0 で推移終了します。

##### `X`（エックス）を指定したとき：

`[rate]`の解釈を、時間の表（`#MB:ENVTBL_TIME`。[7.13](7_13.md)）の添字とします。  
添字は 0 以上の整数です（計算式も書けます）。表は見出しの `tbl_time` で選びます。  
節の時間は「表[添字]」で、扱いは `T` と同じ（時間）です。単位も `T` と同じく、エンベロープクロック設定に従います。  
印（`[mark]`）を付けると、鍵とベロシティで添字をずらします（上の「表の添字で時間を持つ要素」）。  
１つの定義の中で、`T`・`I`・`X` の節が混ざって構いません。

【例１】変化率３の記述。

```
I3
```

【例２】時間１０の記述。

```
10
```

この例では `T`が省略されている状態。

【例３】表の添字６の記述。

```
X6
```

#### ENV節の要素`[lv]`：

`[lv]`には、今回のエンベロープ節における到達点レベルを、数値で指定します。  
数値の指定範囲は、0 〜 `peak`値 です。  
小数点以下の指定も受け付けます。

前回のレベルと今回のレベルが同じ場合で、  
`[rate]` が `I0` または `T0` の場合、  
時間 0 で何もせず次のエンベロープ節に移ります。

---

#### ENV節の要素`[mark]`：（省略可能）

`[mark]`には、その節の時間を変える印を、`k`、`v`、`kv` の３択で指定します（大文字でも小文字でも指定可能）。

- `k`：鍵で変える（`T`・`I` の節は `time_key`、`X` の節は `time_key_idx`）
- `v`：ベロシティで変える（`T`・`I` の節は `time_vel`、`X` の節は `time_vel_idx`）
- `kv`：両方

印はどの節（`N`・`L`・`R`）にも付けられます。１つの定義の中で、`[mark]` のある節と無い節が混ざって構いません。  
倍率は「ベロシティと鍵で形を変える要素」を、`X` の節の添字のずらしは「表の添字で時間を持つ要素」を参照してください。
