# 7.10 `@ep[1]`：ピッチエンベロープ
# 7.11 `#MB:ENV_P`：ピッチエンベロープ定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   env_clock: unit=sec: rate=1/1000,
}
#MB:ENV_P @ep=98 {
   peak=127, init=127, pitch_range=-868, base_lv=0, |
   n:2172:0, r:12:0
}
t120 @ep98 o5 c4 d4 e2 @epz f1
```

上記のように書くと、

- `#MB:ENV_P` によって、定義番号９８番にピッチエンベロープ内容を割り当てています。
- `@ep98` によって、`c` `d` `e` は発音の頭が約 8.68 半音下になり、2.172 秒かけて元の音程へ上がります（音符が短いので、途中で次の音符になります）。
- `@epz` の後の `f` は、元の音程のまま鳴ります。

といった定義と適用を記述できます。

## 【解説】

### ピッチエンベロープコマンド（`@ep[1]`）：

ピッチエンベロープ定義（`#MB:ENV_P`）の定義番号を整数で指定します。  
定義番号は 0 〜 9999 の整数です。  
未定義の番号を指定するとエラーになります。  
トラック先頭では、ピッチエンベロープは止まっています（`@epz` の状態）。

ピッチエンベロープは、エンベロープの形（節の並び・離鍵での移り）で音程を動かします。

- ノートオンで始め、ノートオフでリリース（`R` の節）に入ります。タイ・スラーでは始め直しません。
- 音程のずれは、鍵・`@d`・ポルタメント・`@ap`・ピッチＬＦＯ（`@lp`・`@lq`）と足し合わせます。
- ずれは、ＬＦＯの解像度（`lfo_resol`・`@lor`。[5.8.7](../ch05/5_8_7.md)・[8.2](../ch08/8_1n2.md)）の区切りごとに求め直します。区切りの間は一定です。発音の最初のサンプルから `init` のずれが効きます。
- エンベロープ自身の時間の単位と解像度は、エンベロープのクロックと解像度（`env_clock`・`env_resol`、`@eoc`・`@eor`。[7.1](7_1n2.md)）に従います。
- タイ・スラーの中で `@ep` を書いたときは、次の音符で始め直します。
- `pitch_range` が、そのときのピッチスケールで `@d` に書ける範囲（12 平均律の初期設定では半音 -96 〜 +96）の外なら、エラーになります。
- 音色のレイヤー（`@tl`。[10.9](../ch10/10_9n10.md)）・キーイベント（[10.3](../ch10/10_3n4.md)〜[10.8](../ch10/10_7n8.md)）・`xa`（[10.1](../ch10/10_1.md)）の対象です。レイヤーで `@ep=-1` と書くと、そのレイヤーではピッチエンベロープを止めます。

### ピッチエンベロープ定義（`#MB:ENV_P`）：

ピッチエンベロープコマンド（`@ep[1]`）で使用する、ピッチエンベロープ設定を定義します。  
定義方法の概要は、次の通りです。

- 行頭からの記述で、キーワード「`#MB:ENV_P`」を書く。
- 続けて、スペースを置き、「@ep=定義番号」を書く。
- 続けて、スペースを置き、中括弧「{ }」で括られた設定データを書く。

定義番号の設定範囲は 0 〜 9999 です。`#MB:ENV_P` の定義は 1024 個までです。超えるとエラーになります。

### 設定データ：

書き方は `#MB:ENV_A`（[7.4](7_3n4.md)）と同じです（ベロシティと鍵で形を変える要素・ENV節の印 `[mark]` も書けます）。足す要素は次の 2 つです。

```
#MB:ENV_P @ep=定義番号 {
   peak=[], offset=[], init=[], pitch_range=[], base_lv=[],
   （ベロシティと鍵で形を変える要素。省略可能）
   |
   [ENV節],[ENV節],...
}
```

|要素|意味|範囲|書かないとき|
|:-|:-|:-|:-|
|`pitch_range`|出力 1 のときの音程のずれ。単位は `@d` と同じ（ピッチスケールに従う。12 平均律の初期設定で 1 ＝ 1 セント）。負にすれば下向き|数（符号付き。小数も可）|必須|
|`base_lv`|ずれが 0 になるレベル（基準のレベル）|0 〜 `peak`|0|

- 音量エンベロープの「リリース最終節のレベルを 0 にする」決まりは、ピッチエンベロープにはありません。
- エンベロープの出力（(レベル × G ＋ `offset`) ÷ `peak`）は、ほかのエンベロープと同じく 0 〜 1 です。上下に振れる向きは `base_lv` と `pitch_range` の符号で作ります。

#### ずれの計算：

```
ずれ ＝ pitch_range × ((レベル × G ＋ offset) − base_lv) ÷ peak
```

G はベロシティによる高さの倍率（`vel_curve`・`vel_depth`。[7.4](7_3n4.md)）で、書かなければ 1 です。`base_lv` には G を掛けません。

値と効果（12 平均律の初期設定で、`base_lv=0`・`offset=0` のとき）：

|`pitch_range`|出力 1 で|出力 0.5 で|聞こえ方|
|:-|:-|:-|:-|
|100|+1 半音|+0.5 半音|上へずれる|
|-100|-1 半音|-0.5 半音|下へずれる|
|-868|-8.68 半音|-4.34 半音|大きく下から|
|1200|+1 オクターブ|+半オクターブ||
|-37|-37 セント|-18.5 セント|ごく浅い|

値と効果（`peak=127`・`pitch_range=1200` の例。レベル → ずれ）：

|`base_lv`|レベル 0|64|127|聞こえ方|
|:-|-:|-:|-:|:-|
|0|0|+605 セント|+1,200 セント|レベルが上がるほど上へ（片側）|
|64|-605 セント|0|+595 セント|レベル 64 を中心に上下へ|
|127|-1,200 セント|-595 セント|0|レベルが下がるほど下へ（片側）|

値と効果（`vel_curve=linear`・`vel_depth=100`・`pitch_range=-868`・`base_lv=0`・`init=127` の例。初めのずれ）：

|`vel`|`vel0`|`vel32`|`vel64`|`vel95`|`vel127`|
|:-|-:|-:|-:|-:|-:|
|初めのずれ|0|-2.19 半音|-4.37 半音|-6.49 半音|-8.68 半音|

`base_lv` が 0 でないときは、`base_lv` に G を掛けないので、弱いほど `base_lv` の側へ寄る形にはならず、レベルだけが縮みます（例：`base_lv=64`・`vel64` なら、レベル 127 → 64 で、ずれは 0）。

## 【表示】

### KeyDispへの表示：

`@ep98 ` のように、定義番号が表示されます。`@epz` のときは表示されません。  
KeyDisp の音程の表示にも、ピッチエンベロープのずれが入ります。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`）と差分（`!m` / `!d`）には、`@ep98` / `@epz` のように表示されます。
