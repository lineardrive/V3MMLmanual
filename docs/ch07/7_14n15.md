# 7.14 `@ad[1]`：オートダンパー
# 7.15 `#MB:AUTO_DAMPER`：オートダンパー定義

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG {
   env_clock: unit=sec: rate=1/1000,
}
#MB:ENV_A @ea=1 { peak=15, init=15, | n:0:15, r:800:0 }
#MB:AUTO_DAMPER @ad=1 { key=any, pick=oldest, again=0, time=102.9 }
#MB:AUTO_DAMPER @ad=2 { key=same, pick=all, again=1, time=12, time_older=102.9 }
t120 q16,16 v15 @@"pls" @ea1 @pl4,0 l8 o4
@ad1 cdefgfed
@ad2 c4 [e4 g4] c4 [e4 g4]
@ad0 cdefgfed
```

上記のように書くと、

- `@ad1` の後は、音を鳴らすたびに、リリース中の前の音のうち最も古い１つが、102.9 msec で消えます（自然のリリースは 800 msec）。
- `@ad2` の後は、同じ音程のリリース中の音が消えます。最も新しいものは 12 msec、それより古いものは 102.9 msec で消えます。
- `@ad0` の後は、前の音は自然のリリースのまま鳴ります。

といった定義と適用を記述できます。

## 【解説】

### オートダンパーコマンド（`@ad[1]`）：

新しい音を鳴らすたびに、同じトラックでリリース中の前の音を選び、そのリリースを「今の高さから 0 まで、決まった時間で下げる」リリースに置き換えます。  
特定ドライバの、新しい音の前に、離鍵した後の音のリリースを速く終わらせ直す動きを写すための機能です。

引数[1]には、オートダンパー定義（`#MB:AUTO_DAMPER`）の定義番号を指定します。

- `@ad0` は、オートダンパーをやめます。トラック先頭における初期設定は、`@ad0` です。
- `@ad` はトラックの状態です。一度指定すると、次に指定し直すまで、以降のすべての音符に効きます。
- `@ad`を書いた時点では何もしません。次のノートオンから効きます。
- `@ad`コマンドは時間を消費しません。

オートダンパーは、ポリフォニックモード（`@pl`。[9.1](../ch09/9_1.md)）のトラックで働きます。

- `@pl` を書いていないトラックや、`@pl1` のトラックでは、`@ad` を書いても何も起きません（エラーにもなりません）。新しい音が同じ発音を鳴らし直すので、置き換える相手が残らないためです。
- `@pl1` の間に書いた `@ad` は覚えておき、`@pl` を 2 以上に増やすと、そこからのノートオンで効きます。

### 強制ダンパーとの違い：

|コマンド|呼び名|いつ効くか|
|:-|:-|:-|
|`z`|強制ダンパー（[7.8](7_8.md)）|書いた位置で、鳴っている音すべてに|
|`@az`|オート強制ダンパー（[7.9](7_9.md)）|書いた後、次のノートオンの手前で、鳴っている音すべてに|
|`@ad`|オートダンパー|書いた後、新しい音のノートオンのたびに、定義の条件に合うリリース中の音にだけ|

強制ダンパーとオートダンパーの両方が有効になる書き方は、指定の誤りですが、エラーにはなりません。KeyDisp に `@az` と `@ad` が両方表示されるので、それを見て直してください。

---

### オートダンパー定義（`#MB:AUTO_DAMPER`）：

```mml
#MB:AUTO_DAMPER @ad=定義番号 { 要素=値, 要素=値, ... }
```

定義番号は 1 〜 999 です（0 番は `@ad0` が「やめる」の意味なので、定義できません）。  
同じ定義番号を２回書いた場合は、後に書いたものが有効になります。

#### 定義の要素：

|要素|値|効き方|省略したとき|
|:-|:-|:-|:-|
|`key`|`same`|新しい音と同じ音程番号の音だけを選ぶ|エラー（必ず書く）|
||`any`|音程を問わない||
|`layer`|`same`|新しい音で鳴らすレイヤーと同じレイヤー番号の音だけを選ぶ|`same`|
||`any`|レイヤー番号を問わない||
|`@tl`|`same`|新しい音と同じ `@tl` の番号で鳴らした音だけを選ぶ|`same`|
||`any`|`@tl` の番号を比べない||
|`pick`|`all`|条件に合うものを全部選ぶ|`all`|
||`oldest`|条件に合うもののうち、最も前に離鍵した１つだけ||
||`newest`|条件に合うもののうち、最も後に離鍵した１つだけ||
|`again`|`0`|オートダンパーで下がっている途中の音は選ばない|`0`|
||`1`|オートダンパーで下がっている途中の音も選び、今の高さから置き換え直す||
|`time`|0 以上の msec（小数可）|選んだもののうち、最も後に離鍵したものを 0 にする時間|エラー（必ず書く）|
|`time_older`|0 以上の msec（小数可）|２つ以上選んだとき、それより前に離鍵したものの時間|`time` と同じ|
|`fms_rr`|0 〜 15 の整数|ＦＭ音源（@@"fms"）の音に、選んだもののうち最も後に離鍵したものへ書くリリースレート|ＦＭ音源の音は選ばない|
|`fms_rr_older`|0 〜 15 の整数|２つ以上選んだとき、それより前に離鍵したものへ書くリリースレート|`fms_rr` と同じ|

- `pick=oldest`・`pick=newest` は１つしか選ばないので、`time_older`・`fms_rr_older` は書けません（エラーになります）。
- `fms_rr_older` は、`fms_rr` と一緒に書きます。
- 定義の `@tl` は、`#MB:TONE_LAYER` の中の `@…=` と違い、値を入れる意味ではなく「`@tl` の番号を比べるかどうか」です。`same`・`any` のほかは書けません（`@tl=36` などはエラーになります）。
- `time`・`time_older` の単位は msec で、エンベロープクロック（`env_clock`）の設定に依りません。

#### time の値と効果：

今の高さが何であっても、`time` の時間で 0 に着きます（下がり方は、今の高さに比例した傾きの直線です）。

|`time`（msec）|今の高さが peak のとき|今の高さが peak の 50% のとき|
|:-:|:-:|:-:|
|0|すぐ 0|すぐ 0|
|12|12 msec で 0|12 msec で 0|
|102.9|102.9 msec で 0|102.9 msec で 0|
|441.3|441.3 msec で 0|441.3 msec で 0|
|1645.3|1645.3 msec で 0|1645.3 msec で 0|

- 自然のリリースより長い `time` を書いた場合も置き換えます（余韻が長くなります）。
- `fms_rr` は、リリースレートを書き換えるだけです。その時点の音量から、そのリリースレートの速さで下がります。リリースレートごとの時間の目安は、[7.7](7_7.md) の表を見てください。

### 選ぶ時と、選ぶ相手：

- 新しい音のノートオンのとき、その音が使う発音を取る前に、１回だけ選んで置き換えます。
- スラー（`&`）で音程だけ変わるときは、何もしません。
- 相手は、同じトラックの音のうち、リリース中のものです。押鍵中の音、鳴り終わった音、強制ダンパー（`z`・`@az`）で下がっている音は選びません。`again=1` のときは、オートダンパーで下がっている途中の音も選びます。
- `pick` と、`time`・`time_older` の新旧は、離鍵した順で決めます（同じ時点に離鍵したものは、処理した順）。
- 前の音のノートオンも、その前の音へオートダンパーを配ります。例えば `key=any`・`pick=oldest` では、音を鳴らすたびに、１つ前の音が置き換わります。
- ＦＭ音源（@@"fms"）の音には `fms_rr` のリリースレートだけを、それ以外の音には `time` の時間だけを当てます。`fms_rr` を書かない定義では、ＦＭ音源の音は選ぶ前に除きます（新旧の順にも入りません）。

#### レイヤー（`@tl`）と組み合わせたとき：

- `@tl` を使っていない音は、すべて同じレイヤーとみなします。新しい音と相手のどちらかが `@tl` を使っていないときは、レイヤーは合うとみなします。
- 新しい音が複数のレイヤーを鳴らすときは、レイヤーごとに、そのレイヤー番号の音を選びます（`pick` と、`time`・`time_older` の新旧も、レイヤーごとに決めます）。`layer=any` のときは、レイヤーを分けずに１回だけ選びます。
- `@tl` を使っていない音は、`@tl` の番号を「なし」として比べます（なし同士は同じです）。
- どのレイヤーも鳴らさない音符（レイヤーのキーやベロシティの範囲に入らない音）は、新しい音として扱わず、オートダンパーを配りません。

### 置き換えた後の音：

- 置き換えるのは音量エンベロープ（`@ea`）のリリースだけです。ピッチエンベロープ（`@ep`）や動的フィルタ（`@fd`）のエンベロープは、元のリリースのまま進みます。
- オートダンパーで下がっている途中の音に強制ダンパー（`z`・`@az`）が来ると、強制ダンパーに切り替わります。強制ダンパーのほうが優先です。
- `@ad0` にしても、すでに下がり始めた音は最後まで下がります。
- ＦＭ音源の音に書いたリリースレートは、次にその発音を鳴らすノートオンで、元の値に戻ります。

### 【注意】`@pl` のモード１との組み合わせ：

`@pl` の引数[2] が 1（同じ音程のリリース中の発音を先に使うモード）のトラックでは、置き換えた音の発音が、すぐ新しい音に使われて切れることが多くなります。  
オートダンパーを使うときは、`@pl` の引数[2] を 0 にすることをおすすめします。

## 【エラー】

- `@ad` の番号が `#MB:AUTO_DAMPER` で定義されていない：

```
@ad[] の番号は #MB:AUTO_DAMPER で定義されていません：@ad3
```

- `@ad` の数値を省略した：

```
@ad[] の数値は省略できません。
```

- `key` または `time` を書かなかった：

```
次の必須項目が定義されていません：key
```

- 値の綴りの誤り（`key`・`layer`・`@tl` は `same` か `any`、`pick` は `all`・`oldest`・`newest`、`again` は `0` か `1`）：

```
pick の値は all・oldest・newest のどれかです：pick=first
@tl の値は same か any です（@tl の番号ではなく、比べるかどうかを書きます）：@tl=36
```

- 知らない要素：

```
項目名エラー：rr（書ける項目は key・layer・@tl・pick・again・time・time_older・fms_rr・fms_rr_older）
```

- `pick=oldest`・`pick=newest` に `time_older`・`fms_rr_older` を書いた：

```
pick=oldest・newest は 1 つしか選ばないので、time_older は書けません。
```

- `time` が負、`fms_rr` が 0 〜 15 の整数でない、定義番号が 1 〜 999 の外、`fms_rr_older` だけを書いた：それぞれエラーになります。
- 音色のレイヤー（`#MB:TONE_LAYER`）に `@ad` を書いた：エラーになります。`@ad` はトラックの値だけを持ちます。
- 「`#`」を記述すると、前回の値として解釈されます。

## 【表示】

### KeyDispへの表示：

オートダンパーが有効な間（`@ad1` 以上）は、KeyDisp の２行目の `@az` の次に `@ad1` のように表示されます。`@ad0` のときは表示されません。  
`@pl` を書いていないトラックなど、オートダンパーが働かない間も、書いた番号が表示されます。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`・`!c`）では、`@az` の次に `@ad1` のように表示されます。一度でも書いていれば、`@ad0` も表示されます。  
差分（`!d`）には、値が変わったときに表示されます。
