# 7.1 `@eoc[str],[1]`：エンベロープオプション CLOCK
# 7.2 `@eor[str],[1]`：エンベロープオプション RESOLUTION

[← 目次](../index.md)

## 【記述例】

```mml
#MB:ENV_A @ea=1 { peak=15, init=8, |
   n:2:15, n:12:10, n:30:10, n:10:12, l:10:8, n:10:12,
   r:i1:6, n:40:6, n:1:0
}
t100 q11,16 v15 @@"pls" @ea1
@eoc"sec",1/120
@eor"smp"
l2 o5 cegefdgg cegefdg&g;
```

## 【解説】

エンベロープ（`@ea`,`@ef`）への、オプション設定を行います。

- `@eoc[str],[1]`
- `@eor[str],[1]`

上記のコマンドは、次の `#MB:CONFIG {...}` による設定を、トラックごとに変更したい場合に使用します。

```mml
#MB:CONFIG {
   env_clock: unit=sec: rate=1/60,
   env_resol: unit=sec: rate=1/300,
}
```

---

### `@eoc[str],[1]`

エンベロープクロックの設定を行います。  
エンベロープクロックは、エンベロープの１節での経過時間の単位です。

指定する引数は次の通りです。

- 引数[str]：時間単位
- 引数[1]：時間単位への倍率

引数はカンマで区切って指定します。

#### 引数[str]が、`"sec"` だったとき

時間単位が「１秒」になります。  
引数[1]の設定範囲は、1/2400[秒] 〜 1.0[秒] です。

#### 引数[str]が、`"tick"` だったとき

時間単位は「１tickカウント」になります。  
引数[1]の設定範囲は、０より大きい値です。  
ただし、最小は1/2400[秒]に制限されます。

---

### `@eor[str],[1]`

エンベロープ解像度の設定を行います。  
エンベロープ解像度は、振幅計算更新の最小時間の単位です。

指定する引数は次の通りです。

- 引数[str]：解像度の時間単位
- 引数[1]：解像度の時間単位への倍率

引数はカンマで区切って指定します。

#### 引数[str]が、`"smp"` だったとき

解像度の時間単位が「１サンプル（最大解像度）」になります。  
引数[1]は不要です。（引数[1]は指定できません）

#### 引数[str]が、`"sec"` だったとき

解像度の時間単位が「１秒」になります。  
引数[1]の設定範囲は、1/2400[秒] 〜 1.0[秒] です。

#### 引数[str]が、`"tick"` だったとき

解像度の時間単位は「１tickカウント」になります。  
引数[1]の設定範囲は、０より大きい値です。  
ただし、最小は1/2400[秒]に制限されます。

---

### 【備考】

時間単位が「１tickカウント」の場合、テンポにより時間単位が変動します。
