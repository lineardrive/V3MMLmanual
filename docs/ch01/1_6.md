# 1.6 文字列「`"..."`」の記述

[← 目次](../index.md)

## 【記述例】

```mml
@@"pls"
y"op2_tl",40
ym"fms","subform",1
!s"stat-a"
```

## 【解説】

ＭＭＬコマンドの引数のうち、`[str]` と表記されているものは、ダブルクォーテーション「`"`」で括った文字列で指定します。

文字列引数は、宛先などのキーワードの指定と、デバッグ表示のためのものです。  
特にデバッグ表示用途で文言が決まっていない場合、記述内容に制限があります。

---

## 長さと文字種

### 長さの上限：

長さの上限は 64バイト です。  
65バイト以上を書くと、次の警告が出てコンパイルが止まります。

```
文字引数の記述が長すぎます（上限 64 バイト）。
```

### 使用できる文字：

書けるのは 半角 ASCII（0x20〜0x7E）だけです。

全角文字は、コンパイル前の処理により、空白に置き換えられます。  
全角１文字は３バイトなので、空白３個に置き換わったうえで、上限の枠を３バイトぶん消費します。

### 閉じ引用符：

閉じ引用符を書き忘れたままＭＭＬテキストが終わると、次の警告が出てコンパイルが止まります。

```
文字列引数の終端前にテキスト終端に達しました。
```

---

## 文字列の中に書けない記述

文字列の中身が取り出される前に、コメント除去・マクロ展開・繰り返し展開が、ＭＭＬテキスト全体に対して行われます。  
これらの処理は引用符を見ないため、次の記述は、文字列の中に書いても文字としては残りません。

|文字列内記述|書いた場合どうなるか|
|:-|:-|
|`//`|その行の残りが消えます|
|`/* ... */`|挟まれた部分が消えます（警告が出ません。特に注意してください）|
|`\|:`|繰り返しの開始として解釈されます|
|`:\|`|`\|: ... :\|` の内側に書くと、繰り返しがそこで閉じます|
|`\|`|`\|: ... :\|` の内側に書くと、最終周マーカーとして１バイト消えます|
|`;`|マクロ定義の中で、文字列のつもりで書くと、マクロ定義がそこで切れます|
|`$` ＋ マクロ名|マクロ定義の中で書くと、マクロ展開が優先されるので、マクロ再帰呼び出しエラー、またはマクロ展開による文字数オーバーエラーの原因になります|

上記の条件に当てはまらなければ、次の記述はそのまま書けます。

- `;`（マクロの外）
- `$`（どのマクロ名とも一致しないとき）
- `#`　`@`　`<`　`>`　`{`　`}`　`:`　`/`　`*`　`|`　`:|`（繰り返しの外）
- その他の 0x20〜0x7E すべて

### 【注】

この制限は、仕様として受け入れているものです。緩める予定はありません。

---

## 【備考】数値位置の「`"..."`」について

数値を指定する引数の位置にダブルクォーテーションを書いた場合は、文字列引数ではなく、計算式の記述として解釈されます。上記の長さの上限とは、別の扱いになります。

```mml
@d"(3+4)*2"
```
