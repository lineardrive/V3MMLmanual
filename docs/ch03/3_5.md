# 3.5 `@qt[1]`：キーオンディレイ

[← 目次](../index.md)

## 【記述例】

```mml
#MB:CONFIG { tempo_unit: note_ticks=192: beat_length=4, }

q%0 @q0 @qt0 c4 e4;
q%0 @q0 @qt5 f4 g4;
```

上記の場合、次のように演奏されます。

- `c` は 48ticks発音
- `e` は 48ticks発音
- `f` は 5ticks休符＋43ticks発音
- `g` は 5ticks休符＋43ticks発音

```mml
#MB:CONFIG { tempo_unit: note_ticks=192: beat_length=4, }
@qt3 q%10 l4 cdefg;
```

上記の場合、各音符（48ticks）は 3ticks休符＋10ticks発音＋35ticks休符 になります。

## 【解説】

キーオンディレイです。ノートオンを遅らせる tickカウント数を指定します。

引数[1]には、ノートオンを遅らせる tickカウント数を、0 以上の整数で指定します。  
`@qt0` を指定すると無効になります。  
トラック先頭における初期設定は、`@qt0` です。

コマンド名の `t` は transfer（移動）の意味です。  
ゲート（`q` / `q%` / `@q`）が作った発音の窓を、まるごと後ろへスライドさせます。

音符が消費する時間は変わりません。次の音符の位置は 1tickカウント もずれません。

スライドによって潰れるのは、まず「末尾の無音」です。  
末尾の無音を使い切ってから、はじめて「発音長」が潰れます。発音長は 1tickカウント が下限です。

発音が短くなることはありますが、それは窓が音長からはみ出した分が切られた結果であって、`@qt` 自体が削っているのではありません。

### 【注】`@qt` はゲートタイムのコマンドではありません

`@qt` は窓を移動させるコマンドであり、削る機能ではないため、`q` / `q%` / `@q` のゲートタイムの並びには属しません。

---

## ゲートの計算順序

音符の発音長は、次の順序で決まります。

1. `q[],[]` または `q%[]` で、キーオンからの tickカウント数を決めます。  
   音長を超えたぶんは、音長で頭打ちになります（`q%200` は `q16,16` と同等になります）。
2. `@q[]` で、1. の末尾から tickカウントを削ります。
3. 1. と 2. で決まった窓を、`@qt[]` の tickカウント数だけ後ろへ移動します。

全体をまとめると、次の式になります。

```
発音長 ＝ min( ゲート長, 音長 − ディレイ )
```

### 【計算例】

`note_ticks=192`、`beat_length=4` の設定で、`c%192`（192ticks）を鳴らした場合の例です。

|記述|先頭の無音|発音長|末尾の無音|
|:-|:-:|:-:|:-:|
|`q%200 @qt0 @q0`|0|192|0|
|`q%200 @qt0 @q8`|0|184|8|
|`q%96 @qt0 @q8`|0|88|104|
|`q%96 @qt100 @q8`|100|88|4|
|`q%96 @qt160 @q8`|160|32|0|
|`q%96 @qt200 @q8`|191|1|0|

---

### 【注】`@q` が効いていないように見える場合

次の２つは、同じ音になります。

```mml
q16,16 @qt24 @q24
q16,16 @qt24 @q0
```

`q16,16` ではゲートが音長いっぱいなので、末尾の無音は `@q24` が作った 24ticks しかありません。  
そこへ `@qt24` のスライドが来ると、その 24ticks をちょうど通り過ぎて、末尾が 0 になります。

`@q` が無視されたのではなく、スライドが `@q` の空けた余白を使い切った、ということです。  
`@qt` を 12 に減らせば、末尾に 12ticks が残ります。

---

### ゲート指定との併用：

- `@qt` と `@q` 指定は併用できます。
- `@qt` と `q` 指定は併用できます。
- `@qt` と `q%` 指定は併用できます。
- ただし、`q` と `q%` 指定は排他になります。

### タイ・スラーとの関係：

ノートオンを伴わない継続部分は、`@qt` の対象外です。

- タイ（`&` のあとに音長だけ）… 前の音が伸びるだけで、ノートオンがありません。
- スラー（`&` のあとに音名）… ノートオンを維持したまま次へつながります。

スラーの１音目は、ノートオンを行うため `@qt` の対象になります。この場合も、音符が消費する時間は変わりません。

### 【注】引数[1] が音長以上のとき

エラーにはなりません。  
その音符の発音長は 1tickカウント に矯正されます。音符が消費する時間は、音長のままです。

例えば、４分音符（48ticks）に `@qt200` を指定した場合、47ticks休符＋1tick発音 となり、48ticksぶんの時間を消費します。

### 【備考】

`@qt` の指定値は、`qtp`コマンドで指定された整数倍されます。
