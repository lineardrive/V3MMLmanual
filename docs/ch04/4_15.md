# 4.15 `@fg[1],[2]`：フェードゲイン

[← 目次](../index.md)

## 【記述例】

```mml
@fg2,-12 cdefg
```

上記の場合、`@fg2,-12` 記述以降の演奏に対し、その時点のフェードの音量から、2 秒間かけて、デシベルスケールで `-12dB` まで音量を変化させます。
`-12dB` に着いた後は、`-12dB` を保ちます。

## 【解説】

フェードの音量を、その時点の値から、指定したデシベルまで変化させます。  
当コマンドを使用したトラックのみ、音量を変化させます。

フェードアウト（`@fo`）とフェードインには、始まりか終わりが必ず通常音量（0dB）になる決まりがありますが、
`@fg` には、この決まりがありません。  
「-14dB から -5dB へ」「-5dB から -16dB へ」のように、どこからでも、どこへでも動かせます。

指定する引数は次の通りです。

- 引数[1]...変化させる時間（time）
- 引数[2]...到達点の音量（gain）

引数はカンマで区切って指定します。

### 引数[1]（time）

音量を変化させる時間を 0 以上の数値で指定します。  
単位は秒です。小数点以下の指定も受け付けます。  
負の数を指定するとエラーになります。

- 0 を指定すると、その場で到達点の音量になります。  
  `@fo0` / `@fi0` と違い、フェードの中断（通常音量に戻すこと）にはなりません。

### 引数[2]（gain）

到達点の音量を指定します。  
範囲は -120 〜 24 の数値で、単位はデシベルです。小数点以下の指定も受け付けます。

- 0 より大きい値を指定すると、通常音量より大きくできます。
- -120 より小さい指定は、-120 を指定したものとみなされます。
- 24 より大きい指定は、24 を指定したものとみなされます。
- gain は省略できません。省略するとエラーになります。

### 音量の変化のしかた

その時点のフェードの音量から、到達点の音量まで、デシベルスケールで直線的に変化させます。

- 到達点が 0dB のときは、0dB に着いた時点でフェード機能を解除します。
- 到達点が 0dB 以外のときは、着いた後も到達点の音量を保ちます。

「その時点のフェードの音量」は、直前のフェードコマンドの状態から求めます。

|直前の状態|始まりの音量|
|:-|:-|
|フェードを使っていない（解除されている）|0dB|
|`@fo` の途中・減衰しきった後|その時点の音量|
|`@fi` の途中|その時点の音量|
|`@fg` の途中・到達点を保っている間|その時点の音量|

range を 0 にした `@fo` / `@fi`（線形変化）で、その時点の音量が無音（または -120dB より小さい）の場合は、-120dB から始まります。

#### 【備考１】

最後に指定したフェードコマンドが優先されます。  
`@fg` の後に `@fo` / `@fi` を記述すると、それぞれの決まりどおり、0dB または range から始まります。  
`@fg` の途中や、到達点を保っている間に `@fo0` / `@fi0` を記述すると、フェード機能を中断して、通常音量(0dB)に戻ります。

#### 【備考２】

ポリフォニックモード（`@pl`）のトラックでも、鳴っている音・リリース中の音・その後に鳴り始めた音のどれにも、すぐに同じ音量が掛かります。  
伸ばしている和音を、鳴らしたまま膨らませたり絞ったりする用途に使えます。

```mml
@pl4,0 @fg0,-18 @fg2,-3 [c1&1 e1&1 g1&1] @fg2,-18 [c1&1 e1&1 g1&1]
```

上記の場合、1 つ目の和音を鳴らしている間に -18dB から -3dB へ膨らませ、2 つ目の和音を鳴らしている間に -18dB へ絞ります。

#### 【備考３】

引数に「`#`」を記述すると、直前のフェードコマンド（`@fo` / `@fi` / `@fg`）の値として解釈されます。  
前回が無い場合と、`@fo0` / `@fi0` で中断した後は、time が 1、gain が 0 になります。
