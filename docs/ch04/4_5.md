# 4.5 `@p[1]`：パンポット

[← 目次](../index.md)

## 【記述例】

```mml
@p0 ceg @p100 dfa @p-100 egb;
```

## 【解説】

パンポット（音声出力の左右バランス）を設定します。

引数[1]には、左右バランスを表す数値を指定します。  
設定範囲は -100 〜 100 で、小数点以下の指定も受け付けます。  
トラック先頭における初期設定は、`@p0`（中心）です。

## 【演算モード】

左右の振幅倍率の求め方には、４つのモードがあります。  
モードは、ボリュームスケール定義（`#MB:VOLUME_SCALE`）の項目 `@p=` で選択します。

```mml
#MB:VOLUME_SCALE vs=1 {
   type=linear, v=15, @ea=mul, vl=15, @la=mul, @p=constant_sum,
}
#MB:VOLUME_SCALE vs=2 {
   type=linear, v=15, @ea=mul, vl=15, @la=mul, @p=constant_peak,
}
#MB:VOLUME_SCALE vs=3 {
   type=linear, v=15, @ea=mul, vl=15, @la=mul, @p=sys22rr,
}
#MB:VOLUME_SCALE vs=4 {
   type=linear, v=15, @ea=mul, vl=15, @la=mul, @p=constant_power,
}
t70 l4 vs1 v15 @p0 c @p100 d vs2 @p-100 e vs3 @p-50 f vs4 @p50 g;
```

- `@p=` は省略可能で、省略した場合は `@p=constant_sum`（従来からの動作）になります。
- `type=table` / `type=linear` / `type=exponential` のいずれでも指定できます。
- `vs`コマンドを切り替えれば、曲の途中でもモードが切り替わります。

[（ボリュームスケール定義とは）](4_7n8.md)

---

### `@p=constant_sum` のとき（既定）：

左右の振幅倍率の合計が、常に 1.0 になります。

|`@p`設定|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|
|`@p-100`（左側に最大）|1.0 倍|0.0 倍|
|`@p-50`（左側に50%）|0.75 倍|0.25 倍|
|`@p0`（中央設定）|0.5 倍|0.5 倍|
|`@p50`（右側に50%）|0.25 倍|0.75 倍|
|`@p100`（右側に最大）|0.0 倍|1.0 倍|

- このモードでは、左右の最大振幅が、中央設定の２倍になっているところに注意してください。

---

### `@p=constant_peak` のとき：

左右の振幅倍率が、どちらも 0.5 を超えません。  
パンを振ったとき、近い側は 0.5 倍のまま、遠い側だけが減衰します。

|`@p`設定|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|
|`@p-100`（左側に最大）|0.5 倍|0.0 倍|
|`@p-50`（左側に50%）|0.5 倍|0.25 倍|
|`@p0`（中央設定）|0.5 倍|0.5 倍|
|`@p50`（右側に50%）|0.25 倍|0.5 倍|
|`@p100`（右側に最大）|0.0 倍|0.5 倍|

- 中央設定（`@p0`）では、`constant_sum`・`constant_peak`・`sys22rr` の結果は一致します（左右とも 0.5 倍）。差が出るのは、パンを振ったときだけです。`constant_power` だけは中央で約 0.7074 倍で、ほかより約 3dB 大きくなります。
- パンを振ったときの音量感は、`constant_sum` と比べて一律に 6dB 低くなります。

---

### `@p=sys22rr` のとき：

特定ドライバのパンの曲線を近似します。  
`@p` の -100 〜 100 を、聴き手から見た角度 -90°（左）〜 +90°（右）と読みます。  
左前と右前のスピーカーが ±45°（`@p-50` / `@p50`）にあると考え、その間を S 字の曲線で振り分けます。  
±45° より外側では、近い側のスピーカーだけが S 字の曲線で下がり、±90°（`@p-100` / `@p100`）で 0.5 倍になります。

|`@p`設定|角度|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|:-:|
|`@p-100`|左 90°|0.5 倍|0.0 倍|
|`@p-75`|左 67.5°|0.84375 倍|0.0 倍|
|`@p-50`|左 45°|1.0 倍|0.0 倍|
|`@p-25`|左 22.5°|0.84375 倍|0.15625 倍|
|`@p0`（中央設定）|正面|0.5 倍|0.5 倍|
|`@p25`|右 22.5°|0.15625 倍|0.84375 倍|
|`@p50`|右 45°|0.0 倍|1.0 倍|
|`@p75`|右 67.5°|0.0 倍|0.84375 倍|
|`@p100`|右 90°|0.0 倍|0.5 倍|

計算式は次のとおりです。`x = (@p + 100) / 200`（左端 0.0 〜 中央 0.5 〜 右端 1.0）とし、S 字の曲線を `S(t) = t × t × (3 − 2t)` とします。

|`@p` の範囲|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|
|-100 〜 -50|1 − S(0.5 − 2x)|0|
|-50 〜 50|1 − S(2x − 0.5)|S(2x − 0.5)|
|50 〜 100|0|1 − S(2x − 1.5)|

- `@p-50` 〜 `@p50` の間では、左右の振幅倍率の合計が常に 1.0 になります（`constant_sum` と同じです。違うのは、倍率が直線ではなく S 字の曲線で変わることです）。
- ±45° の境目でも、倍率は途切れずになめらかにつながります。パンポットバランスＬＦＯ（`@lb`）でパンを動かしても、段差やクリックは出ません。
- 実機の曲線（ドライバが持つ表）との差は、振幅倍率で最大 0.07 程度です。大きく鳴る側の差は、どの角度でも 0.5dB 以内です。表を持たずに 3 次式 1 本で求めるための近似です。

---

### `@p=constant_power` のとき：

左右の振幅倍率を、sin / cos の曲線で振り分けます。  
左右の電力の和（左の倍率の２乗 ＋ 右の倍率の２乗）がほぼ一定になる、もっとも一般的な定電力のパンです。  
パンを振っても、聞こえる音の大きさがほとんど変わりません。

|`@p`設定|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|
|`@p-100`（左側に最大）|1.0 倍|0.0 倍|
|`@p-75`|0.980942 倍|0.195099 倍|
|`@p-50`|0.924226 倍|0.382743 倍|
|`@p-25`|0.831861 倍|0.555740 倍|
|`@p0`（中央設定）|0.707411 倍|0.707411 倍|
|`@p25`|0.555740 倍|0.831861 倍|
|`@p50`|0.382743 倍|0.924226 倍|
|`@p75`|0.195099 倍|0.980942 倍|
|`@p100`（右側に最大）|0.0 倍|1.0 倍|

計算式は次のとおりです。`x = (@p + 100) / 200`（左端 0.0 〜 中央 0.5 〜 右端 1.0）とします。

- 右側の振幅倍率 ＝ f(x)
- 左側の振幅倍率 ＝ f(1 − x)
- f(t) ＝ t × (c1 ＋ t² × (c3 ＋ c5 × t²))
  - c1 ＝ π / 2（1.5707963267948966）
  - c3 ＝ 2.5 − π（−0.6415926535897931）
  - c5 ＝ π / 2 − 1.5（0.0707963267948966）

f(t) は、sin(π / 2 × t) を５次の多項式で近似したものです。sin / cos を計算せずに、掛け算と足し算だけで求めるための近似です。  
係数は、sin(π / 2 × t) と同じく、f(1) ＝ 1（端で 1.0 倍）、t ＝ 1 で傾きが 0（端で曲線が平らになる）、t ＝ 0 での傾きが π / 2（遠い側が 0 から立ち上がる傾き）になるように決めています。

- sin / cos との差は、振幅倍率で最大 0.0004、dB で最大 0.004dB です。
- 左右の電力の和は、正確な定電力に対して ＋0dB 〜 ＋0.004dB（中央で最大）です。
- 端（`@p-100` / `@p100`）では、1.0 倍と 0.0 倍のちょうどの値になります。
- 中央設定（`@p0`）は約 0.7074 倍で、`constant_sum` の 0.5 倍より約 3dB 大きくなります。端の 1.0 倍は `constant_sum` と同じです。

---

### 【備考】演算モードの適用範囲

- パンポットバランスＬＦＯ（`@lb`）によってパンが動く場合も、同じ演算モードが適用されます。
- 曲のバス（`@bf`、[6.39](../ch06/6_38n39.md)）へは、パンを振った後の音を送るので、バスのディレイの響きにも、送った時点の演算モードが適用されています。
- レガシーパンポット（`p`コマンド）は、演算モードの影響を受けません。

#### 【ポリフォニックモードでの効き方】

ポリフォニックモード（`@pl`）のトラックでは、`@p` の値は、次のノートオンの直前にその発音チャネルへ当たります（鳴っている音には効きません）。  
`@dlv` で配り方を `all` にすると、鳴っている音にもすぐに効きます。[9.3 `@dlv`](../ch09/9_3.md) を参照してください。
