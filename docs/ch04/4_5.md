# 4.5 `@p[1]`：パンポット

[← 目次](../index.md)

## 【記述例】

```mml
@p0 ceg @p100 dfa @p-100 egb;
```

## 【解説】

パンポット（音声出力の左右バランス）を設定します。

引数[1]には、左右バランスを表す数値を指定します。  
設定範囲は -100 〜 100 で、小数点以下の指定も受け付けます。  
トラック先頭における初期設定は、`@p0`（中心）です。

## 【演算モード】

左右の振幅倍率の求め方には、２つのモードがあります。  
モードは、ボリュームスケール定義（`#MB:VOLUME_SCALE`）の項目 `@p=` で選択します。

```mml
#MB:VOLUME_SCALE vs=1 {
   type=linear, v=15, @ea=mul, vl=15, @la=mul, @p=constant_sum,
}
#MB:VOLUME_SCALE vs=2 {
   type=linear, v=15, @ea=mul, vl=15, @la=mul, @p=constant_peak,
}
t70 l4 vs1 v15 @p0 c @p100 d vs2 @p-100 e;
```

- `@p=` は省略可能で、省略した場合は `@p=constant_sum`（従来からの動作）になります。
- `type=table` / `type=linear` / `type=exponential` のいずれでも指定できます。
- `vs`コマンドを切り替えれば、曲の途中でもモードが切り替わります。

[（ボリュームスケール定義とは）](4_7n8.md)

---

### `@p=constant_sum` のとき（既定）：

左右の振幅倍率の合計が、常に 1.0 になります。

|`@p`設定|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|
|`@p-100`（左側に最大）|1.0 倍|0.0 倍|
|`@p-50`（左側に50%）|0.75 倍|0.25 倍|
|`@p0`（中央設定）|0.5 倍|0.5 倍|
|`@p50`（右側に50%）|0.25 倍|0.75 倍|
|`@p100`（右側に最大）|0.0 倍|1.0 倍|

- このモードでは、左右の最大振幅が、中央設定の２倍になっているところに注意してください。

---

### `@p=constant_peak` のとき：

左右の振幅倍率が、どちらも 0.5 を超えません。  
パンを振ったとき、近い側は 0.5 倍のまま、遠い側だけが減衰します。

|`@p`設定|左側の振幅倍率|右側の振幅倍率|
|:-:|:-:|:-:|
|`@p-100`（左側に最大）|0.5 倍|0.0 倍|
|`@p-50`（左側に50%）|0.5 倍|0.25 倍|
|`@p0`（中央設定）|0.5 倍|0.5 倍|
|`@p50`（右側に50%）|0.25 倍|0.5 倍|
|`@p100`（右側に最大）|0.0 倍|0.5 倍|

- 中央設定（`@p0`）では、２つのモードの結果は一致します。差が出るのは、パンを振ったときだけです。
- パンを振ったときの音量感は、`constant_sum` と比べて一律に 6dB 低くなります。

---

### 【備考】演算モードの適用範囲

- パンポットバランスＬＦＯ（`@lb`）によってパンが動く場合も、同じ演算モードが適用されます。
- ディレイエフェクト（`@dl`）の残響部分にも、同じ演算モードが適用されます。
- レガシーパンポット（`p`コマンド）は、演算モードの影響を受けません。
