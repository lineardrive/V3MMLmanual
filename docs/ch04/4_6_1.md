# 4.6.1 `px[1]`：振幅反転

[← 目次](../index.md)

## 【記述例】

```mml
c px2 c px0 c;
```

上記のように書くと、２つ目の `c` は、左側の出力だけ振幅を反転（-1 倍）して鳴ります。

## 【解説】

左右の出力の振幅を、それぞれ反転（-1 倍）するかどうかを設定します。

引数[1]には、反転のしかたを表す整数を指定します。  
設定範囲は、0 〜 3 です。  
トラック先頭における初期設定は、`px0`（反転しない）です。

|px設定|左側の振幅|右側の振幅|
|:-:|:-:|:-:|
|px0（反転しない）|そのまま|そのまま|
|px1（左右とも反転）|-1 倍|-1 倍|
|px2（左側だけ反転）|-1 倍|そのまま|
|px3（右側だけ反転）|そのまま|-1 倍|

- 「#」は前回の値です（`px#`）。
- 範囲外の値（`px4`、`px-1` など）を書くと、エラーになります。値を範囲に切り詰めることはしません。
- 引数は省略できません。`px` だけを書くとエラーになります。

```
px[] の数値は 0〜3 です：px4
px[] の数値は省略できません。
```

### レガシーパンポット（`p`）との関係

振幅反転は、レガシーパンポット（[4.6](4_6.md)）の左右の振幅倍率に、符号（+1 または -1）を掛ける形で働きます。

- `p-1` や `p1` で 0.0 倍にした側は、反転しても 0 のままです。
- `@p` のパンポット・パンポットバランスＬＦＯ（`@lb`）・パンポットの演算モード（`#MB:VOLUME_SCALE` の `@p=`）とは独立しています。どの組み合わせでも、反転は左右の振り分けの後に掛かります。

### ★ディレイエフェクトの出力にも掛かります

ディレイエフェクト（[6.38](../ch06/6_38n39.md)）の出力は、元の音と同じ経路で左右に振り分けられるので、振幅反転も同じように掛かります。  
音符の後に残るディレイの残響も、そのときの `px` の設定で反転します。

### サンプリングの `amp_mul` との違い

`#MB:LOAD_SAMPLING` の `amp_mul`（[6.58](../ch06/6_58.md)）に負の数を書いても振幅は反転しますが、左右とも反転します。  
`px` は左右を別々に選べます。両方を使うと掛け算になります（`amp_mul` が負で `px1` なら、元の向きに戻ります）。

### 宛先としての扱い

- キーイベント（`@kt` / `@kc` / `@kl`。[10.3](../ch10/10_3n4.md)〜[10.8](../ch10/10_7n8.md)）の宛先に `px` を指定できます。キーイベント定義の値も 0 〜 3 の範囲で書きます。範囲外の値があると、定義の読み込みでエラーになります。
- `xa`（[10.1](../ch10/10_1.md)）・`xm`（[10.2](../ch10/10_2.md)）の宛先にはなりません。`xa"px"` / `xm"px"` は宛先のエラーになります。

## 【備考】

左右の一方だけを反転した音を、反転しない音と重ねると、定位がぼやけて広がって聞こえます。  
ステレオの出力をモノラルにまとめると、反転した成分は打ち消し合います。
