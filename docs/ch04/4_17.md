# 4.17 `vel[1]`：ベロシティ

[← 目次](../index.md)

## 【記述例】

```mml
#MB:TONE_LAYER @tl=1 {
   layer=1, v=10, |
   layer=2, map_vel=100:127, @ea=2, v=6,
}
@@"pls" @pl4,0 @tl1 vel64 c d vel110 e f
```

上記の場合、`vel64` の `c` `d` はレイヤー 1 だけが鳴り、`vel110` の `e` `f` はレイヤー 1 とレイヤー 2 が重なって鳴ります。

## 【解説】

音符のベロシティ（打鍵の強さ）を、0 〜 `peak` の数で指定します。小数も書けます。  
`peak` は `#MB:CONFIG` の `velocity: peak=`（[5.8.17](../ch05/5_8_17.md)）で決まり、書かなければ 127 です。  
トラックの先頭では `peak` です。次に変えるまで、その値を保ちます。

**`vel` だけでは、音は何も変わりません。** 次のものが参照したときだけ効きます。

- 音色のレイヤー（`@tl`・`#MB:TONE_LAYER`。[10.9](../ch10/10_9n10.md)）の `map_vel`・`_velmap`
- 動的フィルタ（`#MB:FILTER_D`。[6.42](../ch06/6_41n42.md)）の `mod=vel`
- エンベロープ（`#MB:ENV_A`・`#MB:ENV_FD`。[7.4](../ch07/7_3n4.md)・[7.5](../ch07/7_5n6.md)）の `vel_curve`・`vel_depth`・`time_vel`

動的フィルタとエンベロープでは、ノートオンのときの r ＝ `vel` ÷ `peak` を、その音符の間使います（タイ・スラーで `vel` を替えても、最初の音符の値のままです）。  
音量の強弱は、今までどおり `v`（[4.9](4_9.md)）でも書けます。`#MB:ENV_A` の `vel_curve` を使うと、`vel` で音量のエンベロープの高さを変えられます。

- 範囲の外を指定するとエラーになります。
- 「`#`」を記述すると、前回の値として解釈されます。
- `)` `(` のような相対指定はありません。
- 無限リピート（`@rp`）で先頭へ戻っても、値は変わりません。

---

## 【表示】

### KeyDispへの表示：

表示されません。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`）と差分（`!m` / `!d`）には、`vg` の後ろに `vel64` のように表示されます。小数は書いた値のとおり（`vel63.5`）に表示されます。  
`vel` を一度も記述していないトラックでは表示されません。
