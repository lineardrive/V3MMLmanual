# 4.17 `vel[1]`：ベロシティ

[← 目次](../index.md)

## 【記述例】

```mml
#MB:TONE_LAYER @tl=1 {
   layer=1, v=10, |
   layer=2, map_vel=100:127, @ea=2, v=6,
}
@@"pls" @pl4,0 @tl1 vel64 c d vel110 e f
```

上記の場合、`vel64` の `c` `d` は層 1 だけが鳴り、`vel110` の `e` `f` は層 1 と層 2 が重なって鳴ります。

## 【解説】

音符のベロシティ（打鍵の強さ）を、0 〜 127 の整数で指定します。  
トラックの先頭では 127 です。次に変えるまで、その値を保ちます。

**`vel` だけでは、音は何も変わりません。**  
音色の層（`@tl`・`#MB:TONE_LAYER`。[10.9](../ch10/10_9n10.md)）の `map_vel`・`_velmap` が参照したときだけ効きます。  
音量の強弱は、今までどおり `v`（[4.9](4_9.md)）で書きます。

- 範囲の外や小数を指定するとエラーになります。
- 「`#`」を記述すると、前回の値として解釈されます。
- `)` `(` のような相対指定はありません。
- 無限リピート（`@rp`）で先頭へ戻っても、値は変わりません。

---

## 【表示】

### KeyDispへの表示：

表示されません。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`）と差分（`!m` / `!d`）には、`vg` の後ろに `vel64` のように表示されます。  
`vel` を一度も記述していないトラックでは表示されません。
