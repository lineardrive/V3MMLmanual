# 4.16 `vg[1],[2]`：ボリュームグライド

[← 目次](../index.md)

## 【記述例】

```mml
#MB:VOLUME_SCALE vs=1 {
   type=exponential, curve=dB, rate=-0.5,
   v=127, @ea=mul, v0act=mute,
   vl=127, @la=mul, vl0act=mute,
   vg=127, vgtu=msec, vg0act=mute,
}
vs1 vg127,12 c4 vg120 d4 vg80,2000 e1 vg96,0 f4
```

上記の場合、`vg120` 以降の演奏に対し、その時点の音量から 12 ミリ秒かけて、音量スケールの目盛りの 120（-3.5dB）まで音量を変化させます。  
`vg80,2000` では 2 秒かけて目盛りの 80（-23.5dB）まで変化させ、`vg96,0` では、その場で目盛りの 96（-15.5dB）にします。

## 【解説】

トラックの音量を、音量スケール（`#MB:VOLUME_SCALE`。[4.7](4_7n8.md)）の目盛りの値で指定し、指定した時間をかけて滑らかに変化させます。  
当コマンドを使用したトラックのみ、音量を変化させます。

`v` と同じ目盛りで値を書けるので、音量の段階をそのまま数値で書けます。  
`v` と違って、値を変えるときに指定した時間をかけて移るので、音の途中で大きく変えても音量の段差が出ません。

指定する引数は次の通りです。

- 引数[1]...音量の目盛りの値
- 引数[2]...変化させる時間

引数はカンマで区切って指定します。

### 引数[1]（目盛りの値）

範囲は 0 〜 音量スケールの `vg=` で定義した最大値の数値です。小数点以下の指定も受け付けます（`type=table` では `vgr` で丸めます）。  
範囲の外を指定するとエラーになります。

### 引数[2]（変化させる時間）

0 以上の数値で指定します。小数点以下の指定も受け付けます。  
単位は、音量スケールの `vgtu` で指定します（`msec` はミリ秒、`tick` は tick 数）。  
負の数を指定するとエラーになります。

- 0 を指定すると、その場で目標の音量になります。
- 省略すると、前回指定した時間を指定したものとみなします。トラックの先頭では 0（即時）です。
- `vgtu=tick` のときは、コマンドの時点のテンポで時間に直して固定します。変化の途中でテンポが変わっても追従しません。

### 目盛りの値から音量への変換

目盛りの値は、コマンドの時点の音量スケールで、デシベルに直します。倍率の出し方は `v` と同じです（音量エンベロープは掛けません）。

|`type`|音量|
|:-|:-|
|`exponential`|(`vg` − 値) × `rate`。`curve=dBB` のときは、同じ考え方でデシベルバイナリモードスケールの値をデシベルに直します。値が 0 のときは `vg0act` に従います|
|`linear`|20 × log10(値 ÷ `vg`)。値が 0 のときは無音です|
|`table`|値を `vgr` で配列の添字に丸め、その倍率をデシベルに直します|

無音は -120dB として扱います（`@fg` の下限と同じ）。

### 音量の変化のしかた

その時点の音量から、目標の音量まで、デシベルスケールで直線的に変化させます。

- 目標に着いた後は、目標の音量を保ちます。
- 変化の途中で次の `vg` を記述すると、その時点の音量から変化し直します。
- トラックの先頭の音量は、目盛りの最大（0dB）です。
- 音を鳴らしていない間も、時間は進みます。休符の途中で鳴り始めた音は、変化の途中の音量から始まります。

#### 【備考１】

`vg` は、`v`・`vl`・`mv`・音量エンベロープ（`@ea`）とは別に、音量に掛け算されます。  
フェード（`@fo` / `@fi` / `@fg`）とも別に掛け算されるので、曲の途中の音量の変化を `vg` で書き、曲の終わりのフェードを `@fo` で書くといった使い分けができます。

#### 【備考２】

`vs` で音量スケールを切り替えても、`vg` のその時点の音量（デシベル）はそのまま保たれます。次の `vg` から、新しい音量スケールの目盛りで変換します。

#### 【備考３】

ポリフォニックモード（`@pl`）のトラックでも、鳴っている音・リリース中の音・その後に鳴り始めた音のどれにも、すぐに同じ音量が掛かります。  
`@dlv`（[9.3](../ch09/9_3.md)）の対象ではなく、常にすぐに掛かります。

#### 【備考４】

音量スケールに `vg=` を書いていない場合（音量スケールを定義していない場合を含みます）、`vg` を記述するとエラーになります。

#### 【備考５】

引数に「`#`」を記述すると、前回の値として解釈されます。  
前回が無い場合、引数[1] は音量スケールの `vg=` の最大値、引数[2] は 0 になります。  
`vg#,500` と書くと、音量はそのままで、以後の省略時の時間だけを 500 にできます。

## 【表示】

### KeyDispへの表示：

そのトラックで `vg` を一度受け付けた後は、KeyDisp の `vl` の後ろに `vg120` のように引数[1] の値が表示されます。  
引数[2]（時間）は表示されません。

- 表示されるのは記述した値です。変化の途中の音量ではありません。
- 目盛りの最大を指定した後も、表示は残ります。
- `vg` を一度も記述していないトラックでは表示されません。

### ＭＭＬステータス表示：

ＭＭＬステータス表示（`!s`）と差分（`!m` / `!d`）には、`vl` の後ろに `vg120,12` のように、引数[1] と引数[2] が表示されます。引数[2] は、省略したときに使われる前回の時間です。  
`vg` を一度も記述していないトラックでは表示されません。
