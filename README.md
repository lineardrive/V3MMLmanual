## 🧾 バージョン管理方針

- **Markdown（Web 版）**
  - 従来の PDF 原文を基準として作成。作成後は Markdown 版が原文として更新対象になる
  - 誤字脱字修正・構造整理は随時反映
  - 差分管理を重視

- **PDF**
  - Markdown版が原文となるので、更新停止
  - v1.28の内容確認のために置いておく
